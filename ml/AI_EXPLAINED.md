# 우리 AI, 진짜 쉽게 이해하기 (개인용 설명서)

> 이 문서는 정식 보고서가 아니라, 내가 우리 AI가 뭘 어떻게 하는지 **완전히 이해해서 내 입으로 설명할 수 있게** 만든 개인 학습 노트다.
> 어려운 말은 최대한 풀고, 비유를 많이 쓴다.

---

## 0. 한 문장 요약

우리 앱엔 **AI가 두 개** 있다.
1. **판정기(신경망, MLP)**: "지금 이 사람이 Zone 2 안에 있나?"를 매 순간 맞히는 AI.
2. **개인화기(베이지안)**: "이 사람의 진짜 Zone 2 경계가 몇 bpm이지?"를 운동할수록 점점 정확히 알아내는 AI.

판정기는 "지금"을 판단하고, 개인화기는 "그 사람"을 배운다. 둘이 협력한다.

---

## 1. 먼저 "머신러닝(ML)"이 뭔지

**머신러닝 = 데이터를 보고, 모델 안의 숫자(파라미터)를 조금씩 조정해서, 점점 잘 맞히게 만드는 것.**

비유: 활쏘기를 배운다고 하자.
- 처음엔 대충 쏜다(엉망).
- 화살이 왼쪽으로 빗나가면 → 조준을 오른쪽으로 조금 튼다.
- 이걸 수백 번 반복하면 점점 과녁에 맞는다.

여기서 "조준을 트는 것"이 바로 **학습(파라미터 조정)**이다. 데이터(빗나간 결과)를 보고 숫자(조준)를 고치는 것.

**중요**: "학습"은 신경망만의 것이 아니다. **데이터로 숫자를 조정하면 다 학습(ML)이다.** 우리 개인화기(베이지안)도 데이터로 숫자를 고치니까 엄연히 ML이다. 다만 **신경망(딥러닝)은 아니다.** (신경망은 학습 방식 중 한 종류일 뿐)

## 2. 모델 ① 판정기 — 신경망(MLP)

### 2-1. 이게 푸는 문제
달리는 중 **매 순간**, 지금 상태가 셋 중 뭔지 맞힌다:
- **미달(below)**: 너무 살살 (Zone 2보다 낮음)
- **유지(in)**: 딱 좋음 (Zone 2 안)
- **초과(above)**: 너무 셈 (Zone 2보다 높음)

### 2-2. 왜 "규칙"이 아니라 "신경망"인가 (제일 중요한 논리)
가장 단순한 방법은 규칙이다: "심박이 X 이상이면 초과". 그런데 이게 잘 안 맞는다:
- **오르막**에선 힘은 이미 넘쳤는데 심박은 아직 안 올라온다(심박은 늦게 따라옴). → 규칙이 "유지"로 착각.
- **더위/피로**로 같은 페이스인데 심박만 뜬다(카디악 드리프트). → 규칙이 "초과"로 착각.
- 노이즈까지 겹친다.

즉 진짜 Zone 2 상태는 **심박 하나로는 안 되고, 여러 신호(심박·페이스·케이던스·드리프트·경사)를 복잡하게(비선형으로) 조합**해야 안다. 이 "여러 신호를 비선형으로 조합해서 답을 내는" 일을 잘하는 도구가 **신경망**이다. → 그래서 신경망을 쓴다. ("AI 과제라서"가 아니라, 규칙의 한계 때문에.)

### 2-3. 구조 (아주 단순한 신경망)
```
입력 7개  →  [32칸] → ReLU → [16칸] → ReLU → [3칸] → softmax  →  미달/유지/초과
```
- **입력 7개**: 심박(내 경계 대비 위치 2개), 심박변화율, 페이스, 케이던스, 드리프트, 경사.
- **[32칸], [16칸]**: 숫자를 섞어주는 층. 이 안의 숫자들이 "학습되는 값"이다.
- **ReLU**: "음수는 0으로" 만드는 간단한 함수. 이게 있어야 **비선형**(복잡한 조합)이 된다. 없으면 그냥 직선 규칙이랑 똑같아짐.
- **softmax**: 마지막 3칸을 **확률**(합=100%)로 바꿈. 예: 미달 5% / 유지 20% / 초과 75% → "초과"로 판정.
- 크기가 작아서(파라미터 수천 개) 폰에서 즉시 돌아간다.

### 2-4. 학습 데이터를 어떻게 만들었나 (핵심! 내가 직접 만든 부분)
**문제: 정답 라벨이 없다.** "이 순간이 진짜 Zone 2다"라는 정답은, 병원/랩에서 젖산 검사를 해야 알 수 있다. 실제 러닝 데이터를 아무리 모아도 "정답표"를 붙일 수가 없다. → 지도학습(정답 보고 배우기)을 할 수가 없다.

**해결: 물리 시뮬레이터로 "정답을 아는 가상 데이터"를 직접 만든다.** ([ml/simulator.py](simulator.py))

시뮬레이터가 하는 일:
1. **가상 러너 생성**: 나이·안정시심박·최대심박을 랜덤으로 정하고, **각자 진짜 Zone 2 경계(θ*)를 우리가 정해둔다.** (사람마다 다르게 — 공식값 0.70에서 개인차만큼 벗어나게)
2. **가상 세션(달리기) 생성**: 강도 시나리오(워밍업→구간별)를 만들고, 물리적으로 그럴듯하게:
   - 심박이 강도를 **늦게 따라감**(1차 지연) — 실제처럼 확 안 오르고 서서히.
   - 강도가 참 경계를 넘으면 **카디악 드리프트**(심박 서서히 상승), 내려오면 회복.
   - 페이스·케이던스·경사도 함께 생성.
3. **정답 라벨 붙이기**: 우리가 참 경계를 아니까, 매 순간을 미달/유지/초과로 **정확히 표시**할 수 있다.

이렇게 만들면 "특징 7개 → 정답" 짝이 **40만 개**(러너 150명 × 세션 8회) 생긴다. 이걸로 신경망을 가르친다.
- **러너 단위로 나눈다**(train/val/test): 학습에 안 쓴 "새로운 사람"으로 시험해서, 처음 보는 사람한테도 되는지 확인.

### 2-5. 학습 과정 (신경망을 실제로 가르치는 법)
```
반복(epoch) 수십 번:
  1) 신경망에 특징을 넣어 예측을 뽑는다 (순전파)
  2) 정답과 얼마나 틀렸는지 점수를 매긴다 (손실함수 = cross-entropy)
  3) "이 숫자를 어느 방향으로 바꾸면 덜 틀릴까"를 계산해서 숫자들을 조금 조정한다 (역전파 + Adam)
  4) 검증셋 점수가 더 안 오르면 멈춘다 (early stopping = 과잉 암기 방지)
```
- **손실(loss)**: 틀린 정도. 이걸 줄이는 게 목표.
- **역전파(backprop)**: "각 숫자를 어떻게 고치면 손실이 줄지"를 수학(미분)으로 알아내는 것. 활쏘기의 "왼쪽으로 빗나갔으니 오른쪽으로" 를 자동으로 하는 것.
- **Adam**: 그 조정을 똑똑하게 해주는 방법.
- 이 과정이 진짜 "딥러닝 학습"이다. (PyTorch로 오프라인에서 함)

### 2-6. 결과
| | Zone2 3분류 정확도 |
|---|---|
| 규칙(심박 임계값)만 | 0.544 |
| + 신경망(다신호) | 0.802 |
| + 개인화 | 0.828 |

- 규칙(0.544)보다 신경망이 **훨씬 잘 맞힌다(+26%p)** → "신경망이 필요했다"는 걸 숫자로 증명.
- **코칭 방향 정확성 99.6%**: 진짜 중요한 지표. "느려야 하는데 빨리 뛰라"는 **반대 방향 실수를 거의 안 한다**(0.4%). 코칭 앱엔 3분류 정답률보다 이게 훨씬 중요.

## 3. 모델 ② 개인화기 — 베이지안(Bayesian)

### 3-1. 이게 푸는 문제
사람마다 진짜 Zone 2 경계가 다르다(같은 나이라도 마라토너와 초보가 다름). **"이 사람의 진짜 경계가 몇 bpm이냐"**를 운동 데이터로 알아내야 한다. 이게 이 프로젝트의 진짜 목적("개인화").

### 3-2. 베이지안이 뭔데? (핵심 개념, 아주 쉽게)
**베이지안 = "처음엔 대충 추측하고, 증거를 볼수록 추측을 다듬어가는 방법."** 그리고 **얼마나 확신하는지(불확실성)까지 같이 들고 다닌다.**

비유: 새로 이사 온 동네의 "출근 소요시간"을 알아간다.
- 첫날 전엔 감이 없다 → "대충 30분쯤?" (넓게 불확실) ← 이게 **사전(prior)**. 우리 앱에선 **공식(HRR) 계산값**이 이 역할.
- 출근을 한 번 해보니 34분 걸렸다 → "음, 30보단 좀 더 걸리네" 하고 추측을 34 쪽으로 조금 옮긴다.
- 여러 번 다닐수록 → 추측이 실제값에 가까워지고, **점점 확신**이 생긴다(범위가 좁아짐).
- 근데 어느 날 사고로 60분 걸렸다 → 이건 이상치니까 크게 안 흔들린다(이미 확신이 쌓여서).

이게 정확히 우리 개인화기가 하는 일이다.

### 3-3. 구체적으로 (숫자로)
- 개인 경계를 **분포**로 들고 있다: `경계 ~ 정규분포(평균 μ, 불확실성 σ)`.
  - μ = 지금 최선의 추측(bpm), σ = 얼마나 확신하는지(작을수록 확신).
- **처음(prior)**: μ = 공식(HRR) 계산값, σ = 크게(잘 모름).
- **세션 끝날 때마다(학습)**: 그 세션에서 "이 사람 경계는 이쯤이다"라는 관측 z를 뽑아, 아래 공식으로 μ와 σ를 갱신:
  ```
  새 μ = (기존 μ와 관측 z를, 각자의 확신도로 가중평균)
  새 σ = (관측을 반영해 더 좁아짐 = 확신 증가)
  ```
  = 저울질이다. 기존 추측과 새 증거를 "누가 더 믿을 만한가"로 섞는다. (이게 켤레 가우시안/칼만 필터라는 기법)

### 3-4. 왜 여기엔 신경망을 안 쓰나
- **데이터가 너무 적다**: 한 사람 세션은 5~30번뿐. 신경망은 수천 개가 필요. → 개인마다 신경망 학습은 불가능.
- **정답이 없다**: 여기도 진짜 경계 정답표가 없다.
- **콜드스타트**: 신규 유저는 데이터 0인데, 베이지안은 "공식값"에서 시작하니 첫날부터 동작.
- 그래서 **가볍고, 적은 데이터로도 되고, 불확실성을 다루는** 베이지안이 딱 맞다. (신경망이 틀린 도구인 경우)

### 3-5. "학습은 언제 하나?"
- 판정기(신경망)는 **한 번 학습하고 고정** → 폰에선 추론만.
- 개인화기(베이지안)는 **런타임에 세션마다** μ, σ를 갱신 → 이게 "지속적 개인 학습". (신경망 재학습이 아니라 숫자 몇 개 산술 갱신이라 폰에서 가볍게 됨)

### 3-6. 결과와 한계 (정직하게)
- **메커니즘은 검증됨**: 관측이 괜찮으면 세션이 쌓일수록 추정이 참값으로 수렴(오차 5→2 bpm, 확신 σ 8→2). → 개인화가 실제로 작동함(QA3).
- **진짜 어려운 부분(한계)**: "세션에서 그 사람 경계 관측 z를 뽑아내는 것"이 어렵다. 우리는 카디악 드리프트로 뽑는데, 이게 실제 임계보다 높게 잡히는 편향이 있다(스포츠과학의 Conconi 편향과 동일). → 이게 개인화의 남은 숙제. (베이지안 갱신 자체는 문제 없음)

## 4. 둘이 어떻게 협력하나

```
[베이지안 개인화기]  세션마다 "이 사람 경계(μ)"를 갱신
        │  (개인 경계를 알려줌)
        ▼
[신경망 판정기]  심박을 "그 사람 경계 기준"으로 정규화해서 입력 → 미달/유지/초과
        │
        ▼
   코칭 방향 결정
```
- 개인화기가 "그 사람 기준자"를 만들어주고,
- 판정기가 그 기준자로 "지금"을 판단한다.
- 여기에 **규칙**이 안전장치로 깔린다: 데이터 없을 때(콜드스타트)는 공식으로, 이상치는 걸러내고, 생리 안전범위를 벗어나면 규칙이 바로잡는다.

## 5. "내가 직접 한 것처럼" 설명하는 3단 요약

누가 물으면 이렇게 말하면 된다:

1. **"Zone 2 판정은 정답 라벨이 없어서, 운동생리학 공식으로 물리 시뮬레이터를 만들어 정답이 붙은 학습 데이터를 생성했습니다."**
2. **"그 데이터로 다변량 신호(심박·페이스·드리프트·경사)를 조합하는 경량 신경망(MLP)을 PyTorch로 학습시켰고, 단순 심박 규칙(0.54)보다 정확도를 0.80까지 올렸습니다. 코칭에 중요한 '방향 정확성'은 99.6%입니다."**
3. **"사람마다 다른 Zone 2 경계는, 데이터가 적고 정답이 없는 문제라 신경망 대신 베이지안 온라인 추정을 썼습니다. 공식값을 사전분포로 시작해 세션마다 갱신하면서 개인 경계로 수렴시킵니다."**

그리고 한 마디 더:
> **"핵심은 '올바른 도구를 골랐다'는 겁니다 — 무거운 딥러닝이 필요한 곳(다신호 판정)엔 신경망을, 데이터가 적고 불확실한 곳(개인화)엔 베이지안을 썼습니다."**
