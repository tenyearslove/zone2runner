# Zone 2 판정 모델 — 구현 및 튜닝 로그

Zone 2 판정 개인화 AI의 PoC 개발 기록. 목표 달성을 위해 어떤 설계를 적용하고
어떤 진단으로 튜닝했는지의 과정 기록이다. (보고서 "구현 및 검증" 섹션 근거)

작성: 2026-07-02 / 대응 문서: adr-005(DP4), adr-004(DP3), spec-006, spec-004

---

## 1. 목표

- Zone 2 판정 정확도 85% (과제계획서 지표)
- 코칭 방향 정확성 95% (QA1), 이상값 강건성 (QA2)
- 라벨(정답)이 없는 문제 → 물리 시뮬레이터로 라벨 생성 후 지도학습

## 2. 적용한 설계 (접근)

| 설계 | 내용 | 근거 |
|------|------|------|
| 물리 시뮬레이터 | 참 경계 θ*를 아는 가상 러너 세션 생성 → (특징, 참 라벨) | 라벨 확보(랩 검사 불가) |
| 러너 단위 분할 | train/val/test를 러너 단위로 분리 | 데이터 누수 방지 |
| 규칙 baseline | 공식(HRR) 임계값 판정 | 비교 기준 + 콜드스타트 폴백 |
| 다변량 MLP (DP4) | 7특징 → 32 → 16 → 3분류 | 단일 HR 임계값의 비선형 한계 극복 |
| 개인화 정규화 (DP3) | HR을 개인 상/하한 경계로 정규화해 입력 | 개인차 반영(QA3) |
| 이상치 필터 | 생리범위(40~220) 밖 값 기각 | 강건성(QA2) |

## 3. 튜닝 이터레이션 (진단 기반)

각 단계는 "문제 → 가설 → 조치 → 결과 → 진단"으로 진행했다. (수치는 test 정확도)

| # | 조치 | 3분류 정확도 | 진단/다음 가설 |
|:-:|------|:---:|------|
| 0 | 초기: 6특징(공식 정규화, 순간값) + MLP | MLP 0.70 / 규칙 0.53 | 85% 미달. HR 지연으로 순간 라벨이 모호할 것 |
| 1 | 라벨을 지속 강도(이동평균) 기준으로 | 0.69 | 변화 없음 → 천장은 라벨 스무딩이 아님 |
| 2 | HR을 개인 경계로 정규화(개인화) + 추정오차 민감도 | 0.69 (완벽 개인화도 0.69) | **개인화가 안 먹힘.** 경계 지식이 병목 아님 |
| 3 | HR/페이스를 지속(윈도우 평균) 특징으로 | 0.69 | 여전. 다른 원인 의심 → 시뮬레이터 점검 |
| 4 | **Cardiac Drift 현실화** (반감기 11분 → 시상수 2~3분 회복) | 규칙 0.49 → MLP 0.73 → 개인화 0.74 | **핵심 수정.** 드리프트 잔류가 HR을 현재 강도와 계속 어긋나게 했음. 이제 개인화가 +기여 |
| 5 | **하한도 개인화**(7번째 특징 hr_norm_l) | 0.74 | below↔in 혼동이 최대였음(상한만 개인화했던 탓). 하한 개인화로 완화 |
| 6 | 방향 정확성 지표 추가(튜닝 아님, 평가 관점) | — | 반대방향 오판 0.5% → 방향 정확성 0.996 |
| 7 | **센서 노이즈 제거**(프로젝트 범위 밖) + QA2를 이상치 필터로 재정의, 평가지표를 코칭 방향으로 확정 | **0.83** | 센서 측정노이즈는 센서 소관. 판정은 실측 정답 없음 → QA는 코칭 방향 정확성으로 측정. 노이즈 제거로 개인화 기여도 뚜렷(+5%p) |

### 결정적 진단 2가지
- **완벽 개인화 프로브**(추정오차=0)로도 정확도가 안 오름(#2) → 병목이 "개인 경계를 모르는 것"이
  아니라 "관측 HR이 강도와 어긋난 것"임을 특정 → 시뮬레이터 드리프트 모델 수정(#4)으로 해결.
- **혼동행렬**에서 below↔in이 지배적 → 상한만 개인화한 게 원인으로 특정 → 하한 개인화(#5).

## 5. 결론 및 해석

- **두 QA가 모두 목표 만족**: QA1 코칭 방향 정확성 0.996(≥0.95), QA2 이상치 기각 1.000.
- **각 설계 결정이 정량 기여**: 규칙 0.485 → +MLP(DP4) 0.780 → +개인화(DP3) 0.826. NN 도입과 개인화의 정당성 실증.
- **평가 관점(중요)**: Zone2 판정은 실측 정답(ground truth)이 없어 판정 자체의 정확도로 QA를 평가할 수 없다.
  따라서 QA1은 "현재 심박 수치 대비 코칭 방향이 맞는가"로 측정한다. 3분류 정확도(0.826)는 개발용 내부 지표일 뿐.
- **센서 노이즈는 프로젝트 범위 밖**(센서 하드웨어 소관)이라 제외. QA2 강건성은 생리범위 밖 이상치 필터링으로 달성.
