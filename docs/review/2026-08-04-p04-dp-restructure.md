# p.4~p.9 피드백 반영 및 DP 재편 기록

## 이번 결정

- 제출 HTML의 DP는 중요도 순으로 `DP1 기능적응성 → DP2 설명용이성 → DP3 제어가능성`만 사용한다.
- 기존 DP4 강건성과 DP5 테스트가능성 전용 페이지는 제출 HTML에서 삭제했다.
- QA4 강건성과 QA5 테스트가능성 자체는 삭제하지 않았다. QA4는 세 DP를 받치는 지원 품질, QA5는 입력 교체와 시드 기반 시뮬레이션을 요구하는 ASR로 유지한다.
- 따라서 최종 기준은 `QAS 5개 / ASR 4개(QA1·QA2·QA3·QA5) / 전용 DP 3개`다.

## QAS 표 작성 원칙

- 샘플 양식과 같이 `ID / QA / 내용 / 시나리오 / 중요도 / 난이도` 열을 사용한다.
- 시나리오 안에서 사용자 또는 입력 상황, 시스템 응답, 성공 기준을 문장으로 적는다.
- 성공 기준은 별도 줄의 파란색 `[측정]` 문장으로 분리한다.
- `3/3`, `5/5`만 단독으로 쓰지 않고 `3개 중 3개`, `시험 문장 5개 모두`처럼 시험 수와 의미를 함께 쓴다.
- 검증 표에서도 같은 시나리오와 측정 기준을 반복하고 실제 결과를 오른쪽에 적는다.

## 시드 재현 판단

- 기존 `RunSimulatorTest`, `VirtualRunnerTest`에는 같은 시드로 같은 입력이 만들어지는 자동시험이 있었다.
- 기존 시뮬레이션 화면은 실행할 때 `System.nanoTime()`을 사용해 사용자가 같은 시드를 다시 지정할 수 없었다.
- `RunActivity`에 재현 시드 입력 UI를 추가하고 자동·수동 페이스·수동 러너가 같은 시드를 사용하도록 수정했다.
- 문서에서는 `같은 가상 러너·설정·시드`를 모두 선택해야 같은 입력을 재현할 수 있다고 범위를 제한했다.

## Zone 2 유행 배경 표현 원칙

- 스마트워치와 슬로우 조깅의 확산으로 Zone 2가 주목받는 배경은 소개한다.
- 체지방 관리에 도움이 될 수 있다는 점은 쓰되, 장기 감량은 전체 운동량과 식습관의 영향을 함께 받는다고 적는다.
- 초보자와 고령자가 접근하기 쉬운 강도라는 장점은 소개한다.
- 관절 부담과 부상이 항상 줄어든다고 단정하지 않는다. 느린 달리기는 한 걸음의 부하는 줄 수 있지만 같은 거리의 누적 부하는 늘 수 있다.
- 슬로우 조깅과 Zone 2는 겹칠 수 있지만 같은 뜻은 아니다.

## 용어와 문장

- `참값`은 제출 HTML과 사용 그림에서 `실험실 기준값`, `측정 정답`, `설정한 목표 경계`처럼 문맥에 맞는 쉬운 말로 바꾼다.
- `회복 심박`은 `운동을 멈춘 뒤 심박이 내려오는 정도`, `경사 보정 페이스`는 `경사의 영향을 평지 기준 속도로 바꾼 값`으로 처음 나올 때 설명한다.
- `더 큰 모델`은 대상을 알기 어려워 `새로운 신경망 모델을 개발하는 데 있지 않다`로 바꿨다.
- ML 판정과 개인화 경계의 충돌은 두 기준이 같은 심박을 다르게 해석할 수 있다는 뜻으로 구체화했다.
