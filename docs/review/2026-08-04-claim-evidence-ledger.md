# Zone2Runner 주장-근거 대장

- 작성일: 2026-08-04
- 목적: 인증 보고서의 주장을 구현/테스트/측정 근거와 연결하고, 증명 범위를 넘는 표현을 차단한다.
- 적용 대상: `report/`, `docs/src/`, 최종 PDF, 발표 대본
- 검증 기준 실행: `:app:testDebugUnitTest --no-daemon --rerun-tasks`, 153/153 통과

## 1. 증거 수준

| 수준 | 의미 | 보고서에서 허용하는 표현 |
|---|---|---|
| E1 코드 구조 | 호출 관계, 상수, 인터페이스가 소스에 존재 | 구현했다, 구조적으로 분리했다 |
| E2 자동 테스트 | 결정론적 규칙과 지정 사례를 JVM에서 재실행 | 지정한 테스트 집합에서 통과했다 |
| E3 시뮬레이션 | 합성 입력/가상 참값으로 메커니즘을 반복 실행 | 시뮬 조건에서 동작/수렴했다 |
| E4 실기기 측정 | 실제 폰/워치에서 시간, 연결, 화면, LLM 실행을 측정 | 해당 기기와 조건에서 실측했다 |
| E5 사용자/임상 평가 | 실제 사용자 또는 기준 장비와 비교 | 사용자가 이해했다, 생리적으로 정확했다 |

상위 수준이 자동으로 하위 수준을 대체하지 않는다. 특히 E2/E3 결과를 E4/E5 결과로 확대하지 않는다.

## 3. QA 측정 대장

### QA1 설명용이성

- 재현값: 지어낸 숫자 5/5 기각, 사실 숫자/무숫자 문장 3/3 통과.
- 추가 근거: LlmCallLog/SessionCodec/NumberGuard 관련 테스트.
- 말할 수 있는 것: 지정한 아라비아 숫자 사례에서 입력 사실에 없는 숫자가 출력되지 않도록 검사한다.
- 말할 수 없는 것: 설명 전체가 사실이다, 사용자가 설명을 이해한다, 모든 우회 표현을 차단한다.
- 본문 판정: `부분 달성(E2)`. 숫자 무결성은 달성, 사용자 이해도와 의미 충실도는 후속 평가.

### QA2 기능적응성

- 기준 사례: 초기 오차 12.9bpm, 8세션 후 1.73bpm, 1세션째 3bpm 이내 안착.
- 안정성 지표: 마지막 4세션 경계 진동폭 **3.04bpm**.
- 스윕: 참임계 5종 x 시드 3종, 15케이스 모두 1~2세션 안착, 최종 오차 0.20~0.77bpm.
- 오답 라벨 10%: 참임계 141/시드 42 단일 사례에서 최종 0.09bpm.
- 말할 수 있는 것: 정해진 합성 라벨 모델에서 베이지안 갱신과 이동 클램프가 수렴/안정한다.
- 말할 수 없는 것: 실제 사용자의 경계가 1~2세션에 3bpm 이내로 정확해진다.
- 수정 필요: 기존의 `수렴 후 0.49~1.73bpm 진동`은 진동폭이 아니라 세션별 오차 범위다. 안정성은 3.04bpm으로 고친다. 오답 10% 결과는 단일 시드 예시로만 두거나 다중 시드 통계 전까지 본문에서 제외한다.
- 본문 판정: `시뮬레이션 달성(E3), 실사용 미검증`.

### QA3 제어가능성

- 재현값: 방향위반/무방향 10/10 기각, 정상 방향 5/5 통과.
- 경계 이동: QA2 기준 사례에서 세션당 최대 9.97bpm, 설계 한도 10bpm 이내.
- 말할 수 있는 것: 지정 사례와 경계 이동 규칙에서 자동 통제 장치가 작동한다.
- 말할 수 없는 것: 모든 자연어 방향 위반을 100% 차단한다.
- 본문 판정: `지정 통제 시나리오 달성(E2)`.

### QA4 강건성

- 이상치: 50/50 기각, 정상 500건 오탐 0, 40/220 유효와 39/221 기각 확인.
- 경계 진동: 300초 x 시드 5종에서 번복 67.1~74.7% 억제.
- 실제 변화: +10bpm 점프를 1틱에 전환.
- 말할 수 있는 것: 합성한 이상치/진동/점프 조건에서 노이즈 억제와 반응성의 균형을 확인했다.
- 말할 수 없는 것: 모든 손목 PPG/GPS 악조건에서 판정 정확도가 유지된다.
- 본문 판정: `시뮬레이션 달성(E3), 실센서 미검증`.

### QA5 테스트가능성

- 2026-08-04 강제 재실행: 29스위트/153테스트, 실패 0, 오류 0, 건너뜀 0.
- RunSource: 실센서 1종 + 시뮬 4종. QA 측정 파일 7개 재생성.
- 말할 수 있는 것: 기기 없는 JVM에서 결정 로직과 시뮬 시나리오를 재현한다.
- 말할 수 없는 것: 테스트 개수가 제품 정확도나 충분한 커버리지를 보장한다.
- 본문 판정: `달성(E2/E3)`.

### QA6 수행효율성

- 2026-08-04 재현값: 3600틱 176ms, 평균 **0.049ms/틱**, 1Hz 주기의 0.0049%.
- 기존 보고서: 실행별 0.06~0.08ms, 대표 약 0.07ms.
- 해석: 실행 환경과 JVM 상태에 따라 달라지는 마이크로벤치마크다. 정확한 대표값 하나보다 `JVM에서 0.1ms/틱 미만`으로 보고한다.
- 말할 수 있는 것: 현재 JVM 측정에서 순수 로직은 1Hz 예산의 병목이 아니다.
- 말할 수 없는 것: 실제 폰 UI, 워치 통신, Nano, TTS를 포함해 5초 이내다.
- 본문 판정: `로직 예산 달성(E2), 실기기 종단 지연 미검증`.

## 5. 최종 보고서 작성 규칙

1. 모든 정량 결과 옆에 `환경/표본/증거 수준`을 붙인다.
2. 달성 표시는 `달성`, `시뮬레이션 달성`, `부분 달성`, `미측정`으로 나눈다.
3. 100%라는 표현에는 항상 분모를 쓴다.
4. 시뮬레이션의 참임계는 검증 도구가 정의한 값이며 실제 사람의 생리 참값이 아님을 첫 등장에 밝힌다.
5. 의료적 정확성/안전, 사용자 이해도, 실기기 종단 성능은 E4/E5 증거 전까지 성과로 확정하지 않는다.
