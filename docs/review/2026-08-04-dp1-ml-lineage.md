# DP1 ML 시도 계보와 설계 전환 근거

- 작성일: 2026-08-04
- 목적: DP1을 고칠 때 서로 다른 ML 시도와 실패 원인을 한 이야기로 섞지 않도록 실제 개발 순서를 고정한다.
- 적용 범위: 제출 HTML의 DP1, QA1 QAS, DP1 대안 다이어그램과 발표 대본

## 1. 먼저 내린 결론

Zone2Runner는 ML을 검토만 하고 피한 프로젝트가 아니다. 판정과 개인화, 심박 예측에 ML을 직접 적용하고 여러 차례 학습·평가했다. 그러나 합성 데이터에서 좋아 보인 점수가 실제 사용자에게 맞는다는 근거가 되지 못했고, 일부 평가는 시뮬레이터가 만든 답을 같은 시뮬레이터 데이터로 맞히는 자기참조였다.

따라서 최종 결정은 “규칙이 ML보다 항상 우수하다”가 아니다.

> 현재 확보할 수 있는 데이터와 참값으로는 ML 판단의 유효성을 입증하기 어렵다. 그래서 판정은 근거를 직접 추적할 수 있는 규칙·관측 통계에 두고, 개인화는 사용자가 직접 주는 말하기 테스트 응답으로 제한해 갱신한다. 실제 사용자 데이터가 쌓이면 작은 잔차 모델은 다시 검토할 수 있다.

설명용이성은 ML 실패를 포장하는 사후 명분이 아니다. 데이터와 검증의 한계를 확인한 뒤 대안을 고를 때 사용한 핵심 평가 기준이다.

## 2. 실제 개발 계보

|---|---|---|---|---|
| 1 | 다변량 Zone 판정 MLP | 합성 러너 데이터로 학습하고 규칙 기준과 비교했다. 합성 시험에서는 3분류 정확도 약 0.83, 코칭 방향 일치율 0.996이 나왔다. | 실기기에서 지속 심박이 상한을 크게 넘었는데도 ‘미달’로 판정했다. 합성 라벨과 평가가 같은 시뮬레이터 정의에 기대어 점수가 실제 판정 타당성을 보이지 못했다. 개인화 경계와 MLP 판정이라는 두 기준도 서로 충돌했다. | 판정 MLP를 폐기했다. 판정은 지속 심박과 개인 경계를 직접 비교하는 규칙과 히스테리시스로 바꿨다. |

## 3. DP1에서 비교할 두 안

DP1의 비교 대상은 실제 이력을 대표해야 한다.

### 1안 — 투명한 규칙·관측 통계 + 사용자 응답 개인화

- 판정은 현재 값과 개인 경계를 직접 비교한다.
- 분석은 실제로 관측한 값에서 계산한다.
- 개인 경계는 말하기 테스트 응답으로 조금씩 조정한다.
- 판단에 사용한 값과 변경 이유를 그대로 기록할 수 있다.

### 2안 — 합성·공개 데이터로 학습한 ML 판단 + 사후 설명

- 여러 센서 특징을 학습해 판정이나 개인 경계를 직접 출력한다.
- 실제 데이터가 충분하면 규칙에 없는 비선형 관계를 찾을 가능성이 있다.
- 현재 조건에서는 학습 라벨과 평가 기준이 합성 데이터에 의존한다.
- 실제 사용자에게 맞는지 확인할 참값이 없고, 설명은 모델 밖에서 다시 근사해야 한다.

2안은 허수아비가 아니다. 프로젝트가 실제로 여러 형태로 구현하거나 검토한 길이다. 다만 판정 MLP, 역치 MLP, 심박 예측 MLP를 하나의 동일한 모델처럼 쓰지는 않는다. 각각에서 반복해서 드러난 데이터·라벨·검증 문제를 대표하는 대안으로 설명한다.

## 4. DP1의 결정 논리

결정 이유의 우선순위는 다음과 같다.

1. **검증할 참값이 없다.** 합성 라벨을 잘 맞힌 점수로 실제 사람의 판정 정확도를 주장할 수 없다.
2. **목표 사용자 데이터가 없다.** 공개 데이터가 있어도 이 사용자의 Zone 2 경계와 같은 문제인지 확인하기 어렵다.
3. **두 기준의 충돌을 없애야 한다.** 개인화 경계와 별도 ML 판정기가 서로 다른 답을 내지 않도록 하나의 투명한 기준을 사용한다.
4. **판단 근거를 추적해야 한다.** 심박, 경계, 사용자 응답과 판정의 연결을 그대로 확인할 수 있어야 한다.
5. **향후 확장 가능성은 남긴다.** 실제 데이터가 확보되면 공식 위의 작은 잔차 모델을 다시 검토할 수 있다.

설명용이성은 3번과 4번을 평가하는 품질이다. 데이터 부족만으로 규칙을 자동 선택한 것이 아니라, 현재 검증 가능한 대안 가운데 근거가 드러나는 구조를 선택한 것이다.

## 5. QA1 검증 범위

현재 QA1을 ‘LLM 숫자 가드’ 하나로 설명하면 DP1 전체와 맞지 않는다. 검증을 다음 세 층으로 나눈다.

1. **판단 근거 구성**: 대표 코칭 사례에서 판정, 지속 심박, 개인 경계, 경사, 페이스 등 실제 입력 사실이 근거에 포함되고 모르는 값은 생략되는지 확인한다.
2. **개인화 근거 구성**: 초기 경계와 현재 경계의 이동 방향이 말하기 테스트 응답과 맞는지 확인한다.
3. **표현의 사실 무결성**: LLM 문장에 허용되지 않은 숫자가 있으면 막고, 실제 사실만 사용한 문장은 통과시키는지 확인한다.

이 자동시험은 설명의 사실 충실성과 추적 구조를 확인한다. 실제 사용자가 설명을 쉽게 이해하는지는 별도의 사용자 평가가 필요하다.
