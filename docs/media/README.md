# 보고서 화면 자료

2026년 8월 6일 연결된 실기기에서 촬영한 Zone2Runner 화면 자료다.

- 폰: Samsung SM-S942B, 1080×2340
- 워치: Samsung SM-L330, 480×480
- 러닝 입력: 시드 42의 앱 시뮬레이션
- 워치 화면: 폰 시뮬레이션을 받은 미러 모드
- 영상 길이: 폰 15초, 워치 12초

시뮬레이션은 화면 흐름과 시스템 처리 구조를 재현하기 위한 것이다. 화면에 보이는 심박·경로·세션 횟수는 실제 사용자의 생리 데이터나 실외 주행 성능을 뜻하지 않는다.

`screens/`에는 보고서에서 선별해 사용하는 원본 스크린샷을 보관한다. `docs/build.py`와 `docs/build.ps1`은 `docs/src/decks.json`의 대응표에 따라 이 파일을 `docs/img/`로 복사한다. 두 MP4는 HTML 보고서가 `docs/media/`에서 직접 참조한다.
