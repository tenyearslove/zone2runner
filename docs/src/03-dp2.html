ML 대안을 직접 구현해 확인한 결과와 최종 운영 구조를 선택한 기준을 설명한다.

DP2. ML 대안을 검토하고 최종 구조를 선택한 과정

3

1.초기에는 ML의 적용 가능성을 검토했다

  • 가상 러너로 학습 데이터를 만들어 Zone 판정, 개인 경계 추정, 30~60초 뒤 심박 예측에 작은 신경망을 적용했다.
  • 시뮬레이션에서는 좋은 점수가 나왔지만, 실제 기기에서는 시뮬레이션 결과와 맞지 않는 사례가 확인됐다.
  • 모델이 합성 데이터의 생성 규칙을 잘 재현하더라도 실제 사용자에게 적합한 판단을 내린다고 볼 수는 없었다.

2.실제 판정에 적용하려면 검증 근거가 필요했다

  • 학습할 실제 데이터가 부족했다. 개인별 Zone 2 경계와 미래 심박을 함께 기록한 데이터가 없었다.
  • 출력을 비교할 기준값이 없었다. 실험실 장비로 측정한 유산소 역치가 없어 ML의 출력이 실제 상태와 맞는지 검증할 수 없었다.
  • 개인화 경계와 ML 판정이 충돌할 수 있었다. 앱은 말하기 테스트로 Zone 2 상한을 조정하지만, 별도 ML 판정기는 합성 데이터에서 학습한 기준으로 심박을 Zone 2 아래·범위 안·위로 구분한다. 같은 심박을 두 기준이 다르게 해석하면 어느 결과를 따라야 하는지 설명하기 어렵다.
  • 따라서 ML은 향후 검토할 대안으로 남겨 두고, 현재 확보한 데이터로 판단 근거를 설명하고 반복 검증할 수 있는 구조를 선택해야 했다.

DP2. 설계 결정과 검증

3

1.최종 결정

현재 데이터와 운영 조건에서는 1안인 ‘투명한 규칙·관측 통계와 사용자 응답’ 구조를 채택했다.

2.결정 근거

  1. QA1 설명용이성: 판정 결과, 심박, 개인 경계와 경계 변경 이유를 하나의 근거 기록에 남긴다. 설명은 이 기록을 사용하므로 판정 이유를 사후에 다시 추정하지 않는다.
  2. QA5 테스트가능성: 입력, 판정, 근거 기록이 분리되어 있어 같은 입력에서 세 결과가 일치하는지 반복 확인할 수 있다. 2안은 데이터 구성부터 학습과 배포까지 같은 조건으로 재현해야 한다.
  3. Tradeoff: 현재 데이터로 검증할 수 있는 규칙과 기록 구조를 선택했다. 실제 러닝 데이터와 비교 기준이 확보되면 규칙이 놓친 오차를 보정하는 작은 모델부터 다시 검토한다.

3.검증 결과

QA1: Zone 2 아래·범위 안·위의 판정에서 사용한 심박, 개인 경계와 판정 결과를 모두 기록했다. 대표 판정 근거의 기록률은 100%였다.

QA5: 같은 입력에서는 판정과 근거 기록을 반복 비교할 수 있게 구성했다.

이는 미리 정한 입력에서 판단 근거가 연결되고 반복 확인됨을 검증한 결과다. 실제 Zone 2의 생리학적 정확도나 사용자가 설명을 이해하는 정도까지 확인한 것은 아니다.

4.보완 계획

  • 단기 개선안: 판정·개인화·코칭 화면에서 같은 용어와 숫자를 사용하는지 확인하는 시험 사례를 확대한다.
  • 장기 개선안: 실제 사용자 데이터와 비교 기준을 확보할 수 있다면 규칙이 놓친 오차만 보정하는 작은 모델을 다시 검토한다.
