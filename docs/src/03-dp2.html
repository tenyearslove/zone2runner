DP2. ML 대안을 검토하고 운영 구조를 선택한 과정

3

1.초기에는 ML의 적용 가능성을 검토했다

  • 가상 러너로 학습 데이터를 만들어 Zone 판정, 개인 경계 추정, 30~60초 뒤 심박 예측에 작은 신경망을 적용했다.
  • 시뮬레이션에서는 좋은 점수가 나왔지만, 실제 기기에서는 시뮬레이션 결과와 맞지 않는 사례가 확인됐다.
  • 모델이 합성 데이터를 만든 규칙을 잘 따라 하더라도, 실제 사람에게 맞는 판단을 내린다고 볼 수는 없었다.

2.실제 판정에 적용하려면 검증 근거가 필요했다

  • 학습할 실제 데이터가 부족했다. 개인별 Zone 2 경계와 미래 심박을 함께 기록한 데이터가 없었다.
  • 정답을 확인하기 어려웠다. 실험실 장비로 측정한 유산소 역치가 없어 ML의 출력이 맞는지 검증할 수 없었다.
  • 개인화 경계와 ML 판정이 충돌할 수 있었다. 앱은 말하기 테스트로 Zone 2 상한을 조정하지만, 별도 ML 판정기는 합성 데이터에서 배운 기준으로 아래·범위 안·위를 정한다. 같은 심박을 두 기준이 다르게 해석하면 어느 결과를 따라야 하는지 설명하기 어렵다.
  • 따라서 이번 과제에서는 ML의 가능성과 별개로, 현재 확보한 데이터만으로도 판단 근거를 설명하고 반복 검증할 수 있는 구조를 최종 구조로 선택해야 했다.

DP2. 설계 결정과 검증

3

1.최종 결정

이번 과제에서는 1안인 ‘투명한 규칙·관측 통계와 사용자 응답’ 구조를 채택했다.

2.결정 근거

  1. 현재 데이터만으로는 ML 판정을 실제 기능에 적용할 만큼 타당성을 입증하기 어려웠다. 합성 데이터 점수만으로 사람의 Zone 2 판정이 정확하다고 주장하지 않는다.
  2. 판정 기준을 하나로 모았다. 모든 판정과 설명에서 현재 심박과 말하기 테스트로 조정한 개인 경계를 함께 사용한다.
  3. 판단 근거를 설명까지 그대로 이어 쓴다. 판정, 심박, 개인 경계, 경계가 바뀐 이유를 하나의 기록에 남긴다. 설명을 나중에 추측해 붙이지 않는다.
  4. 나중에 ML을 다시 검토할 길은 남겼다. 실제 러닝 데이터가 충분히 쌓이면, 전체 판단을 바꾸기보다 규칙이 놓친 오차만 보정하는 작은 모델부터 검증할 수 있다.

3.이번 과제에서 확인한 범위

  • Zone 2 아래·범위 안·위의 판정에 사용한 심박과 개인 경계를 모두 기록해 판정 근거 기록률 100%를 확인했다.
  • 근거에 없는 숫자가 포함된 시험 문장 5개를 모두 차단해 근거 없는 숫자 표시율 0%를 확인했다.

이 결과는 설명이 실제 내부 판단의 근거와 연결돼 있음을 확인한 것이다. 실제 Zone 2의 생리학적 정확도나 사용자가 느끼는 이해도까지 증명한 것은 아니다.
