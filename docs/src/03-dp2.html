DP2. 설명용이성 — 판단에 사용한 근거를 그대로 설명하는 구조

판정의 근거를 직접 기록하는 방법과, ML 판정 뒤에 이유를 다시 추정하는 방법을 비교한다.

DP2. 설계 문제 정의

3

1.배경

  • 사용자는 러닝이 끝난 뒤 리포트와 개인화 화면에서 왜 해당 Zone으로 판정됐고 어떤 근거로 코칭했는지 확인할 수 있어야 한다.
  • 초기 개발에서는 가상 입력으로 학습한 작은 신경망을 Zone 판정, 개인 경계 추정과 이후 심박 예측에 적용하는 방안을 검토했다.
  • 그러나 합성 조건의 평가 결과만으로는 모델이 실제 사용자의 상태를 올바르게 판단하는지 확인할 수 없었다. 자연스러운 설명을 덧붙이는 것만으로도 모델이 실제로 사용한 근거를 보여 줄 수는 없었다.

2.문제점

  • 모델 출력을 비교할 실제 기준값이 부족하다. 개인별 유산소 역치와 이후 심박을 함께 기록한 실제 데이터가 없어 합성 데이터의 평가 점수를 실제 정확도로 해석할 수 없다.
  • 두 판정 기준이 충돌할 수 있다. 말하기 응답으로 조정한 개인 경계와 별도로 학습한 Zone 판정기가 같은 심박을 다르게 해석하면 어느 결과를 따라야 하는지 설명하기 어렵다.
  • 판정 뒤에 만든 설명은 실제 판단 근거와 다를 수 있다. 입력과 결과만 보고 이유를 다시 추정하면 모델 내부에서 무엇이 결정에 영향을 줬는지 확인하기 어렵다.
  • 판정·개인화·코칭이 같은 사실을 사용해야 한다. 설명을 위한 별도 추측이 아니라, 각 기능이 실제로 사용한 심박·개인 경계·판정 결과와 처리 경로를 남길 구조가 필요하다.

구조
  • 판정과 근거 확정: 정제한 심박과 개인 경계를 직접 비교해 Zone과 판정에 사용한 값을 함께 확정한다.
  • 같은 사실 공유: 설명·분석·운영 서비스는 판정을 다시 해석하지 않고, 확정된 사실과 생성 경로를 전달받아 기록한다.
  • 표현만 위임: LLM은 전달받은 사실을 문장으로 표현하지만 Zone 판정이나 근거값은 변경하지 않는다.
  • 모델 개발: 수집한 데이터로 ML을 학습·검증하고, 검증을 통과한 모델을 추론 서비스에 배포한다.
  • ML 판정: 배포된 모델이 프로필과 운동 정보를 입력받아 Zone을 판정하거나 개인 경계와 이후 심박을 예측한다.
  • 사후 설명: 설명 서비스는 판정 뒤에 입력과 결과를 분석해 이유를 다시 추정한다. 설명이 실제 판단 근거와 같은지는 별도로 확인해야 한다.

2.채택 근거

  • QA1 설명용이성: 판정 결과, 심박, 개인 경계와 문장 생성 경로를 하나의 근거 기록으로 연결한다. 설명은 이 기록을 사용하므로 판정 이유를 사후에 다시 추정하지 않는다.
  • QA5 테스트가능성: 같은 입력에서 판정 결과와 근거 기록이 함께 만들어지는지 반복 확인할 수 있다. 2안은 데이터 구성부터 학습·배포와 설명까지 같은 조건으로 재현해야 한다.
  • Tradeoff: 현재 확보한 근거로 판정과 설명의 연결을 검증할 수 있는 대신, 규칙이 놓친 복잡한 관계는 자동으로 학습하지 못한다.
