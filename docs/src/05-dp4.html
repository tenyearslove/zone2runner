DP4. 설계 문제 정의

3

1.배경

  • 이 앱에 들어오는 신호는 깨끗하지 않다. 손목 광학 심박계는 달리는 중 팔 흔들림으로 값이 튀는 것이 알려진 한계이고, GPS도 잡음이 섞이며, 연결이 잠깐 끊기기도 한다.
  • 판정 결과는 화면 표시로 끝나지 않고 "속도를 줄이세요" 같은 행동 지시로 이어진다. 튄 값 하나가 지시가 되면 사용자는 노이즈에 맞춰 달리게 된다.
  • 그래서 노이즈가 일상인 신호에서 판정과 지시를 지키는 구조를 고르는 것이 이 설계 결정이다.

2.문제점

  • 오판의 비용이 비대칭이다. 판정이 조금 늦는 것보다, 튄 값으로 잘못된 지시를 내보내는 것이 더 나쁘다.
  • 경계 근처에서 판정이 깜빡인다. 심박이 경계를 오르내리면 순간값 판정은 초 단위로 뒤집혀 신뢰를 잃는다.
  • 노이즈 폭이 사람마다 다르다. 고정된 필터 하나로 모두를 맞출 수 없다.
  • 실제 센서의 정답지가 없다. 이번 과제에서는 기준 장비와 비교하지 않는다. 따라서 강건성은 정해 둔 이상값을 차단하고 경계 부근의 불필요한 판정 번복을 줄이는지로 평가한다.

DP4. 설계결정 및 근거

3

1.최종 채택 구조

후보 1: 계층 방어 판정 아키텍처 채택

2.채택 근거

  • 오판의 비용이 비대칭이다. 코칭은 행동 지시라 잘못된 지시가 늦은 지시보다 비싸다. 표시(빠름)와 코칭(엄격)의 기준을 분리해 이 비대칭에 맞췄다. 2안은 두 출력이 같은 값에 매여 있다.
  • 한 층으로는 못 막는다. 스파이크, 깜빡임, 추세 오독, 두절은 성격이 다른 노이즈다. 평활 창 하나는 이 모두와 싸워야 하고, 어느 쪽으로 조정해도 반대쪽이 뚫린다.
  • 노이즈 크기를 계산에 반영한다. 추세 판단 기준을 최근 신호의 흔들림에 맞춰 조정해, 고정 기준 하나를 모든 상황에 적용하지 않는다.
  • 잘 알려진 방법을 조합했다. 진입과 이탈 기준을 다르게 두는 방법, 시간 구간의 평균, 노이즈 크기를 반영하는 기준처럼 검증된 원리를 각 문제에 맞게 사용했다.
  • 이번 과제에서 시험할 범위가 분명하다. 자동시험은 입력 범위 검사와 화면 판정의 번복 억제를 확인한다. 60초 코칭 판정, 추세 신뢰도, 입력 전환은 구현 구조로 제시하되 이번 QA4 수치가 네 층 전체의 성능을 뜻하지는 않는다.

3.보완 계획

  • 이번 과제에서 확인: 정해 둔 범위 밖 값 50개는 모두 차단했고 정상 범위 500개는 잘못 차단하지 않았다. 경계 부근의 판정 번복은 5개 시드에서 순간값 판정보다 67.1~74.7% 줄었고, 화면 판정은 +10bpm 변화에 1틱 만에 전환했다.
  • 향후 확인: 이 결과는 결정론적 입력을 사용한 구조 회귀시험이며 실제 워치 센서의 정확도 시험이 아니다. 실제 주행 데이터를 확보하게 되면 60초 평균과 판정 기준을 다시 조정한다.

Appendix. DP4 상세 설계 내역

A

A1.문제점이 걸리는 품질 속성

  • 손목 심박의 순간 스파이크 → 강건성(입력 차단)
  • 경계 근처 판정 깜빡임 → 강건성(번복 억제)
  • 오판이 행동 지시로 직행 → 제어가능성(지시에 더 엄격한 기준)
  • 노이즈 폭의 개인차 → 기능적응성(자가 보정 문턱)
  • 신호 두절과 센서 부재 → 강건성(기능 유지)
  • 정답지가 없어 채점 불가 → 일관성 지표로 대응
  • 방어가 과하면 진짜 변화도 늦는다 → 수행효율성(비용의 정직한 인정)

A2.채택안의 방어 4층 (각 층은 서로 다른 노이즈를 막는다)

층하는 일막는 것
1. 입력 가드레일허용 범위 밖 값과 낡은 값을 처음 단계에서 버린다범위 밖 값, 낡은 값
2. 이중 기준 판정표시는 순간심박+이중 문턱, 코칭은 60초 평균 심박(지속심박)깜빡임, 순간 이탈의 지시 직행
3. 통계 평탄화추세는 창 기울기+신뢰도로, 문턱은 개인 노이즈의 배수로잡음의 추세 오독, 노이즈 개인차
4. 입력 전환센서가 없거나 끊기면 사용할 수 있는 다음 입력으로 전환한다센서 부재와 두절

별점의 범위: 손목 심박, 야외 사용, 행동 지시가 있는 앱이라는 조건에서 구조를 비교한 점수다. 실제 센서 정확도나 의학적 안전성을 평가한 점수가 아니며, 더 안정적인 센서를 쓰거나 기록만 보여 주는 앱이라면 결과가 달라질 수 있다.

A4.예상 질문

  • "코칭이 60초 늦으면 이미 늦은 것 아닌가?" → 이 설계는 순간 반응보다 안정적인 강도 유지를 우선한다. 화면 판정은 순간심박으로 빠르게 바뀌고, 코칭만 60초 평균을 사용한다. 위험 심박은 별도 규칙으로 처리하지만 이것이 의료 안전을 보장한다는 뜻은 아니다.
  • "이동평균 창을 잘 고르면 2안도 충분하지 않나?" → 창 하나로는 스파이크 억제(긴 창)와 반응성(짧은 창)을 동시에 못 잡고, 경계 근처 번복은 창 길이와 무관하게 남는다. 번복 억제는 평활이 아니라 판정 규칙(이중 문턱)과 판정 입력(순간값을 보느냐 60초 평균을 보느냐)의 문제다.
  • "이동평균에 히스테리시스만 더한 중간안은?" → 그 순간 "층을 쌓는 설계"를 받아들인 것이다. 남는 질문은 몇 층이냐이고, 시간 필터와 개인 문턱과 폴백도 같은 논리로 필요해진다 — 각 층이 서로 다른 노이즈를 막기 때문이다.

A5.용어 대조(심사용)와 근거 문헌

들어올 때/나갈 때 문턱 분리 = hysteresis / 판정 번복 = flicker, chattering / 순간 이탈을 시간축에서 거르기 = 시간 필터(경보 관리 표준 ISA-18.2는 on-delay 타이머와 데드밴드를 제시 — 우리 구현은 60초 평균과 히스테리시스) / 개인 노이즈 배수 문턱 = k·σ(통계적 공정 관리) / 두절 시 갈아타기 = graceful degradation

근거 문헌: 슈미트 트리거(이중 문턱 표준 기법) / ISA-18.2(경보의 시간 필터와 데드밴드) / Shewhart 관리도(산포 배수 관리한계) / 손목 광학 심박의 운동 중 오차(검증 연구들의 일관된 보고)
