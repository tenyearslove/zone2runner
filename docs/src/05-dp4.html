DP4. 강건성 — 흔들리는 입력에도 판정을 안정시키는 구조

센서 오류와 경계 부근의 흔들림을 다루는 두 가지 방법을 비교한다.

DP4. 설계 문제 정의

3

1.배경

  • 센서 신호에는 잡음이 섞일 수 있다. 손목 광학 심박계는 달리는 중 팔 움직임 때문에 값이 갑자기 튈 수 있고, GPS에도 오차가 있으며 연결이 잠깐 끊기기도 한다.
  • 판정 결과는 화면 표시로 끝나지 않고 "속도를 줄이세요" 같은 행동 지시로 이어진다. 튀는 값 하나가 곧바로 지시가 되면 사용자는 잘못된 값에 맞춰 속도를 바꾸게 된다.
  • 따라서 잡음이 섞인 신호에서도 판정과 코칭을 안정적으로 유지하는 구조가 필요하다.

2.문제점

  • 잘못된 지시는 늦은 지시보다 영향이 크다. 판정이 조금 늦더라도, 튀는 값 하나로 잘못된 지시를 내보내지 않는 편이 낫다.
  • 경계 근처에서 판정이 깜빡인다. 심박이 경계를 오르내리면 순간값 판정은 초 단위로 뒤집혀 신뢰를 잃는다.
  • 노이즈 폭이 사람마다 다르다. 모든 사람에게 같은 필터 기준을 적용하기 어렵다.
  • 기준 장비와 비교한 측정값이 없다. 이번 과제에서는 별도의 기준 심박계와 비교하지 않는다. 따라서 강건성은 정해 둔 이상값을 차단하고 경계 부근의 불필요한 판정 번복을 줄이는지로 평가한다.

DP4. 설계 결정과 근거

3

1.최종 채택 구조

1안인 단계별 방어 판정 구조를 채택했다.

2.채택 근거

  • 화면 표시와 코칭의 기준을 다르게 두었다. 코칭은 행동 지시이므로 빠른 반응보다 잘못된 지시를 줄이는 것이 중요하다. 화면은 현재 심박을 바로 보여 주고, 코칭은 일정 시간 유지된 심박을 사용한다. 2안은 두 출력 모두 같은 순간값을 사용한다.
  • 한 가지 필터로 모든 문제를 해결하기 어렵다. 순간 이상값, 판정 깜빡임, 잘못된 추세 판단, 연결 두절은 원인이 서로 다르다. 이동평균 하나만 조정해서는 이 문제들을 각각 다루기 어렵다.
  • 노이즈 크기를 계산에 반영한다. 추세 판단 기준을 최근 신호의 흔들림에 맞춰 조정해, 고정 기준 하나를 모든 상황에 적용하지 않는다.
  • 잘 알려진 방법을 조합했다. 진입과 이탈 기준을 다르게 두는 방법, 시간 구간의 평균, 노이즈 크기를 반영하는 기준처럼 검증된 원리를 각 문제에 맞게 사용했다.
  • 이번 과제에서 시험할 범위가 분명하다. 자동시험은 입력 범위 검사와 화면 판정의 번복 억제를 확인한다. 60초 코칭 판정, 추세 신뢰도, 입력 전환도 구현했지만 이번 QA4 수치가 네 단계 전체의 성능을 뜻하지는 않는다.

3.보완 계획

  • 이번 과제에서 확인: 범위 밖 입력 차단율 100%(50/50), 정상 입력 오차단율 0%(0/500)였다. 번복 감소 기준은 5개 시드 모두 충족했고(100%, 5/5), 실제 감소 폭은 67.1~74.7%였다. 심박이 한 번에 10bpm 높아지는 시험 입력에서는 한 번의 갱신 주기(1틱) 만에 판정이 바뀌었다.
  • 향후 확인: 이 결과는 미리 정해 둔 입력을 사용한 반복 시험이며 실제 워치 센서의 정확도 시험이 아니다. 실제 주행 데이터를 확보하게 되면 60초 평균과 판정 기준을 다시 조정한다.

Appendix. DP4 상세 설계 내역

A

A1.이 설계 결정이 다루는 품질 문제

  • 손목 심박의 순간 이상값 → 강건성(입력 차단)
  • 경계 근처 판정 깜빡임 → 강건성(번복 억제)
  • 잘못된 판정이 곧바로 행동 지시로 전달됨 → 제어가능성(지시에 더 엄격한 기준)
  • 사람마다 다른 잡음의 크기 → 기능적응성(잡음 크기에 따라 기준 조정)
  • 신호 두절과 센서 부재 → 강건성(기능 유지)
  • 기준 장비의 정답이 없어 절대 정확도를 평가하기 어렵다 → 일관성 지표로 대응
  • 각 방어층을 같은 노이즈 입력으로 반복 확인할 수 있어야 한다 → 테스트가능성

A2.채택안의 4단계 방어 (각 층은 서로 다른 노이즈를 막는다)

단계하는 일막는 것
1. 입력 가드레일허용 범위를 벗어난 값과 너무 오래된 값을 처음 단계에서 버린다.범위 밖 값, 낡은 값
2. 이중 기준 판정화면은 순간 심박에 서로 다른 진입·이탈 기준을 적용하고, 코칭은 최근 60초의 평균 심박을 사용한다.깜빡임, 순간 이탈의 지시 직행
3. 추세 안정화여러 심박값으로 추세와 신뢰도를 계산하고, 사람마다 다른 잡음의 크기에 맞춰 판단 기준을 조정한다.잘못된 추세 판단, 사람마다 다른 잡음 크기
4. 입력 전환센서가 없거나 끊기면 사용할 수 있는 다음 입력으로 전환한다센서 부재와 두절

A4.용어 대조(심사용)와 근거 문헌

진입 기준과 이탈 기준을 다르게 두는 방법을 hysteresis(히스테리시스)라고 한다. 순간 이탈은 시간 필터로 걸러 내며, 이 구현에서는 60초 평균을 사용한다. 센서가 끊겼을 때 다른 입력으로 전환해 기능을 유지하는 방식은 graceful degradation에 해당한다.

근거 문헌: 슈미트 트리거(이중 문턱 표준 기법) / ISA-18.2(경보의 시간 필터와 데드밴드) / Shewhart 관리도(산포 배수 관리한계) / 손목 광학 심박의 운동 중 오차(검증 연구들의 일관된 보고)

상세 설계와 참고 문헌은 별도의 DP4 설계 문서에 기록했다.
