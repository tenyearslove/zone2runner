DP1. 기능적응성 — 사용자 응답으로 개인 경계를 조정하는 구조

사용자 응답을 개인 경계에 반영하는 두 가지 방법을 비교한다.

DP1. 설계 문제 정의

3

1.배경

  • Zone 2 코칭에는 사용자마다 다른 개인 경계가 필요하다. 같은 사용자도 몸 상태와 훈련 정도에 따라 적절한 경계가 달라질 수 있다.
  • 프로필로 계산한 값은 개인별 측정값이 아니라 첫 러닝을 위한 추정값이다. 이 값이 실제 상태와 다르면 코칭 기준도 어긋날 수 있다.
  • 따라서 말하기 테스트 답변을 실행 중 개인 경계에 빠르게 반영하는 기능(기능적응성)을 핵심 품질로 선정했다. 이 설계 결정에서는 사용자 응답을 개인 경계에 반영하는 구조를 다룬다.

2.문제점

  • 개인 경계의 기준값을 직접 측정하기 어렵다. 현재 개발 범위에서는 실제 유산소 역치를 별도로 측정하지 않는다. 따라서 생리학적 정확도가 아니라, 말하기 테스트 답변으로 조정한 경계가 판정에 반영되기까지 걸린 시간을 측정한다.
  • 응답 횟수가 적고 내용도 주관적이다. 말하기 테스트 응답은 한 세션에서 제한된 횟수만 수집하며, 사용자가 자신의 상태를 잘못 판단할 수도 있다. 제한된 응답을 반영하되 한 번의 응답으로 경계가 지나치게 바뀌지 않아야 한다.
  • 몸 상태는 시간에 따라 달라질 수 있다. 한 번 조정한 경계도 시간이 지나면 현재 몸 상태와 달라질 수 있다. 적응은 한 번으로 끝나지 않고 계속되어야 한다.
  • 개인화 처리는 서버 없이 기기에서 수행해야 한다. 서버 기반 학습 환경을 구축하거나 별도 운영 비용을 들일 수 없는 조건이다.

구조
  • 첫 경계: 프로필로 개인 경계의 초기값을 추정한다.
  • 러닝 중 갱신: 말하기 테스트 응답과 당시 심박을 새 근거로 받아 기존 경계를 조금씩 수정한다. 한 번의 응답으로 이전 값을 완전히 바꾸지 않고, 같은 방향의 응답이 쌓일수록 그 근거를 더 반영한다. 이처럼 기존 추정과 새 근거를 함께 반영하는 방식이 베이지안 갱신이며 별도의 모델 재학습은 필요하지 않다.
  • 저장과 설명: 수정한 경계를 다음 러닝의 시작값으로 저장하고, 어떤 응답 때문에 어느 방향으로 달라졌는지도 기록한다.
  • 응답 수집: 2안에서도 러닝 중 말하기 테스트에 답한다. 현재 경계를 바로 바꾸지 않고, 응답 당시의 심박과 세션 기록을 동의받아 서버의 Data Lake에 모은다.
  • 공통·개인화 학습: 여러 사용자의 기록에서 프로필과 운동 반응의 공통 관계를 학습하고, 현재 사용자의 프로필과 누적 기록으로 개인 Zone 2 상한 또는 보정값을 산출한다.
  • 반영 시점: 새 응답은 다음 학습 데이터에 포함되며, 재학습·검증·배포가 끝난 뒤 이후 러닝부터 개인 경계에 반영된다.

DP1. 1안의 개인화 원리

3

개인화는 현재 개인 경계를 새로운 말하기 응답이 가리키는 방향으로 조금씩 옮기는 과정이다. 경계 부근을 직접 알려 주는 응답은 더 크게 반영하고, 방향만 알려 주는 응답은 작게 반영한다.

1.첫 경계와 추정 범위

최대심박은 사용자가 입력한 값이나 나이 기반 공식으로 계산한 값을 사용한다. 안정심박은 입력값을 우선하고, 입력하지 않았다면 러닝 수준과 주간 운동 횟수로 추정한다. 키와 몸무게로 계산한 BMI는 체형 선택을 돕고, 계산 결과와 사용자가 선택한 체형의 차이가 크면 초기 추정 범위를 넓게 잡는다.

프로필 정보 → 첫 Zone 2 상한 + 초기 추정 범위

추정 범위는 계산한 상한 주변에 어느 정도 오차가 있을 수 있는지를 bpm으로 나타낸 내부 값이다. 센서 오차나 의학적으로 검증된 신뢰구간은 아니다. 안정심박을 추정했거나 프로필 정보가 서로 잘 맞지 않으면 처음에는 경계를 덜 확실하게 본다.

2.말하기 응답을 관측값으로 환산하는 방법

응답의미경계에 반영하는 방법
편안함현재 강도보다 경계가 위에 있을 가능성현재 경계를 올리는 정보일 때만 작게 반영
보통현재 심박이 경계 부근일 가능성경계 부근의 직접 관측으로 보고 양방향 반영
벅참현재 강도보다 경계가 아래에 있을 가능성현재 경계를 내리는 정보일 때만 작게 반영

3.갱신 원리와 안전장치

새 경계 = 현재 경계 + 반영 정도 × (응답이 가리키는 경계 − 현재 경계)

반영 정도는 응답이 경계를 얼마나 직접 알려 주는지와 현재 경계를 얼마나 확실하게 보는지에 따라 달라진다. 따라서 경계 부근을 나타내는 "보통"은 상대적으로 크게, 방향만 알려 주는 "편안함"과 "벅참"은 작게 반영한다.

  • 현재 판단과 같은 방향의 정보만 반영해 불필요한 역방향 이동을 막는다.
  • 한 세션에서 경계가 바뀌는 폭은 시작값을 기준으로 최대 ±10bpm으로 제한한다.
  • 조정한 상한은 다음 러닝의 시작값으로 저장한다. 최근 추정 범위는 개인화 상태 표시용으로 별도 기록한다.

  • QA1 설명용이성: 어떤 응답으로 경계가 어느 방향으로 바뀌었는지 기록해 개인화 화면과 리포트에서 확인할 수 있다. 다만 이 기록이 실제 유산소 역치의 정확성을 보장하지는 않는다.
  • QA5 테스트가능성: 같은 프로필과 응답 순서를 다시 넣어 경계의 이동 방향과 변경 한도를 반복 확인할 수 있다.
  • Tradeoff: 서버 없이 응답을 바로 반영하고 그 과정을 확인할 수 있는 대신, 여러 사용자의 복잡한 패턴을 학습하는 방안은 실제 데이터와 운영 환경이 마련된 뒤 다시 검토한다.

3.검증 결과

  • 장기 개선안: 실제 달리기 기록과 말하기 응답을 확보할 수 있다면 응답별 보정량과 반영 정도를 다시 조정한다.

A4.용어와 근거 문헌

첫 추정값을 prior(사전값), 새로운 근거로 추정값을 수정하는 방법을 Bayesian update(베이지안 갱신)라고 한다. 데이터가 없는 초기 상태는 cold start, 변화가 발생한 뒤 시스템에 반영되기까지 걸리는 시간은 적응 지연(adaptation latency)이라고 한다.

근거 문헌은 베이지안 켤레 갱신을 다룬 표준 통계 교과서(Gelman 외), 변화 대응 온라인 학습 서베이(Gama 외, 2014), 말하기 테스트를 제1환기역치의 실용 지표로 검토한 연구(Persinger, 2004), 나이 기반 최대심박 공식의 개인 오차를 다룬 연구(Tanaka, 2001)다.

상세 설계와 참고 문헌은 별도의 DP1 설계 문서에 기록했다.
