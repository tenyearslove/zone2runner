DP4. 설계 문제 정의

3

1.배경

  • 이 앱에 들어오는 신호는 깨끗하지 않다. 손목 광학 심박계는 달리는 중 팔 흔들림으로 값이 튀는 것이 알려진 한계이고, GPS도 잡음이 섞이며, 연결이 잠깐 끊기기도 한다.
  • 판정 결과는 화면 표시로 끝나지 않고 "속도를 줄이세요" 같은 행동 지시로 이어진다. 튄 값 하나가 지시가 되면 사용자는 노이즈에 맞춰 달리게 된다.
  • 그래서 노이즈가 일상인 신호에서 판정과 지시를 지키는 구조를 고르는 것이 이 설계 결정이다.

2.문제점

  • 오판의 비용이 비대칭이다. 판정이 조금 늦는 것보다, 튄 값으로 잘못된 지시를 내보내는 것이 더 나쁘다.
  • 경계 근처에서 판정이 깜빡인다. 심박이 경계를 오르내리면 순간값 판정은 초 단위로 뒤집혀 신뢰를 잃는다.
  • 노이즈 폭이 사람마다 다르다. 고정된 필터 하나로 모두를 맞출 수 없다.
  • 정답지가 없다. 어느 판정이 맞았는지 채점할 수 없으니, 강건성은 판정의 일관성(번복 억제, 이상값 차단)으로 세워야 한다.

DP4. 설계결정 및 근거

3

1.최종 채택 구조

후보 1: 계층 방어 판정 아키텍처 채택

2.채택 근거

  • 오판의 비용이 비대칭이다. 코칭은 행동 지시라 잘못된 지시가 늦은 지시보다 비싸다. 표시(빠름)와 코칭(엄격)의 기준을 분리해 이 비대칭에 맞췄다. 2안은 두 출력이 같은 값에 매여 있다.
  • 한 층으로는 못 막는다. 스파이크, 깜빡임, 추세 오독, 두절은 성격이 다른 노이즈다. 평활 창 하나는 이 모두와 싸워야 하고, 어느 쪽으로 조정해도 반대쪽이 뚫린다.
  • 사람마다 자가 보정된다. 문턱이 고정 숫자가 아니라 그 사람 노이즈의 배수라, 노이즈가 크든 작든 같은 오경보율이 유지된다.
  • 표준 기법의 조립이다. 이중 문턱(온도조절기와 같은 원리), 지속 조건(산업 경보 표준), 노이즈 배수 문턱(통계 관리도) — 근거 없는 자체 발명이 없다.
  • 검증할 수 있다. 강건성을 일관성 지표(이상값 기각률, 판정 번복률)로 정의했고, 층별 모듈이라 시뮬로 노이즈를 주입해 층마다 검증한다.

3.보완 계획

  • 단기: 시뮬 측정은 완료했다(검증 파트 QA4 수록 — 이상치 기각율 100%, 번복 억제율 67~75%, 시드 5종). 남은 것은 실주행에서의 재측정이다.
  • 장기: 지속 시간(60초), 문턱 폭 같은 상수는 문헌 근거 출발점이다 — 실주행 기각/번복 기록으로 조정한다. 두절이 길 때 판정 보류를 알리는 표시를 다듬는다.

Appendix. DP4 상세 설계 내역

A

A1.문제점이 걸리는 품질 속성

  • 손목 심박의 순간 스파이크 → 강건성(입력 차단)
  • 경계 근처 판정 깜빡임 → 강건성(번복 억제)
  • 오판이 행동 지시로 직행 → 제어가능성(지시에 더 엄격한 기준)
  • 노이즈 폭의 개인차 → 기능적응성(자가 보정 문턱)
  • 신호 두절과 센서 부재 → 강건성(기능 유지)
  • 정답지가 없어 채점 불가 → 일관성 지표로 대응
  • 방어가 과하면 진짜 변화도 늦는다 → 수행효율성(비용의 정직한 인정)

A2.채택안의 방어 4층 (각 층은 서로 다른 노이즈를 막는다)

층하는 일막는 것
1. 입력 가드레일생리 범위 밖 값과 낡은 값을 문에서 버린다순간 스파이크, 낡은 값
2. 이중 기준 판정표시는 순간값+이중 문턱, 코칭은 60초 지속 조건깜빡임, 순간 이탈의 지시 직행
3. 통계 평탄화추세는 창 기울기+신뢰도로, 문턱은 개인 노이즈의 배수로잡음의 추세 오독, 노이즈 개인차
4. 소스 폴백센서 부재/두절 시 다음 소스로 갈아탄다두절, GPS 튐

A4.예상 질문

  • "코칭이 60초 늦으면 이미 늦은 것 아닌가?" → Zone 2 훈련의 목적은 초 단위 반응이 아니라 강도 유지다. 조금 늦은 올바른 지시가 빠른 잘못된 지시보다 낫다. 위험 심박은 별도 안전 규칙이 즉시 감시하고, 화면 표시는 순간값이라 빠르다.
  • "이동평균 창을 잘 고르면 2안도 충분하지 않나?" → 창 하나로는 스파이크 억제(긴 창)와 반응성(짧은 창)을 동시에 못 잡고, 경계 근처 번복은 창 길이와 무관하게 남는다. 번복 억제는 평활이 아니라 판정 규칙(이중 문턱, 지속 조건)의 문제다.
  • "이동평균에 히스테리시스만 더한 중간안은?" → 그 순간 "층을 쌓는 설계"를 받아들인 것이다. 남는 질문은 몇 층이냐이고, 지속 조건과 개인 문턱과 폴백도 같은 논리로 필요해진다 — 각 층이 서로 다른 노이즈를 막기 때문이다.

A5.용어 대조(심사용)와 근거 문헌

들어올 때/나갈 때 문턱 분리 = hysteresis / 판정 번복 = flicker, chattering / 일정 시간 지속 후 반응 = on-delay(경보 관리 표준 ISA-18.2) / 개인 노이즈 배수 문턱 = k·σ(통계적 공정 관리) / 두절 시 갈아타기 = graceful degradation

근거 문헌: 슈미트 트리거(이중 문턱 표준 기법) / ISA-18.2(경보 지속 조건과 데드밴드) / Shewhart 관리도(산포 배수 관리한계) / 손목 광학 심박의 운동 중 오차(검증 연구들의 일관된 보고)
