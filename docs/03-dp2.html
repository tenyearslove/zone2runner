DP2. ML 대안을 검토하고 최종 구조를 선택한 과정

3

1.초기에는 ML의 적용 가능성을 검토했다

  • 가상 러너로 학습 데이터를 만들어 Zone 판정, 개인 경계 추정, 30~60초 뒤 심박 예측에 작은 신경망을 적용했다.
  • 시뮬레이션에서는 좋은 점수가 나왔지만, 실제 기기에서는 시뮬레이션 결과와 맞지 않는 사례가 확인됐다.
  • 모델이 합성 데이터의 생성 규칙을 잘 재현하더라도 실제 사용자에게 적합한 판단을 내린다고 볼 수는 없었다.

2.실제 판정에 적용하려면 검증 근거가 필요했다

  • 학습할 실제 데이터가 부족했다. 개인별 Zone 2 경계와 미래 심박을 함께 기록한 데이터가 없었다.
  • 출력을 비교할 기준값이 없었다. 실험실 장비로 측정한 유산소 역치가 없어 ML의 출력이 실제 상태와 맞는지 검증할 수 없었다.
  • 개인화 경계와 ML 판정이 충돌할 수 있었다. 앱은 말하기 테스트로 Zone 2 상한을 조정하지만, 별도 ML 판정기는 합성 데이터에서 학습한 기준으로 심박을 Zone 2 아래·범위 안·위로 구분한다. 같은 심박을 두 기준이 다르게 해석하면 어느 결과를 따라야 하는지 설명하기 어렵다.
  • 따라서 ML은 향후 검토할 대안으로 남겨 두고, 현재 확보한 데이터로 판단 근거를 설명하고 반복 검증할 수 있는 구조를 선택해야 했다.

강의의 AI Operation Subsystem에서 추론 서비스가 판정과 근거를 확정하고, 설명·분석·운영 서비스가 같은 근거를 전달·기록·표시한다. 현재 심박과 개인 경계를 직접 비교해 Zone을 판정하며, LLM은 시스템이 확정한 사실을 자연스러운 문장으로 표현한다.

강의의 AI Development Subsystem에서 ML을 학습·검증·등록한 뒤 추론 서비스에 배포하고, 설명 서비스는 판정이 끝난 뒤 이유를 별도로 추정한다. 실제 사용자 데이터와 측정 기준값이 충분하다면 규칙에 없는 관계도 학습할 수 있지만, 이번 과제의 데이터로는 실제 사용자에게도 유효한지 확인하기 어렵다.
확인 가능한 것판정에 사용한 심박·경계·규칙, 개인 경계가 바뀐 이유, 설명 문장의 숫자와 방향가상 러너가 만든 기준값에 대한 점수와 학습 손실만 확인할 수 있다. 실제 사용자에 대한 정확도는 별도 데이터가 있어야 검증할 수 있다.
장점판단 근거를 따라갈 수 있고, 사용자 응답이 다음 판정에 어떻게 반영됐는지 확인하기 쉽다.실제 데이터가 충분하면 사람이 정한 규칙보다 복잡한 관계를 학습할 가능성이 있다.
한계규칙과 관측 범위를 벗어난 복잡한 관계를 학습하지는 못한다.현재 데이터에서 얻은 높은 점수가 실제 사용자에게도 유지된다고 말할 수 없다. 또한 Zone 판정과 개인화가 서로 다른 기준을 사용할 수 있다.
절충현재 검증할 수 있는 범위를 분명히 하고, 복잡한 관계를 학습하는 방안은 실제 데이터가 확보된 뒤 다시 검토한다.복잡한 관계를 학습할 수 있지만, 실제 사용자 데이터와 검증 기준값을 먼저 확보해야 한다.

DP2. 설계 결정과 검증

3

1.최종 결정

이번 과제에서는 1안인 ‘투명한 규칙·관측 통계와 사용자 응답’ 구조를 채택했다.

2.결정 근거

  1. 현재 데이터만으로는 ML 판정을 실제 기능에 적용할 근거가 부족했다. 합성 데이터에서 얻은 점수만으로 실제 사용자의 Zone 2를 정확히 판정한다고 주장할 수 없다.
  2. 판정 기준을 하나로 모았다. 모든 판정과 설명에서 현재 심박과 말하기 테스트로 조정한 개인 경계를 함께 사용한다.
  3. 판단에 사용한 근거를 설명에도 그대로 사용한다. 판정 결과, 심박, 개인 경계와 경계 변경 이유를 하나의 기록에 남긴다. 따라서 설명을 만들 때 판단 근거를 다시 추정할 필요가 없다.
  4. 추후 ML을 다시 검토할 수 있다. 실제 러닝 데이터가 충분히 확보되면 전체 판정 구조를 바꾸기 전에 규칙의 오차를 보정하는 작은 모델부터 검증할 수 있다.

3.검증 결과

Zone 2 아래·범위 안·위의 판정에 사용한 심박과 개인 경계를 모두 기록했다.

이 결과로 미리 정한 세 가지 Zone 판정의 근거가 기록되고, 해당 기록을 사후 설명에 사용할 수 있음을 확인했다. 실제 Zone 2의 생리학적 정확도나 사용자가 설명을 이해하는 정도까지 확인한 것은 아니다.

4.보완 계획

  • 단기 개선안: 판정·개인화·코칭 화면에서 같은 용어와 숫자를 사용하는지 확인하는 시험 사례를 확대한다.
  • 장기 개선안: 실제 사용자 데이터와 비교 기준을 확보할 수 있다면 규칙이 놓친 오차만 보정하는 작은 모델을 다시 검토한다.
