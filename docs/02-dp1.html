DP1. 기능적응성 — 사용자 응답으로 개인 경계를 조정하는 구조

사용자 응답을 개인 경계에 반영하는 두 가지 방법을 비교한다.

DP1. 설계 문제 정의

3

1.배경

  • Zone 2 코칭의 기준은 그 사람의 개인 경계다. 이 경계는 사람마다 다르고, 같은 사람도 몸 상태와 훈련 정도에 따라 달라질 수 있다.
  • 프로필로 계산한 값은 개인 측정값이 아니라 첫 추정값이다. 이 값이 실제 상태와 다르면 코칭 기준도 함께 어긋날 수 있다.
  • 그래서 이 앱은 앱을 사용할수록 경계를 그 사람에게 맞춰 가는 것(기능적응성)을 핵심 품질로 잡았다. 그 적응을 어떤 구조로 만들지가 이 설계 결정이다.

2.문제점

  • 개인 경계의 정답을 직접 측정하기 어렵다. 이번 과제에서는 실제 유산소 역치를 별도로 측정하지 않는다. 따라서 사용자의 말하기 테스트 응답을 조정 근거로 삼고, 그 응답에 맞게 값이 움직이는지를 확인한다.
  • 응답이 적고 주관적이다. 말하기 테스트는 세션당 몇 번만 받고, 사용자가 잘못 답할 수도 있다. 적은 응답에도 반응하되 한 번에 지나치게 바뀌지 않아야 한다.
  • 몸 상태는 시간에 따라 달라질 수 있다. 한 번 조정한 경계도 시간이 지나면 현재 몸 상태와 달라질 수 있다. 적응은 한 번으로 끝나지 않고 계속되어야 한다.
  • 서버 없이 폰 안에서 적응해야 한다. 서버 학습 환경이나 추가 비용을 사용할 수 없는 조건이다.

DP1. 채택안의 개인화 계산

3

베이지안 갱신은 현재 경계 추정값과 새로운 말하기 응답을 각각의 불확실성에 따라 섞는 계산이다. 더 확실한 정보에 더 큰 비중을 주며, 응답이 쌓일수록 불확실성은 줄어든다.

1.첫 경계와 불확실성

최대심박은 입력값 또는 나이 기반 공식, 안정심박은 입력값 또는 러닝 수준·주간 빈도 기반 추정값을 사용한다. 키·몸무게는 BMI로 체형을 제안하고, 입력 체형과 다르면 초기 불확실성을 키운다.

HRR = 최대심박 − 안정심박, δ = 체형·러닝 수준·주간 빈도 보정값의 합으로 둔다.

u₀ = clamp(((0.70 + δ) × 최대심박 − 안정심박) / HRR, 0.30, 0.75)
μ₀ = 안정심박 + u₀ × HRR

δ는 체형 [−0.01, 0, 0, −0.02, −0.04], 러닝 수준 [−0.05, −0.025, 0, +0.025, +0.05], 주간 빈도 [−0.02, −0.01, 0, +0.01, +0.02]에서 선택한 값을 더한 뒤 −0.08~+0.06으로 제한한다. E=각 선택 단계가 중앙값 3에서 떨어진 거리의 합, M=체형 정보 불일치 여부(0 또는 1), R=안정심박 추정 여부(0 또는 1)일 때 σ₀ = 8 + 0.8E + 2M + 3R bpm이다.

2.말하기 응답을 관측값으로 바꾸는 방법

응답관측값 z관측 불확실성 s반영 방향
편안함현재 심박 + 5bpm14bpm현재 경계를 올리는 정보일 때만 반영
보통현재 심박6bpm경계 부근의 직접 관측으로 양방향 반영
벅참현재 심박 − 5bpm14bpm현재 경계를 내리는 정보일 때만 반영

3.코드에서 사용하는 갱신식과 안전장치

현재 추정값을 μ, 현재 분산을 σ², 새 관측의 표준편차를 s라고 하면 정밀도는 p₀=1/σ², p₁=1/s²이다.

μ′ = (μp₀ + zp₁) / (p₀ + p₁)    /    σ′² = 1 / (p₀ + p₁)

계산 후 경계 μ′는 한 세션의 시작값 μ₀에서 ±10bpm 안으로 제한한다. 갱신된 상한은 다음 세션의 시작값으로 저장하고, Zone 2 하한은 상한보다 HRR의 0.12만큼 낮게 둔다.

DP1. 설계 결정과 근거

3

1.최종 채택 구조

1안인 온라인 베이지안 개인 적응 구조를 채택했다.

2.채택 근거

  • 적응이 즉시 일어난다. 응답이 들어오면 즉시 경계를 조정하고, 얼마나 바뀌었는지 화면에 보여 준다. 2안에서는 같은 응답이 반영되려면 다음 재학습과 배포까지 기다려야 한다.
  • 관측한 응답과 갱신 결과를 연결할 수 있다. 어떤 응답 때문에 경계가 어느 방향으로 움직였는지 확인할 수 있다. 다만 이것이 실제 유산소 역치의 정확도를 뜻하지는 않는다.
  • 한 번에 지나치게 움직이지 않는다. 불확실성을 반영해 이동 폭을 계산하고, 세션당 최대 이동을 10bpm으로 제한한다. 응답이 쌓이면 불확실성이 줄어 변화 폭도 작아진다.
  • 과제 제약과 맞는다. 개인화 갱신은 서버 없이 폰에서 계산하고 저장한다. 개인화를 위해 심박과 개인화 값을 외부 서버로 보내지 않는다.
  • 이 결정은 DP2의 설명 구조와도 연결된다. 개인 경계의 추정값과 불확실성을 그대로 보여 줄 수 있어 설명용이성을 높인다. 이동 한도와 사용자 응답은 개인화가 한 번에 지나치게 바뀌지 않도록 제어한다.

3.검증 결과

응답 기준과 시드를 바꾼 자동시험에서 학습된 경계와 설정한 응답 기준의 차이는 모두 3bpm 이하였다. 세션당 최대 경계 변경 폭은 9.97bpm으로 제한값 10bpm을 지켰다.

4.보완 계획

  • 단기 개선안: 개인화 화면에 최근 말하기 응답이 경계를 어느 방향으로 얼마나 바꿨는지 더 쉽게 설명한다.
  • 장기 개선안: 실제 달리기 기록과 말하기 응답을 확보할 수 있다면 응답별 ±5bpm 보정값과 관측 불확실성 6·14bpm을 다시 조정한다.

Appendix. DP1 상세 설계 내역

A

A1.이 설계 결정이 다루는 품질 문제

  • 프로필 공식만으로는 개인차를 충분히 반영하기 어렵다 → 기능적응성
  • 몸 상태가 변해 한 번 맞춘 경계도 낡는다 → 기능적응성
  • 개인별 경계의 측정 정답이 없다 → 관측 가능한 말하기 테스트 응답을 갱신 근거로 사용
  • 응답이 적고 주관적이다 → 강건성
  • 개인 경계가 왜 바뀌었는지 보여야 한다 → 설명용이성
  • 같은 응답과 시드에서 경계 이동을 반복 확인할 수 있어야 한다 → 테스트가능성
  • 사용자가 적응을 확인하고 제어할 수 있어야 한다 → 제어가능성

A2.채택안의 개인화 과정 5단계

단계하는 일
1. 출발선프로필로 초기 경계를 계산하고, 불확실성을 넓게 두어 아직 정보가 적다는 상태를 표현한다.
2. 응답 수집달리는 중 말하기 테스트("지금 대화가 편한가요?") 응답을 받는다.
3. 갱신응답이 들어오면 현재 경계와 응답의 불확실성을 반영해 경계를 조정한다.
4. 안전장치한 세션의 경계 이동을 제한한다. 최대심박과 안정심박의 입력값 또는 추정값은 세션 중 자동으로 바꾸지 않는다.
5. 안정조정 결과를 다음 세션의 시작값으로 저장한다. 응답이 쌓일수록 불확실성이 줄어 경계도 덜 흔들린다.

A4.용어 대조(심사용)와 근거 문헌

첫 추정값은 prior(사전값), 새 근거로 추정값을 고치는 방법은 Bayesian update(베이지안 갱신)라고 한다. 데이터가 없는 첫 상태는 cold start, 변화가 생긴 뒤 반영되기까지 걸리는 시간은 적응 지연(adaptation latency)이라고 한다.

근거 문헌: 베이지안 켤레 갱신(표준 통계 교과, Gelman 외) / 변화 대응 온라인 학습 서베이(Gama 외 2014) / 말하기 테스트 = 제1환기역치 실용 지표(Persinger 2004) / 나이 공식의 개인 오차 ±10~15bpm(Tanaka 2001 기반, spec-001)

상세 설계와 참고 문헌은 별도의 DP1 설계 문서에 기록했다.
