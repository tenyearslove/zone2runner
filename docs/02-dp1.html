DP1. 기능적응성 — 사용자 응답으로 개인 경계를 조정하는 구조

사용자 응답을 개인 경계에 반영하는 두 가지 방법을 비교한다.

DP1. 설계 문제 정의

3

1.배경

  • Zone 2 코칭에는 사용자마다 다른 개인 경계가 필요하다. 같은 사용자도 몸 상태와 훈련 정도에 따라 적절한 경계가 달라질 수 있다.
  • 프로필로 계산한 값은 개인별 측정값이 아니라 첫 러닝을 위한 추정값이다. 이 값이 실제 상태와 다르면 코칭 기준도 어긋날 수 있다.
  • 따라서 말하기 응답이 쌓일수록 경계를 개인에게 맞춰 가는 기능(기능적응성)을 핵심 품질로 선정했다. 이 설계 결정에서는 사용자 응답을 개인 경계에 반영하는 구조를 다룬다.

2.문제점

  • 개인 경계의 기준값을 직접 측정하기 어렵다. 이번 과제에서는 실제 유산소 역치를 별도로 측정하지 않는다. 사용자의 말하기 테스트 응답을 조정 근거로 삼고, 경계가 응답에 맞는 방향으로 바뀌는지를 확인한다.
  • 응답 횟수가 적고 내용도 주관적이다. 말하기 테스트 응답은 한 세션에서 제한된 횟수만 수집하며, 사용자가 자신의 상태를 잘못 판단할 수도 있다. 제한된 응답을 반영하되 한 번의 응답으로 경계가 지나치게 바뀌지 않아야 한다.
  • 몸 상태는 시간에 따라 달라질 수 있다. 한 번 조정한 경계도 시간이 지나면 현재 몸 상태와 달라질 수 있다. 적응은 한 번으로 끝나지 않고 계속되어야 한다.
  • 개인화 처리는 서버 없이 기기에서 수행해야 한다. 서버 기반 학습 환경을 구축하거나 별도 운영 비용을 들일 수 없는 조건이다.

DP1. 채택안의 개인화 계산

3

베이지안 갱신은 현재 경계 추정값과 새로운 말하기 응답을 각각의 불확실성에 따라 반영하는 계산이다. 더 확실한 정보에 큰 비중을 두며, 응답이 쌓일수록 경계의 불확실성은 줄어든다.

1.첫 경계와 불확실성

최대심박은 사용자가 입력한 값이나 나이 기반 공식으로 계산한 값을 사용한다. 안정심박은 입력값을 우선하고, 입력하지 않았다면 러닝 수준과 주간 운동 횟수로 추정한다. 키와 몸무게로 계산한 BMI는 체형 선택을 돕고, 계산 결과와 사용자가 선택한 체형의 차이가 크면 초기 불확실성을 높인다.

HRR은 최대심박에서 안정심박을 뺀 값이며, δ는 체형·러닝 수준·주간 운동 횟수에 따른 보정값의 합으로 정의한다.

u₀ = clamp(((0.70 + δ) × 최대심박 − 안정심박) / HRR, 0.30, 0.75)
μ₀ = 안정심박 + u₀ × HRR

δ는 체형 [−0.01, 0, 0, −0.02, −0.04], 러닝 수준 [−0.05, −0.025, 0, +0.025, +0.05], 주간 운동 횟수 [−0.02, −0.01, 0, +0.01, +0.02]에서 선택한 값을 더한 뒤 −0.08~+0.06으로 제한한다. E는 각 선택 단계가 중앙값 3에서 떨어진 거리의 합, M은 체형 정보 불일치 여부(0 또는 1), R은 안정심박 추정 여부(0 또는 1)다. 초기 불확실성은 σ₀ = 8 + 0.8E + 2M + 3R bpm으로 계산한다.

2.말하기 응답을 관측값으로 환산하는 방법

응답관측값 z관측 불확실성 s반영 방향
편안함현재 심박 + 5bpm14bpm현재 경계를 올리는 정보일 때만 반영
보통현재 심박6bpm경계 부근의 직접 관측으로 양방향 반영
벅참현재 심박 − 5bpm14bpm현재 경계를 내리는 정보일 때만 반영

3.코드에서 사용하는 갱신식과 안전장치

현재 추정값을 μ, 현재 분산을 σ², 새 관측의 표준편차를 s라고 두면 두 값의 정밀도는 각각 p₀=1/σ², p₁=1/s²이다.

μ′ = (μp₀ + zp₁) / (p₀ + p₁)    /    σ′² = 1 / (p₀ + p₁)

계산된 경계 μ′는 한 세션의 시작값 μ₀를 기준으로 ±10bpm 이내로 제한한다. 갱신된 상한은 다음 세션의 시작값으로 저장하며, Zone 2 하한은 상한에서 HRR의 0.12에 해당하는 값을 뺀 값으로 정한다.

DP1. 설계 결정과 근거

3

1.최종 채택 구조

1안인 온라인 베이지안 개인 적응 구조를 채택했다.

2.채택 근거

  • 응답을 바로 반영할 수 있다. 응답이 들어오면 개인 경계를 조정하고 변경 폭을 화면에 보여 준다. 2안은 같은 응답을 반영하려면 다음 재학습과 배포까지 기다려야 한다.
  • 응답과 갱신 결과를 연결할 수 있다. 어떤 응답으로 경계가 어느 방향으로 바뀌었는지 확인할 수 있다. 다만 이 연결이 실제 유산소 역치의 정확성을 의미하지는 않는다.
  • 경계의 변화 폭을 제한할 수 있다. 불확실성을 반영해 변경 폭을 계산하고, 한 세션에서는 최대 10bpm까지만 바뀌도록 제한한다. 응답이 쌓이면 불확실성이 줄어 이후의 변경 폭도 작아진다.
  • 과제의 제약을 충족한다. 개인화 계산과 저장을 기기에서 수행하므로 심박과 개인화 값을 외부 서버로 보낼 필요가 없다.
  • DP2의 설명 구조와 일관된다. 개인 경계의 추정값과 불확실성을 설명 근거로 사용할 수 있다. 또한 응답과 변경 한도를 기록해 경계가 지나치게 바뀌지 않도록 통제한 과정도 확인할 수 있다.

3.검증 결과

말하기 가능 상한 5개와 시드 3개를 조합해 자동시험을 실행했다. 모든 조합에서 조정된 Zone 2 상한과 설정한 말하기 가능 상한의 차이가 3bpm 이하였다. 한 세션에서 경계가 바뀐 최대 폭은 9.97bpm으로, 제한값 10bpm을 넘지 않았다.

4.보완 계획

  • 단기 개선안: 최근 말하기 응답으로 경계가 어느 방향으로 얼마나 바뀌었는지 개인화 화면에서 더 쉽게 설명한다.
  • 장기 개선안: 실제 달리기 기록과 말하기 응답을 확보할 수 있다면 응답별 ±5bpm 보정값과 관측 불확실성 6·14bpm을 다시 조정한다.

A1.이 설계 결정이 다루는 품질 문제

  • 프로필 공식만으로는 개인차를 충분히 반영하기 어렵다 → 기능적응성
  • 몸 상태가 변하면 이전에 조정한 경계가 현재 상태와 달라질 수 있다 → 기능적응성
  • 개인별 경계를 비교할 측정 기준값이 없다 → 관측 가능한 말하기 테스트 응답을 갱신 근거로 사용
  • 응답 횟수가 적고 내용도 주관적이다 → 한 번의 응답으로 경계가 바뀌는 폭을 제한할 필요
  • 개인 경계가 왜 바뀌었는지 보여야 한다 → 설명용이성
  • 같은 응답과 시드에서 경계 변경을 반복 확인할 수 있어야 한다 → 테스트가능성
  • 사용자가 말하기 응답으로 적응에 개입할 수 있어야 한다 → 기능적응성

A2.채택안의 개인화 과정 5단계

단계하는 일
1. 초기값프로필로 초기 경계를 계산하고, 아직 개인화 근거가 적다는 점을 초기 불확실성에 반영한다.
2. 응답 수집달리는 중 말하기 테스트("지금 대화가 편한가요?") 응답을 받는다.
3. 갱신응답이 들어오면 현재 경계와 응답의 불확실성을 반영해 경계를 조정한다.
4. 안전장치한 세션의 경계 이동을 제한한다. 최대심박과 안정심박의 입력값 또는 추정값은 세션 중 자동으로 바꾸지 않는다.
5. 다음 세션 반영조정한 경계를 다음 세션의 시작값으로 저장한다. 응답이 쌓일수록 불확실성이 줄어 이후의 경계 변경 폭도 작아진다.

A4.용어 대조(심사용)와 근거 문헌

첫 추정값을 prior(사전값), 새로운 근거로 추정값을 수정하는 방법을 Bayesian update(베이지안 갱신)라고 한다. 데이터가 없는 초기 상태는 cold start, 변화가 발생한 뒤 시스템에 반영되기까지 걸리는 시간은 적응 지연(adaptation latency)이라고 한다.

근거 문헌은 베이지안 켤레 갱신을 다룬 표준 통계 교과서(Gelman 외), 변화 대응 온라인 학습 서베이(Gama 외, 2014), 말하기 테스트를 제1환기역치의 실용 지표로 검토한 연구(Persinger, 2004), 나이 기반 최대심박 공식의 개인 오차를 다룬 연구(Tanaka, 2001)다.

상세 설계와 참고 문헌은 별도의 DP1 설계 문서에 기록했다.
