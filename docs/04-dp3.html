DP3. 설계 문제 정의

3

1.배경

  • Zone 2 코칭의 기준은 그 사람의 개인 경계다. 이 경계는 사람마다 다르고, 같은 사람도 체력에 따라 변한다.
  • 나이로 계산한 값은 개인 측정값이 아니라 첫 추정값이다. 이 값이 실제 상태와 다르면 코칭 기준도 함께 어긋날 수 있다.
  • 그래서 이 앱은 경계를 쓸수록 그 사람에게 맞춰가는 것(기능적응성)을 핵심 품질로 잡았다. 그 적응을 어떤 구조로 만들지가 이 설계 결정이다.

2.문제점

  • 사람에 대한 정답지가 없다. 이번 과제에서는 실제 유산소 역치를 별도로 측정하지 않는다. 따라서 사용자의 말하기 테스트 응답을 관측값으로 삼고, 그 응답에 맞게 값이 움직이는지를 확인한다.
  • 응답이 적고 주관적이다. 말하기 테스트는 세션당 몇 번만 받고, 사용자가 잘못 답할 수도 있다. 적은 응답에도 움직이되 한 번에 지나치게 바뀌지 않아야 한다.
  • 몸 상태가 계속 변한다. 한 번 맞춘 경계도 시간이 지나면 낡는다. 적응은 한 번으로 끝나지 않고 계속되어야 한다.
  • 서버 없이 폰 안에서 적응해야 한다. 서버 학습 인프라도, 추가 비용도 쓸 수 없는 조건이다.

DP3. 설계결정 및 근거

3

1.최종 채택 구조

후보 1: 온라인 베이지안 개인 적응 아키텍처 채택

2.채택 근거

  • 적응이 그 자리에서 일어난다. 답한 순간 경계가 움직이고, 얼마나 움직였는지 화면에 보인다. 2안은 같은 답이 다음 재학습과 배포를 기다린다.
  • 관측한 응답과 갱신 결과를 연결할 수 있다. 어떤 응답 때문에 경계가 어느 방향으로 움직였는지 확인할 수 있다. 다만 이것이 실제 유산소 역치의 정확도를 뜻하지는 않는다.
  • 한 번에 지나치게 움직이지 않는다. 불확실성을 반영해 이동 폭을 계산하고, 세션당 최대 이동을 10bpm으로 제한한다. 응답이 쌓이면 불확실성이 줄어 변화 폭도 작아진다.
  • 과제 제약과 맞는다. 개인화 갱신은 서버 없이 폰에서 계산하고 저장한다. 심박과 개인화 값을 이 계산 때문에 외부 서버로 보내지 않는다.
  • DP1, DP2와 같은 구조에서 나온다. 적응 상태(평균과 확신 폭)가 그대로 노출되어 설명이 되고(DP1), 이동 한도와 답 채널이 통제가 된다(DP2).

3.보완 계획

  • 이번 과제에서 확인: 경계를 정해 둔 가상 러너 15개 사례가 모두 1~2세션 안에 목표 범위에 들어왔다. 8세션 뒤 오차는 0.20~0.77bpm, 마지막 4세션의 경계 폭은 기준 사례에서 3.04bpm, 한 세션 최대 이동은 9.97bpm이었다.
  • 향후 확인: 이 수치는 시뮬레이션 결과다. 실제 사람의 유산소 역치를 같은 오차로 찾았다는 뜻이 아니며, 실사용 평가를 하게 되면 말하기 테스트 안내와 개인화 상수를 다시 조정한다.

Appendix. DP3 상세 설계 내역

A

A1.문제점이 걸리는 품질 속성

  • 나이 공식의 개인 오차가 커 고정 경계는 코칭을 틀리게 한다 → 기능적응성
  • 몸 상태가 변해 한 번 맞춘 경계도 낡는다 → 기능적응성
  • 사람에 대한 경계 정답지가 없다 → 관측 가능한 말하기 테스트 응답을 갱신 근거로 사용
  • 응답이 적고 주관적이다 → 강건성
  • 적응이 왜 그렇게 움직였는지 보여야 한다 → 설명용이성
  • 서버 없이 폰 안에서, 추가 비용 없이 돌아야 한다 → 수행효율성
  • 사용자가 적응을 확인하고 제어할 수 있어야 한다 → 제어가능성

A2.채택안의 적응 루프 5단계

단계하는 일
1. 출발선나이/안정심박으로 대략의 경계를 계산하되, 확신 폭을 넓게 잡아 "아직 모른다"를 정직하게 표현
2. 응답 수집달리는 중 말하기 테스트("지금 대화가 편한가요?") 응답을 받는다
3. 갱신응답이 들어오면 현재 값과 응답의 불확실성을 반영해 경계를 옮긴다
4. 안전장치세션당 이동 한도, 최대심박은 관측 피크로 위로만/안정심박은 아래로만
5. 안정갱신 결과가 저장돼 다음 세션의 출발선 — 확신이 쌓일수록 덜 흔들림

별점의 범위: 1인 과제, 온디바이스 실행, 적은 사용자 응답, 서버 없음이라는 조건에서 두 안을 비교했다. 많은 사용자 데이터와 서버 운영 환경이 있다면 결과가 달라질 수 있다. 별점은 실제 사람의 유산소 역치 정확도를 평가한 점수가 아니다.

A4.예상 질문

  • "데이터를 모아 학습하면 더 정확해지지 않나?" → 사용자가 많고 검증 체계가 있으면 그렇다. 이 조건에서는 코호트도 채점 기준도 없어 잠재를 확인할 수 없고, 개인의 변화 반영은 오히려 느려진다.
  • "말하기 테스트 답이 틀리면?" → 답 하나의 영향은 확신 폭이 제한하고 세션당 이동 한도가 추가로 막는다. 갱신 이력이 화면에 노출되어 확인하고 재설정할 수 있다.

A5.용어 대조(심사용)와 근거 문헌

첫 짐작 = prior(사전값) / 증거로 짐작을 고치는 통계 방법 = Bayesian update / 데이터 없는 첫 상태 = cold start / 변화 발생에서 반영까지의 시간 = adaptation latency(이 DP의 결정축) / 표본마다 즉시 갱신 vs 모아서 재학습 = online learning vs batch retraining

근거 문헌: 베이지안 켤레 갱신(표준 통계 교과, Gelman 외) / 변화 대응 온라인 학습 서베이(Gama 외 2014) / 말하기 테스트 = 제1환기역치 실용 지표(Persinger 2004) / 나이 공식의 개인 오차 ±10~15bpm(Tanaka 2001 기반, spec-001)
