Appendix. Use Case

A
  • 액터는 둘 — 러너(사용자)와 개발자/검증자. 검증자가 정식 액터인 것이 이 시스템의 특징이다(시뮬 모드가 제품 기능 — DP5 테스트가능성).
  • 러너 중심 흐름: 프로필 등록 → 세션 시작 → 실시간 존/음성 코칭 → 말하기 테스트 응답(코칭 흐름에 포함 — 답이 그 자리에서 판정 기준을 정정하는 HITL) → 리포트 → 지표 설명/코칭 근거 열람(리포트에서 확장).
  • 부속: 코칭 방식 조정(HOTL), AI 모델 준비(미준비 시 안내로 확장), 이력/추세 확인.

Appendix. Context View

A
  • 시스템 경계: 폰 앱(판정/분석/개인화/코칭의 단일 주체) + 워치 앱(측정/표시). 외부 5종: Health Services / GPS / Gemini Nano(AICore, 별도 프로세스) / Open-Meteo(기온, 세션당 1회) / OSM 지도 타일 서버.
  • LLM 왕복에 통제 명시: 나가는 것은 "규칙이 확정한 사실+임무"뿐, 들어오는 문장은 가드 3종 통과 시 채택, 아니면 단어 폴백. 모델 다운로드는 세션 밖에서만.
  • 사용자에게 나가는 것에 생성 근거(프로비넌스) 포함 — 설명용이성이 컨텍스트 수준에서 보인다.
