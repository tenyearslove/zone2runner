## 1. 설계 문제

처음부터 규칙만 사용한 것은 아니다. 가상 러너로 데이터를 만들어 Zone 판정, 개인 경계 추정, 30~60초 뒤 심박 예측에 작은 신경망을 적용했다. 시뮬레이션 점수는 좋았지만 실제 기기 시험에서는 심박이 상한보다 42bpm 높은데도 '아래'로 판정한 사례가 나왔다.

원인을 확인하니 모델은 실제 사람의 생리를 배운 것이 아니라 가상 러너의 규칙과 데이터 생성 공식을 다시 배운 것이었다. 개인별 Zone 2 경계와 미래 심박의 측정 정답도 없어서, 합성 데이터 점수가 실제 사용자에게도 이어지는지 검증할 수 없었다. 말하기 테스트로 조정한 개인 경계와 ML 판정이 서로 다른 기준이 되는 문제도 있었다.

따라서 설계 질문을 다음과 같이 바꾸었다.

> 실제 정답 데이터가 부족한 조건에서, 판단 근거를 기록하고 같은 입력으로 반복 검증할 수 있는 구조는 무엇인가?

설명용이성은 ML을 포기하기 위한 명분이 아니다. 데이터와 검증의 한계를 확인한 뒤, 현재 구조를 고르는 평가 기준 가운데 하나다.

## 2. 설계안 비교

| 구분 | 1안: 투명한 규칙·관측 통계 + 사용자 응답 | 2안: 합성·공개 데이터 기반 ML + 사후 설명 |
|---|---|---|
| 판단 | 현재 심박과 개인 경계를 직접 비교 | ML이 Zone을 판정하거나 경계·심박을 예측 |
| 개인화 | 말하기 테스트 응답으로 경계를 조금씩 갱신 | 학습 또는 미세조정으로 반영 |
| 확인 가능한 것 | 판정, 심박, 개인 경계, 경계가 바뀐 이유 | 합성 정답에 대한 점수와 학습 손실 |
| 장점 | 판단 근거와 사용자 응답의 반영 결과를 따라가기 쉽다 | 실제 데이터가 충분하면 복잡한 관계를 배울 가능성이 있다 |
| 한계 | 규칙과 관측 범위 밖의 관계를 스스로 배우지 못한다 | 현재 데이터로는 실제 사람에 대한 정확도를 검증할 수 없다 |
| 결정 | 채택 | 보류 |

2안은 가상의 비교 대상이 아니다. 판정 MLP, 경계 추정 MLP, 심박 예측 MLP로 나누어 실제로 구현하고 시험했던 방향을 하나의 설계 대안으로 정리한 것이다. 세 모델이 완전히 같은 모델이었다는 뜻은 아니다. 공통으로 확인한 문제는 학습과 평가가 합성 데이터에 의존했다는 점이다.

## 3. 최종 결정

이번 과제에서는 1안을 채택한다.

1. 실제 정답으로 ML의 타당성을 검증할 수 없다.
2. 현재 심박과 말하기 테스트로 조정한 개인 경계를 하나의 판정 기준으로 사용한다.
3. 판정, 심박, 개인 경계, 개인화 이유를 한 기록으로 이어 설명 근거를 나중에 추정하지 않는다.
4. 실제 러닝 데이터가 충분히 쌓이면 규칙의 오차만 보정하는 작은 잔차 모델부터 다시 검토한다.

이 결정은 '규칙이 ML보다 항상 낫다'는 주장이 아니다. 이번 과제에서 증명할 수 있는 범위를 분명히 선택한 것이다.

## 4. QA1 검증

### 질문

판정과 설명이 같은 심박·개인 경계를 사용하는가? 근거에 없는 숫자가 생성되면 사용자에게 전달되기 전에 막을 수 있는가?

### 성공 기준

- 아래·범위 안·위의 대표 판정 3종에서 판정, 심박, 개인 경계의 근거 기록률 100%(3/3)
- 근거에 없는 숫자 차단율 100%(5/5)
- 근거가 있는 문장 통과율 100%(3/3)
- 코칭 문장과 근거 기록의 저장·복원 시험 통과

### 해석 범위

이 검증은 설명과 내부 판단의 연결을 확인한다. 실제 Zone 2의 생리학적 정확도나 사용자가 설명을 얼마나 쉽게 이해하는지까지 증명하지는 않는다.

## 5. 개발 이력 요약

| 시도 | 확인한 문제 | 현재 결정 |
|---|---|---|
| Zone 판정 MLP | 합성 정답은 잘 맞혔지만 실제 기기에서 명백한 오판이 발생. 개인 경계와 판정 기준도 충돌 | 현재 심박과 개인 경계를 직접 비교 |
| 개인 경계 추정 MLP | 개인별 측정 정답과 학습 데이터 부족 | 말하기 테스트 응답으로 경계 갱신 |
| 심박 예측 MLP | 가상 러너의 생리 공식을 다시 학습 | 실제 관측값 분석으로 범위 축소 |
| 규칙 오차 보정 NN | 합성 시험에서 약 10% 개선했으나 실제 데이터로 검증하지 못함 | 향후 후보로 보관 |
