# Report-016: 결론 — 인증 보고서 05. 결론

- 용도: 인증 보고서 PPT 원고

## 슬라이드 1 — 결론

### 1. 주요 성과

- **제약에서 출발해 AI 품질을 골랐다.** 개인의 정확한 유산소 역치를 측정할 수 없고, 대량 데이터와 자체 서버도 없다. 그래서 설명용이성, 기능적응성, 제어가능성, 강건성을 핵심 품질로 정했다.
- **품질 요구가 설계로 이어지게 했다.** 사용자 응답으로 개인 경계를 갱신하고, 규칙이 판단 사실을 확정하며, LLM은 문장 표현만 맡는다. 어긋난 문장은 가드가 막고, 이상 심박과 경계 부근의 흔들림은 입력 가드와 히스테리시스가 줄인다.
- **같은 QAS로 구현을 검증했다.** 미등록 숫자 5/5 차단, 개인화 15개 사례 모두 1~2세션 안착, 방향 위반 문장 10/10 차단, 판정 번복 67.1~74.7% 감소를 자동시험으로 확인했다.
- **참값이 없어도 반복할 수 있는 검증 구조를 만들었다.** RunSource와 가상 러너를 사용해 워치 없이 같은 로직에 입력을 넣고, 고정 시드와 결과 파일로 시험을 다시 실행할 수 있게 했다. 최근 JVM 단위시험 153개가 통과했다.
- **검증의 한계를 분리했다.** 자동시험은 설계와 로직이 의도대로 동작하는지를 보여 준다. 실제 사람의 생리 정확도, 사용자 이해도, 실제 센서 성능을 증명한다고 주장하지 않는다.

### 1-1. 과제 규정 충족

### 2. 향후 확인 항목

아래 항목은 최종 제출을 위해 반드시 수행해야 하는 일이 아니다. 실제 제품으로 발전시킬 때 필요한 다음 단계다.

- 실제 사용자가 설명을 쉽게 이해하는지 확인
- 실제 달리기에서 개인화 값과 말하기 테스트 응답의 관계 확인
- 손목 움직임과 신호 두절이 있는 환경에서 입력 가드 재확인
- 워치 입력부터 음성 출력까지 실기기 지연 측정
- 더 다양한 한국어 문장으로 LLM 출력 가드 시험 확대

### 맺음말

이 과제에서 중요한 결과는 큰 모델을 만든 것이 아니다. 제한된 조건에서 필요한 AI 품질을 고르고, 그 품질이 설계를 바꾸게 하고, 같은 기준으로 구현을 검증한 과정이다.
