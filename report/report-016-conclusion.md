## 슬라이드 1 — 결론

### 1. 주요 성과

- **참값 없는 문제를 검증 가능한 AI 시스템으로 설계했다.** 개인 Zone 2 경계는 실험실 밖에서 잴 수 없다. 이 제약을 정면으로 받아들여 — 판정은 투명한 규칙, 개인화는 사용자 실라벨 기반 온라인 베이지안, 분석은 관측 통계, 표현만 온디바이스 LLM — 어느 값도 지어내지 않는 구조("없는 숫자 금지")를 세우고, 그 원칙을 기계 검증(숫자 무결성 가드)까지 내렸다.
- **강의 AI System 아키텍처의 표준 요소를 온디바이스 앱 한 벌에 구현했다.** 입출력 가드레일, 모델 서빙(규칙/베이지안/분석/LLM), 설명 서비스, 분석 서비스, HITL/HOTL, Data Lake, 개인 적응(Retraining 대응), 시뮬 검증(모델 테스팅 대응) — 서버 없이, 비용 0으로, 데이터가 기기를 떠나지 않는 조건에서.
- **설계 결정 5건(DP1~DP5)을 정체성 품질과 1:1로 세웠다.** 설명용이성(충실한 설명), 제어가능성(약한 LLM 통제), 기능적응성(실라벨 즉시 적응), 강건성(계층 방어), 테스트가능성(재현 검증) — 각각 진지한 대안과의 비교/Trade-off/조건 의존성을 명시했고, 다섯 DP가 같은 아키텍처의 다른 단면임을 보였다.
- **검증을 실측으로 마쳤다.** 단위 테스트 152개(전 결정 로직이 기기 없이 실행) + 품질 측정 6종 — 경계 수렴 12.9→1.73bpm, 방향위반/이상치/없는숫자 기각율 100%, 판정 번복 73% 억제(진짜 이동은 1틱), 틱당 처리 0.079ms. 측정 도구가 저장소에 있어 언제든 재현된다.
- **구현이 설계 그대로다.** 화면 8종(폰 6+워치 2)의 모든 AI 접점 — 설명 팝업, 코칭 문장 근거 추적, 학습 반영 표시, LLM 사용 감사, 시뮬 검증 모드 — 이 DP의 결정들을 사용자 눈에 보이는 기능으로 구현한다.

### 2. 향후 계획

- **실주행 검증(층위 ②)**: 시뮬로 확인한 구조 위에서 실주행 데이터를 수집해 — 코칭 음성 지연(5초 기준), 필드 기각률/폴백 분포, 경계 수렴의 실제 체감 — 실기기 측정 항목을 확정하고 종류 C 상수(문턱/창 크기)를 튜닝한다.
- **LLM 직생성 품질 확인**: Nano 모델 준비 완료 기기에서 채택률/기각 사유 분포를 감사 기록으로 모아, 프롬프트와 가드 기준을 데이터로 다듬는다.
- **다국어 확장**: 문장은 LLM(언어 지시), 폴백/UI는 표준 리소스(단어 수준) — 표현 정본 구조가 다국어를 구조적으로 지원하므로 1차(영어)부터 착수한다.
- **적응 신호 확장**: 세션 간 추세(체력 향상 신호)를 적응 트리거로 승격 — 판단은 여전히 사용자 실라벨이 한다.
- **사용자 평가**: 설명 이해도/신뢰(설명용이성)와 코칭 만족(말투/빈도)을 실사용자에게 측정해 layered explanation을 다듬는다.

**맺음**: 이 과제의 답은 "더 큰 모델"이 아니라 **"검증할 수 있는 구조"**였다. 참값이 없어도, 모델이 약해도, 시스템 수준에서 신뢰를 만드는 것 — 가드레일과 폴백, 실라벨 적응, 프로비넌스, 재현 가능한 검증 — 이 AI 시스템 설계의 본론임을 이 구현으로 보였다.
