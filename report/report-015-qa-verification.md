| 프로비넌스 완전성 | 코칭 1문장당 근거 기록(관측 스냅샷+프롬프트+경로) 1건, JSON 왕복 보존 | 1:1 | 1:1 |
| 설명 결정론 | 동일 입력에 대한 규칙 팩트 생성의 일치 | 100% | 100% |

**산출 근거**: (a) 제1원칙 "없는 숫자 금지"의 기계 검증 — 출력 숫자 ⊆ 입력 사실 집합(아라비아 숫자 표기에 대해 언어 무관. 한글 숫자 표현은 프롬프트 제약과 길이 가드가 보조하고, 실주행 기각 기록으로 감시한다). (b) 참값 없는 조건에서 설명의 신뢰는 사후 채점이 아니라 구조로 확보(DP1 결정축=충실도) — 그래서 지표가 "정확한 설명 %"가 아니라 "어긋난 설명이 만들어질 수 없음"이다. (c) 사용자 이해도 평가(샘플의 전문가/사용자 평가에 해당)는 실사용 단계 과제로 분리.

### QA2 기능적응성

| 지표명 | 측정 방법 | 목표치 | 최소 허용치 |
|---|---|---|---|
| 수렴 오차 (Quality Recovery) | 참임계를 아는 가상 러너로 8세션 폐루프, 세션별 \|μ−참임계\| | 최종 ≤3bpm | ≤5bpm |
| 안착 세션 수 (Time to Stabilization) | 오차가 3bpm 이하로 처음 들어온 세션 | ≤5세션 | ≤8세션 |
| 안정성 (Stability Index) | 수렴 후(마지막 4세션) 경계 진동폭 | ≤라벨 산포(4bpm) | ≤6bpm |
| 이동 한도 보장률 | 세션당 경계 이동이 10bpm을 넘지 않는 비율 | 100% | 100% |

**산출 근거**: (a) 목표 3bpm = 존 폭(프로필에 따라 약 12~18bpm, 기본 프로필 약 18bpm)의 1/6~1/4 — 경계 오차가 존 판정을 바꾸는 빈도가 무시 가능해지는 수준. (b) 진동폭 기준 = 라벨 자체의 경계대(±4bpm) — 주관 라벨의 고유 산포보다 경계가 더 흔들리면 학습기가 노이즈를 증폭한다는 뜻이므로 이를 상한으로. (c) 이동 한도 10bpm = 잘못된 답 1회의 피해 상한(제어가능성과 공유, 실기기 관찰 이력에서 결정된 값).

| 판정 반영 지연 | 샘플 수신→판정/화면 반영 | 1주기(1초) 내 | 2주기 |

### QA1 검증 결과 상세

| 항목 | 내용 |
|---|---|
| 시나리오 | 코칭 문장에 근거 관측(심박 148, 경계 132~152)에 없는 숫자가 실려 나가려 한다 |
| 검증 방법 | ① 허용 집합={2, 148, 132, 152} 도출 ② 지어낸 숫자 문장 5종(160/145/5/30/존3) + 사실 문장 3종을 NumberGuard에 통과 ③ LlmCallLog에 기록 1:1 여부 + JSON 왕복(구버전 역호환 포함) 테스트 |

### QA2 검증 결과 상세

| 항목 | 내용 |
|---|---|
| 시나리오 | 공식 초기값(약 128bpm)보다 참임계가 12.9bpm 높은 러너(141bpm) — 최대심박 공식 오차와 개인 임계 비율 차이가 결합된 크기다 — 가 8세션 사용, 세션당 말하기 테스트 5회 |
| 검증 방법 | 참임계 기준으로 답을 생성(편함/보통/벅참, ±4bpm 경계대+노이즈)하되 **학습기는 참임계를 모른 채** 갱신. 세션 간 warm-start 포함 폐루프. 세션별 \|μ−참임계\|/이동폭/진동폭 기록 |
| 검증 결과 | 기준 사례: 오차 12.9 → 2.93(1세션) → 1.73bpm(8세션) — 수렴 후에는 라벨 산포 내 진동(0.49~1.73bpm). 스윕: 참임계 5종×시드 3종 15케이스 전부 1~2세션 안착, 최종 0.20~0.77bpm. 오답 라벨 10% 주입 시 최종 0.09bpm. 세션당 이동 최대 9.97bpm — 한도 상한 근접은 초기 세션에서 클램프가 실제로 작동했다는 확인이다 |
| 판정 | **달성(시뮬 층위)** — 감지→적응→안정 루프가 설계대로 동작. 실주행 재확인은 층위 ② |

### QA3 검증 결과 상세

| 항목 | 내용 |
|---|---|
| 시나리오 | "감속하라" 판정인데 LLM이 "속도를 올려봐요!"/"힘내세요!"(무방향)를 낸다 / LLM이 아예 응답하지 못한다 |
| 검증 방법 | ① 실기기 로그에서 수집한 위반 문장 포함 10종을 의도별로 DirectionGuard에 통과 ② 정상 문장 5종의 통과 확인(과차단 검사) ③ 로딩 중 코칭 보류→재개, 페르소나 4종 전 상황 폴백 문구의 가드 전수 통과 테스트 ④ QA2 폐루프에서 이동 한도 위반 0건 확인 |
| 검증 결과 | 위반 기각 10/10(100%), 정상 통과 5/5, 폴백 무중단 확인(관련 테스트 12건), 이동 한도 보장(최대 9.97bpm) |
| 판정 | **달성** — 개입 지점(기각/폴백/한도)이 전부 자동 작동하고 기록됨 |
