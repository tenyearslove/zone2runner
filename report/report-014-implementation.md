## 슬라이드 1 — 홈 화면 (HomeActivity)

**역할**: 앱의 관문. 프로필/최근 기록/AI 모델 상태를 요약하고 모든 기능으로 분기한다.

**주요 기능**:
- **AI 코칭 모델 배너**: Gemini Nano 기능 모델이 준비 안 된 경우에만 표시 — 첫 실행 시 자동 다운로드(MB 단위 진행률), "미준비 상태에서도 규칙 코칭은 정상 동작" 안내(모델 준비 관리, adr-027). 준비 완료 시 배너 자체가 사라진다.
- **내 프로필 / Zone 2 목표 카드**: 활성 프로필(다중 프로필 전환 지원), 나이/안정심박/최대심박 타일, 현재 Zone 2 목표 심박 범위. 학습이 반영된 경우 "공식 초기값 대비 얼마나 상향/하향됐는지 + 근거(N회 러닝 학습)"를 문장으로 보여준다 — 기능적응성(DP3)이 홈에서 바로 보이는 지점.
- **최근 러닝 카드**: 날짜 + 거리/시간/Zone2% 타일, 탭하면 해당 리포트로.
- **액션 버튼 5종**: 러닝 시작(시뮬레이션) / 실센서 러닝(GPS+워치) / 기록 보기 / 프로필 설정 / 설정.
- **온보딩**: 프로필 미설정 시 프로필 화면 자동 진입.

`[📸 스크린샷 1-1: 홈 전체 — 프로필 학습 반영 문구("N회 러닝 학습 반영")가 보이는 상태]`
`[📸 스크린샷 1-2: 홈 상단 — Nano 모델 자동 다운로드 배너(진행률 표시 중)]`

## 슬라이드 2 — 러닝 화면 (RunActivity) ①: 실시간 대시보드

**역할**: 세션의 중심 화면. 지도 + 실시간 판정/코칭. 시뮬과 실센서가 같은 화면을 쓴다(입력 소스만 교체 — DP5의 소스 추상화가 UI 레벨에서 보이는 지점).

**주요 기능**:
- **지도(상단 55%)**: 경로를 존 색으로 칠한 폴리라인 + 현재 위치 마커.
- **심박 + 존 칩**: 큰 숫자(순간 심박)와 표시 존 색(5존, 히스테리시스로 깜빡임 억제 — DP4).
- **존 게이지(ZoneBandView)**: Zone 2 목표 범위 위 현재 위치. **탭하면 "왜 이 범위인가" 설명 팝업** — 규칙 설명이 먼저 뜨고 LLM 자연어 풀이로 비동기 교체(설명용이성, DP1).
- **범례**: "● 순간 심박(존 색 기준) | 얇은 틱 = 60초 평균(코칭 기준)" — 이중 기준 판정(DP4)을 사용자에게도 표시.
- **조언 줄**: 안전 경고(⚠) 최우선, 없으면 드리프트(bpm/분)/경사보정 페이스(GAP).
- **지표 타일**: 시간/거리/페이스 + 경사/케이던스(저케이던스 경고색)/보폭/기온.
- **코칭 문구(🗣) + TTS 음성**: 규칙이 확정한 방향/사실을 LLM이 문장으로(가드 3종 통과분만), 워치 연결 상태 표시.
- **말하기 테스트 팝업**: 주기적으로 "지금 대화가 편하세요?" — 편함/보통/벅참 + [안내] + 건너뛰기(30초 자동 닫힘). 답이 그 자리에서 개인 경계를 움직인다(HITL, DP3).

`[📸 스크린샷 2-1: 러닝 중 전체 화면 — 지도 경로(존 색) + 심박/게이지 + 코칭 문구 표시 상태]`
`[📸 스크린샷 2-2: 존 게이지 탭 → Zone 2 계산 근거 팝업(LLM 풀이 교체 후)]`
`[📸 스크린샷 2-3: 말하기 테스트 3지선다 팝업]`
`[📸 스크린샷 2-4: 안전 경고(⚠ 지속 고심박) 표시 상태 — 시뮬로 유발]`

## 슬라이드 3 — 러닝 화면 (RunActivity) ②: 시뮬레이션/검증 모드

**역할**: 같은 화면의 시뮬 전용 컨트롤 — 검증 도구가 제품 안에 있다(DP5).

**주요 기능**:
- **재생 배속**: ×70/×30/×10/×1 — 60분 세션을 1분 내로 압축 검증.
- **입력 모드 순환**: 자동 시나리오 → 수동 페이스(슬라이더) → 수동 러너(케이던스/보폭/심박보정/경사 슬라이더 4종).
- **가상 러너 선택**: 🎲 랜덤 러너 + 프리셋 — 나이/안정/최대심박/**진짜 임계**/페이스 규율/코칭 반응/코스/기온이 다른 러너로 폐루프 검증(개인화가 그 러너의 진짜 임계로 수렴하는지).
- **LLM 코칭 토글**: 켬/끔 실시간 비교 — 끄면 단어 폴백 경로, 감사 기록에 "rule(LLM 꺼짐)"로 남는다(제어가능성 검증 도구, DP2).
- **프롬프트 뷰**: 누적 사용량(LLM n회/규칙 n회/평균 ms) + 실제 프롬프트 전문.

`[📸 스크린샷 3-1: 시뮬 컨트롤 전체 — 배속 칩 + 가상 러너 카드 + 슬라이더]`
`[📸 스크린샷 3-2: LLM 토글 + 프롬프트 뷰(프롬프트 전문과 누적 카운터가 보이게)]`

## 슬라이드 4 — 리포트 화면 (ReportActivity): 관측 데이터 최대 활용

**역할**: 세션 종료 후 카드 20여 종으로 관측을 다각도 분석해 보여준다. 전부 저장본 렌더(LLM 재호출 없음).

**카드 구성**(렌더 순서): 이전 세션 대비(▲▼) → 오늘 컨디션(효율 vs 개인 기준선) → 세션 추세 스파크라인 → 개인 기록(🏅 신기록 배지) → 기간 요약(7/30일) → **이번 러닝 이야기**(터치=생성 근거 팝업) → 요약 → 존 체류 분포 → 심박 추이(Zone 2 밴드) → 페이스 추이 → 존 타임라인 → 유산소 분석(드리프트→코칭 인과 문장) → 관측 분석 지표(EF/드리프트/서브맥시멀) → km 구간(경사보정) → 경사 분해 → 워밍업 → 내리막 습관 → 초과 원인 분해 → 효율 곡선(이번 vs 직전 산점도) → 개인 Zone 2 학습(start→end) → 경로(존 색) → **코칭 로그** → **LLM 사용**.

**설명용이성이 작동하는 지점**:
- 모든 카드 제목에 **ⓘ 설명 팝업**(20개 지표 사전).
- **코칭 로그의 문장 터치 → 프로비넌스 팝업**: 그 문장의 근거 관측(판정/심박/경계/경사) + 생성 프롬프트 전문 + 채택/기각/폴백 경로 + 지연 — "이 말이 어떻게 만들어졌나"를 문장 단위로 추적(DP1/spec-027).
- **LLM 사용 카드**: 총 호출, LLM 채택 vs 규칙 폴백, 용도별/지연/글자 수/폴백 사유별 카운트 + 앱 메모리. AICore가 별도 프로세스라 LLM 자체 자원은 계측 불가함을 ⓘ에 정직하게 명시(HOTL 감사, DP2).

`[📸 스크린샷 4-1: 리포트 상단 — 이전 대비/컨디션/추세 스파크라인 카드]`
`[📸 스크린샷 4-2: 심박 추이(Zone 2 밴드) + 존 타임라인 카드]`
`[📸 스크린샷 4-3: 코칭 로그에서 문장 터치 → 프로비넌스 팝업(근거+프롬프트 보이게)]`
`[📸 스크린샷 4-4: LLM 사용 카드 전체]`
`[📸 스크린샷 4-5: 효율 곡선(이번 vs 직전) + 구간 분석 카드]`

## 슬라이드 5 — 프로필/이력/설정 화면

**프로필(ProfileActivity)**: 다중 프로필 관리(생성/이름 변경/개인화 초기화/삭제) / **개인화 진행 카드**(단계 라벨 + 러닝 N회/말하기 테스트 N회 + 학습 시각화 + **AI 설명 텍스트, 터치=생성 근거 팝업**) / 심박 정보(0=자동 추정) / 신체 정보(BMI→체형 제안) / 체형/러닝 수준/운동 빈도 5단계 칩 / 관절 보호 토글(내리막 코칭 전환) / **초기 Zone 2 미리보기**(범위 + 신뢰도 ±bpm) — 입력이 경계에 어떻게 반영되는지 저장 전에 보여준다.

**이력(HistoryActivity)**: 세션 카드(날짜 + 거리/시간/평균HR/Zone2%) 목록, 탭=리포트, 길게=삭제.

**설정(SettingsActivity)**: 코칭 빈도 5단계 / 음성(TTS 켬끔/속도/높낮이/목소리 선택+미리듣기) / 코칭 말투 4종(친절한 코치/스파르타 교관/다정한 친구/차분한 안내 — 방향/숫자는 말투와 무관) / 더위 코칭 토글 / 화면 항상 켜기 / **AI 모델 카드**(기능 2종 상태 + 새로고침 + 수동 다운로드) — HOTL 개입 지점 모음(DP2).

`[📸 스크린샷 5-1: 프로필 — 개인화 진행 카드(AI 설명 텍스트 보이게)]`
`[📸 스크린샷 5-2: 프로필 — 초기 Zone 2 미리보기(신뢰도 ±bpm 보이게)]`
`[📸 스크린샷 5-3: 설정 전체 — 말투 4종 + AI 모델 카드 보이게]`

## 슬라이드 6 — 워치 앱 (Wear OS)

**러닝 대시보드(WearRunActivity)**: 베젤형 5존 게이지(270°) + 흰 마커, 경과 시간, 심박 큰 숫자, 존 라벨("Z2 지방연소 · 목표 유지"), 페이스/거리/속도 3열, 시작/일시정지/종료 버튼. **워치는 존을 계산하지 않는다** — 폰이 확정한 존을 1Hz로 받아 그대로 그린다(폰=단일 판정 주체). 폰 판정이 8초 이상 안 오면 존을 지우고 "폰 동기화 중…" 표시(낡은 값으로 우기지 않기 — DP4의 정직성). 시뮬 중엔 미러 모드("시뮬 미러 · 대화 테스트만").

**토크테스트 설문(TalkTestActivity)**: 진동과 함께 전체 화면 3지선다 — 편함(초록)/보통(회색)/벅참(빨강) + 한 줄 힌트. 달리면서 한 번의 탭으로 답할 수 있는 최소 UI. 30초 자동 닫힘, 폰에서 답하면 워치 설문도 자동 닫힘(이중 응답 방지).

**측정(RunService)**: 포그라운드 서비스가 화면이 꺼져도 Health Services 심박/케이던스를 유지 수집해 폰으로 전송(/hr, /spm).

`[📸 스크린샷 6-1: 워치 러닝 대시보드 — 게이지 + 존 라벨(Z2 상태)]`
`[📸 스크린샷 6-2: 워치 토크테스트 3지선다]`
`[📸 스크린샷 6-3: 워치 "폰 동기화 중…" 상태(존 미표시) — 폰 앱 종료로 유발]`

## 슬라이드 7 — 구현이 설계 그대로임을 보이는 연결 고리 (마무리)

| 설계(DP/아키텍처) | 구현에서 확인되는 지점 |
|---|---|
| DP1 설명용이성 | 리포트 ⓘ 20종, 코칭 문장 프로비넌스 팝업, 존 게이지 탭 설명 |
| DP2 제어가능성 | 설정 HOTL 6종, LLM 사용 감사 카드, 시뮬 LLM 토글, 안전 경고 우선 |
| DP3 기능적응성 | 홈의 "학습 반영" 문구, 프로필 개인화 진행 카드, 리포트 개인 Zone 2 학습 카드 |
| DP4 강건성 | 표시 존 무깜빡임, 60초 평균 범례, 워치 "동기화 중"(낡은 값 거부) |
| DP5 테스트가능성 | 시뮬 모드가 제품 기능(배속/가상 러너/수동), 같은 화면 코드로 실센서/시뮬 |
| 최종 아키텍처 | 화면 = 운영 서비스(D1), 각 카드 = 분석(C)/설명(B) 서비스의 표시 계층 |
