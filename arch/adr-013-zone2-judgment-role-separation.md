# ADR-013: Zone2 판정 역할 재분리 — 규칙 판정 전환과 NN 재조준(개인 심박 동역학 모델)

> **⚠ 부분 대체 (2026-07-10, adr-024)**: 본 ADR의 **"판정 = 규칙"** 결정은 **유효(정본)**. 다만 **"NN 재조준 = 개인 심박 동역학 예측 모델"** 절반은 예측 드롭으로 **폐기** — 그 자리는 관측 데이터 분석 엔진(adr-024)과 자체 NN 0개 재정립(adr-025)으로 대체됐다. 본문의 NN/예측 서술은 역사 기록으로 읽는다.

- **상태**: Accepted (2026-07-03 사용자 승인 / 2026-07-10 예측 절반 adr-024로 대체)
- **날짜**: 2026-07-03
- **결정자**: coolove + Claude

## 맥락

실기기 시뮬 검증에서 "지속 심박(60초 평균)이 개인화 상한을 42bpm 초과했는데 판정=미달"이 발생했다.
모델 순전파 재현 결과, 원인은 시뮬레이터 라벨 순환 — 학습 데이터에서 "심박 급강하(dHR 음수)는 곧 존
아래로 감"이 상관되어, MLP가 추세(dHR)로 절대 위치(hr_norm_u)를 압도하는 지름길을 학습했다
(dHR≤-0.5면 상한 +0.30 HRR 초과에도 확률 ~1.0으로 미달 출력. 회귀 테스트로 고정).

이 사건이 드러낸 구조 문제는 두 가지다.

1. **진실이 두 개**: "Zone2가 어디냐"를 개인화 경계(Bayesian, adr-004)가 답하는데, 판정은 그 경계와
   비교하지 않고 별도 학습된 분류기(adr-005)가 낸다. 화면의 밴드와 판정 칩이 서로 모순될 수 있는
   구조 자체가 결함이다.
2. **라벨과 지표의 자기참조**: 판정 MLP의 라벨을 시뮬레이터가 생성했고, 성능 지표(acc 0.826,
   방향일치 0.996 — 구 QA1 지표, 현 체계에선 QA4 제어가능성 계열)도 같은 시뮬레이터 라벨로 채점했다. "판정이 정확히 무엇에 대한 분류인가"(현재 지속
   상태인가, 곧 도달할 상태인가)를 spec에서 정의하지 않은 채 구현으로 넘어갔다.

재점검을 위해 파이프라인 전 구간(센싱/판정/경계/코칭/분석)에서 NN 후보를 전수 조사했다.
기준: 정답 라벨의 정직성 / 비선형 필요성 / 제품 가치. 결과, 세 기준을 동시에 통과하는 자리는
**개인 심박 동역학 모델**(입력: 페이스/경사/케이던스/경과시간/현재 심박 → 출력: 30~60초 뒤 심박)
하나뿐이다. 나머지 후보(판정 분류/경계 회귀/prior 학습/HRV 임계/코칭 정책)는 전부 라벨 부재 또는
순환으로 탈락 — 이는 이 도메인의 본질(경계 참값 부재, spec-001 C04)에서 오는 성질이다.
운동 중 심박 동역학 모델링은 트레드밀 자동 제어 계열의 기존 연구 축적이 있는 정통 문제다.

과제의 본질(사람마다 다른 Zone2 경계를 prior로 예측하고 실주행 관측으로 보정)은 Bayesian
개인화 + 토크테스트/디커플링 관측 채널이 담당하며 이 부분은 유지한다. 교육과정 요건(실제 NN
설계/학습/산출)도 유지해야 한다.

## 결정

### 대안 비교

| 기준 | A: 규칙 판정 + 심박 동역학 NN | B: 판정 MLP 유지, 라벨 재정의 재학습 | C: NN=경계 보정 회귀 |
|------|---------------------------|-----------------------------------|--------------------|
| 판정-밴드 모순 가능성 | 구조적으로 불가능(같은 경계 비교) | 남음(모델이 경계 밖 판정 가능) | 구조적으로 불가능(판정은 규칙) |
| 라벨 정직성 | 정답=실제 미래 심박(순환 없음) | 라벨을 다시 시뮬이 정의(함정 재발 위험) | 경계 참값이 없어 라벨을 또 시뮬에 의존 |
| NN의 존재 이유(왜 AI) | 강함 - 심박 지연 30~60초의 비선형/개인차 동역학은 규칙로 불가 | 약함 - 재정의하면 규칙과 거의 동일한 함수가 됨 | 중간 - Bayesian과 역할 중복 |
| 제품 가치 | 목표 페이스 제안 + 선제 코칭 + 드롭아웃 브리지 | 현행과 동일(사후 코칭) | 개인화 수렴 가속(간접적) |
| 개인화와의 관계 | 예측 오차가 새 관측 채널(prior 오차의 증거) | 무관 | 개인화 자체를 대체/중복 |
| 실주행 데이터 활용 | 필드 로그로 채점/재학습 가능(자기지도) | 필드에 참 라벨이 없어 채점 불가 | 동일하게 참값 없음 |
| 구현 비용 | 중 - 학습 파이프라인 재사용(회귀 헤드), 판정 규칙+히스테리시스 추가 | 소 - 라벨 재생성+재학습 | 중 - 관측 모델 재설계 |
| 성능의 정직한 채점 | 가능 - 지속 예측(persistence)/선형 외삽 대비 RMSE | 불가(시뮬 라벨 채점) | 불가 |

### 대안 A: 판정=규칙, NN=개인 심박 동역학 모델 (채택)

역할을 세 층으로 재분리한다.

- **경계(진실은 하나)**: 개인 Zone2 경계 = Bayesian 개인화(prior + 관측 보정, adr-004/012). 변경 없음.
- **판정(규칙)**: 지속 심박(60초 평균) vs 개인화 경계의 결정적 비교 + 히스테리시스(경계 ±2bpm,
  최소 유지 시간)로 채터링 억제. 설명 가능, 모순 불가능.
- **NN(재조준)**: 개인 심박 동역학 모델 — 현재 심박/추세/페이스/경사/케이던스/경과시간 -> 30초, 60초 뒤 심박 회귀.
  라벨 = 실제 미래 심박(시뮬 학습, 필드 로그로 검증/재학습 가능, 순환 없음).

NN의 용도(하나의 모델, 네 얼굴):

1. **Zone2 목표 페이스 제안(대표 용도)**: 모델을 역질의 — 후보 페이스들을 넣어 "심박이 밴드 안에
   머무는 페이스"를 찾아 제시. "당신의 Zone2는 138bpm"(추상적, 30초 지연 신호)을
   "지금은 6'30"/km로 뛰세요"(즉시 실행 가능)로 번역한다. 경사/피로(경과시간)가 자동 반영되어
   오르막/후반부에서 제안이 스스로 조정된다. 심박-페이스-경사-시간 관계는 비선형이고 개인차가
   크므로 규칙로 불가 — NN 필요성의 실체.
2. **선제 코칭**: 판정이 IN이라도 예측이 상한 초과를 가리키면 "곧 넘어요, 미리 낮추세요".
   심박은 30~60초 지연 신호이므로 사후 코칭은 구조적으로 늦다 — 예측만이 존 체류 시간을 직접 개선.
3. **개인화 관측 채널**: 예측 오차가 한쪽으로 쏠리면 prior가 이 사람을 잘못 봤다는 증거 -> Bayesian 갱신 재료.
4. **드롭아웃 브리지**: 워치 심박 끊김 시 수십 초 예측으로 판정/코칭 유지.

서사: "경계는 Bayesian이 추정하고, 그 경계를 달릴 수 있는 페이스로 번역하는 것이 NN" — 두 AI
컴포넌트가 중복이 아니라 한 줄로 이어진다.

- 장점: 판정 모순의 구조적 제거, 라벨 정직성, NN 필요성이 생리학(심박 지연/개인차)에서 직접 도출,
  실주행 로그가 곧 학습/평가 자산, 성능을 baseline 대비 RMSE로 정직하게 채점 가능
- 단점: adr-005/spec-006 Supersede와 지표 재정리 필요, 학습/통합 재작업, 페이스 제안의 실효는 검증 전

### 대안 B: 판정 MLP 유지 + 라벨 엄격 재정의 후 재학습

라벨을 "지속 심박 vs 참경계의 결정적 함수"로 재정의하고 추세 누수를 제거해 재학습한다.

- 장점: 아키텍처 변경 최소, 기존 문서/지표 체계 유지
- 단점: 그렇게 고치면 MLP가 학습하는 함수가 규칙 비교와 사실상 동일해져 "왜 NN인가"가 붕괴,
  진실 두 개 구조와 모순 가능성은 잔존, 라벨 정의 주체가 여전히 시뮬레이터(같은 함정 재발 위험)

### 대안 C: NN=경계 보정 회귀(세션 특징 -> 경계 오차 추정)

판정은 규칙으로 바꾸되, NN을 개인 경계 오차 추정기로 쓴다.

- 장점: 과제 원래 목표(개인 경계 정밀화)에 NN을 직접 투입
- 단점: 경계 참값이 없어(C04) 라벨을 또 시뮬레이터가 만들어야 함 - 이번 결함과 같은 순환 구조,
  Bayesian 개인화와 역할 중복(둘 중 하나가 형식적 존재가 됨)

### 채택: 대안 A

판정 모순을 구조적으로 제거하면서 NN을 "정답이 존재하는 문제"로 옮기는 유일한 안이며, NN이
사용자에게 만져지는 형태(목표 페이스)로 개인화를 완성한다. 파이프라인 전수 조사에서 라벨 정직성을
통과한 유일한 자리이기도 하다.

## 결과

- 긍정: 판정-밴드 모순 재발 불가, 코칭이 사후 수습에서 사전 예방으로, "몇 분/km로 뛰라"는 실행
  가능한 개인화 출력, 필드 로그가 학습 자산화, adr-002 코칭 구조(규칙이 방향 결정)는 그대로 유지
- 부정/비용: spec-006(MLP 판정기)과 adr-005는 Superseded로 전환하고 경위를 기록,
  EXPERIMENT_LOG의 판정 지표는 "시뮬 라벨 기준"임을 명시하고 예측 RMSE 체계로 대체,
  report-002/003의 AI 컴포넌트 서사 수정, ml 파이프라인(학습/export)과 앱 통합 재작업
- 이행 순서: spec-014(심박 동역학 모델) 작성 -> ml 학습/평가(persistence, 선형 외삽 baseline 대비
  RMSE) -> export -> 앱 통합(규칙 판정+히스테리시스, 페이스 제안, 선제 코칭) -> 문서 환류
- 개인화 관측 채널(용도 3)과 드롭아웃 브리지(용도 4)는 후속 단계로 유보 — 유보 자체가 설계 판단
- 판정 지표의 재정의: "판정 정확도"(시뮬 라벨 채점)는 폐기. 새 지표 = 예측 RMSE(baseline 대비)
  + 존 체류 시간(시뮬/필드), 코칭 방향(구 QA1 — 현 체계에선 QA4 제어가능성 소관)은 규칙 판정 기준으로 재측정
