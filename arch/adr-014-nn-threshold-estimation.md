# ADR-014: 개인 젖산역치(Zone2 상단) 추정에 경량 신경망 도입

- **상태**: Accepted
- **날짜**: 2026-07-04
- **결정자**: coolove + Claude

## 맥락

프로젝트의 원래 목적은 "사람마다 다른 Zone2를 랩 측정 없이 더 정확하게 추정"이다. Zone2 상단은
유산소 임계(LT1) 부근으로 참값은 랩의 젖산/가스교환 측정으로만 얻어지며(spec-001 C04), 손목 기기로는
원천적으로 불가하다. 통용 공식(%HRR, %HRmax)은 개인차를 담지 못한다.

adr-005/006에서 판정용 MLP를 검토했으나 라벨 순환 결함으로 adr-013에서 판정을 규칙으로 전환했다.
그럼에도 교육과정 요건("작은 부분이라도 실제 NN을 설계/학습/모델 산출")과 "개인 경계를 더 정확히"라는
본래 목적을 함께 만족할 NN의 자리를 재정의할 필요가 있다.

선행연구 조사 결과, 심박/페이스/케이던스 등 다신호와 젖산역치의 관계를 신경망으로 모델링해 랩 없이
역치를 추정하는 접근이 검증되어 있다:
- Etxegarai et al. (2018, Applied Soft Computing): 순환신경망으로 레크리에이션 러너의 젖산역치를
  실측과 상관 R=0.89, 89.5% 성공률로 추정.
- Zhu et al. (2025, Engineering Applications of AI): 전이학습 기반 RNN으로 실주행 데이터에서 역치심박
  MAE 4.37 bpm(통제)/9.18 bpm(실주행).
- Rogers et al. (2021, Frontiers): DFA-α1(HRV 비선형 지표) = 0.75가 유산소 임계에 대응 -> 무랩 검증 채널.

이들 연구는 "이 관계가 비선형적이고 개인차가 커서 신경망이 유리하다"는 것을 방법의 근거로 제시한다.
본 ADR은 이 타당성에 근거해 신경망을 도입하되, 1인 교육과제 규모에 맞춘 경량 형태를 결정한다.

## 결정

### 대안 비교

| 기준 | A: 경량 MLP(문헌 축소) | B: RNN 전이학습(논문 원형) | C: NN 없이 공식+Bayesian |
|------|----------------------|--------------------------|------------------------|
| 문헌 근거 | Etxegarai/Zhu 접근의 경량화 | 논문 그대로 | 없음(공식만) |
| 교육요건(실제 NN) | 충족 | 충족 | 미충족 |
| 구현 복잡도 | 낮음(기존 순전파 재사용) | 높음(시퀀스+전이 파이프라인) | 최저 |
| 개인차 반영 | 특징 기반 + Bayesian 누적 | 전이학습 fine-tune | prior만(개인 관측 약함) |
| 1인 과제 적합성 | 적합 | 과함 | 적합하나 NN 없음 |
| 무랩 검증 | 토크테스트/DFA-α1 정합 | 동일 | 동일 |

### 대안 A: 경량 MLP (채택)

- 입력: 러닝 세션에서 추출한 특징 벡터(여러 강도 구간의 안정 심박, HR/페이스 비율, 심박 드리프트,
  케이던스, 나이, 안정심박 등) -> 개인 역치 심박(=Zone2 상단) 회귀.
- 모델: 소형 MLP(입력 -> 16 -> 8 -> 1, ReLU). 순수 Kotlin 순전파(adr-011)로 온디바이스 추론 —
  기존 인프라 재사용, 새 런타임 불필요.
- 학습: 물리 시뮬레이터로 러너마다 다른 참 역치를 가진 세션을 생성해 지도학습(라벨=시뮬 참 역치).
- 개인 적응: NN이 세션 관측으로 역치 추정치를 내면, 기존 Bayesian(adr-004)이 prior와 융합해 누적 수렴.
  즉 NN=관측 산출기, Bayesian=시변 개인 적응.
- 검증: 랩 참값 부재로 절대 정확도는 검증 불가. 무랩 서로게이트(토크테스트, DFA-α1)와의 정합 +
  세션 누적 수렴 + 체력 변화에 대한 합당한 반응으로 타당성 확인.

장점: 문헌 근거가 서고 교육요건 충족, 구현이 가볍고 기존 자산(시뮬/순전파/Bayesian/토크테스트) 재사용,
개인차를 특징으로 직접 반영.
단점: 논문 원형(RNN/전이학습) 대비 표현력 축소 — 이는 규모 대비 이득 불명확에 따른 의도적 경량화로 명시.

### 대안 B: RNN 전이학습(논문 원형)

- 장점: 시계열 이력/전이학습으로 이론적 표현력 최대, 논문과 동일.
- 단점: 시퀀스 모델 + 전이 파이프라인 = 1인 과제 과부하, 온디바이스 런타임 부담, 산출/디버깅 비용 큼.

### 대안 C: NN 없이 공식 + Bayesian

- 장점: 최소 복잡도, 이미 동작.
- 단점: 교육요건(실제 NN) 미충족, 개인 경계 추정을 공식 prior에 크게 의존.

### 채택: 대안 A

문헌 근거로 신경망 도입을 정당화하면서 교육요건과 본래 목적을 함께 만족하는 유일한 경량 안이다.
논문 원형을 1인 과제 규모로 축소한 것임을 명시하고, 절대 정확도 대신 무랩 정합/수렴으로 검증한다.

### 경량화 매핑 (논문 -> 본 프로젝트)

| 축 | 논문(Etxegarai/Zhu) | 본 프로젝트 | 근거 |
|----|--------------------|------------|------|
| 모델 | RNN(시계열 순환) | 소형 MLP(집계 특징) | 단계별 요약 특징 -> 순환 불필요 |
| 입력 | 원시 심박 시계열 | 특징 벡터(~8) | 시간축 표준화/층화샘플링 제거 |
| 개인화 | 전이학습 fine-tune | 사전학습 + Bayesian 누적 | NN 고정, 적응은 기존 Bayesian |
| 검증 | 랩 젖산 실측 | 토크테스트/DFA-α1 정합 | 랩 접근 불가 -> 무랩 서로게이트 |
| 런타임 | - | 순수 Kotlin 순전파 | 온디바이스 경량(adr-011) |

## 결과

- 긍정: "왜 NN인가"가 문헌으로 방어됨, 교육요건 충족, 기존 자산 최대 재사용, 개인 Zone2 추정이라는
  본래 목적 복원. 판정(규칙, adr-013)과 역할 분리 유지 — NN은 경계 추정, 규칙은 판정.
- 부정/한계(명시): 랩 참값 부재로 절대 정확도 미검증(무랩 정합으로 대체), 논문 대비 표현력 축소,
  시뮬 학습의 한계(실데이터 fine-tune은 향후 과제 — 필드 로그 spec-012 활용 가능).
- 이행: spec-015(역치 추정 MLP 명세) -> ml 학습/export -> 앱 통합(ThresholdEstimator + Bayesian prior 연결)
  -> 무랩 검증(토크테스트/DFA-α1). DFA-α1 관측 채널은 후속.
