# ADR-028: 코칭 표현 정본 전환 — LLM 직생성 1순위 + 단어 수준 폴백

- **상태**: Accepted (2026-07-23, 사용자 결정) / Implemented
- **관련**: adr-002(방향=규칙/표현=LLM — 골격 유지, 폴백 문구 계층만 이 ADR로 개정), adr-026(Rewriting 톤 재작성 1순위 — **이 ADR로 코칭 경로에서 폐지**, Summarization은 유지), spec-005(LLM 코칭), spec-024(페르소나), spec-027(감사 기록), spec-028(상세 명세), arch/dp/dp-02-controllability(판단=규칙 불변 — 이 ADR은 표현층만 변경)

## 맥락

사용자 방향 확정: **"이 앱은 언어를 생성하는 앱이 아니다 — 문구 조합에 노력을 쓰지 말고 언어는 LLM에 맡긴다. LLM이 있는데 안 쓸 이유가 없다. 폴백은 문장이 아니라 거의 단어 수준으로."**

현행은 반대에 가깝다: 규칙 문장 세트(4페르소나 × 상황별, 수십 문장)가 콘텐츠의 정본이고, LLM은 그 문장의 톤만 재작성(adr-026 1순위)하거나 미가용 시 아예 빠진다. 이 구조는 (a) 문구 세트 유지보수(사람이 언어 조합)를 계속 요구하고, (b) 같은 상황에 같은 문장이 반복되며(자연스러움의 실제 약점), (c) 언어마다 문장 세트를 다시 써야 해 다국어가 사실상 막힌다.

## 대안 비교

| | A. 현행 (규칙 문장 정본 + LLM 톤 재작성) | **B. LLM 직생성 1순위 + 단어 수준 폴백 (채택)** | C. LLM 판단 위임 |
|---|---|---|---|
| 문장 정본 | 사람이 쓴 문구 세트 | LLM(간결 구조화 프롬프트: 사실+지시+말투+언어) | LLM |
| 판단(방향/안전) | 규칙 | **규칙(불변)** | LLM |
| 폴백 | 페르소나 4벌 문장 세트 | **단어 수준 큐 10여 개**("속도 줄이기/올리기/유지" 등) — 미지원 단말/일시 실패 시에만 | 없음(침묵) |
| 다국어 | 언어마다 문장 세트 재작성 | LLM=언어 지시 한 줄, 폴백=단어 10여 개 표준 리소스 번역 | LLM |
| 판정 | 문구 유지보수 지속, LLM이 장식으로 전락 | **채택** — 언어는 LLM, 통제(방향/가드/폴백/감사)는 규칙 | DP-02에서 기각(제어가능성) |

## 결정

**B 채택.**
1. **1순위 = Nano Prompt 직생성**: 규칙이 확정한 사실/지시를 **간결한 구조화 프롬프트**(상황 숫자 + 임무 + 말투 한 단어 + 언어)로 주고 LLM이 문장을 만든다. **특수 코칭(마일스톤/워밍업/회복/오르막 예방/관절 보호)도 LLM 직생성에 포함**(임무 문구로 지시).
2. **Rewriting 톤 재작성 경로 폐지**(코칭): 입력이 규칙 문장을 전제하므로 이 결정과 모순. Summarization(리포트 요약, 입력=사실 텍스트)은 유지.
3. **폴백 = 단어 수준 큐**: 페르소나 문장 세트를 폐기하고 방향/특수별 큐 10여 개로 대체("속도 줄이기", "회복 중", "내리막, 무릎 보호, 보폭 줄이기" 등). LLM 미지원 단말이거나 호출이 실패/기각된 그 순간에만 나간다. 페르소나는 LLM 프롬프트 파라미터로만 존재(폴백은 중립 — 비상용).
4. **출력 가드레일 강화(언어 의존 축소)**: 형식 가드(길이/문장 수/이모지) + **숫자 무결성 가드 신설**(출력의 모든 숫자 ⊆ 입력 사실의 숫자 — "없는 숫자 금지"의 기계 검증, 언어 무관) + 방향 가드(한국어 키워드, 방향 코칭만; 특수 코칭 중 워밍업/오르막 예방/관절 보호는 가속 명령만 금지).
5. **안전 불변**: SafetyGuard(위험 심박)는 계속 LLM 미경유 규칙 직행(spec-008).
6. **다국어 구도**: 문장=LLM(프롬프트 언어 지시), 폴백/UI=표준 문자열 리소스. 1차 구현은 한국어, 구조는 언어 파라미터 수용형.

## 결과 / 정직한 트레이드오프

- 지원 단말에서 코칭 문장의 정본이 LLM이 된다 — 반복 문제 해소, 문구 유지보수 소멸, 다국어 길이 열림.
- **채택률 리스크**: 자유 생성은 톤 재작성보다 방향/형식 기각률이 높을 수 있다. 간결 프롬프트의 방향어 강제 지시 + 감사 기록(spec-027 기각/폴백 사유)으로 실측하며 튜닝한다. 기각의 비용은 "그 1회가 단어 큐로 나감"이지 중단이 아니다.
- **미지원 단말 경험 하락(의도된 선택)**: 문장 코칭 대신 단어 큐 — 화면 존 표시/게이지가 주 전달 수단이 된다.
- DP-02 구도(판단=규칙, 계층 가드레일, 폴백, 감사)는 불변 — 폴백 계층의 내용물이 문장→단어로 바뀔 뿐이다.
