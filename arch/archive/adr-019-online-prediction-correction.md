# ADR-019: 심박 예측의 온라인 개인 보정 (실주행 오차로 학습)

> **대체됨(2026-07-08 정리)**: 보정 대상이던 심박 예측 NN이 adr-020(생리 ODE)으로 폐기됨. 이 ADR의 핵심 원리(실주행 오차 기반 온라인 점추정)는 adr-020의 ODE 파라미터(τ/드리프트/수요) 온라인 추정으로 승계되어 살아있고, 이 문서 자체는 NN 보정 시점의 역사 기록이다.

- **상태**: Superseded by adr-020 — 원 상태: Accepted
- **날짜**: 2026-07-05
- **관련**: `spec/spec-018-online-prediction-correction.md`, `arch/adr-016`(도구 선택), `arch/adr-004`(Bayesian 개인화), `spec/spec-014`(심박 예측 NN)

## 맥락

DP1의 심박 예측 NN(HrDynamics)은 시뮬레이터로 오프라인 학습된 "평균 러너" 모델이고, 폰에선 추론만
한다. 실주행에서 "페이스 변화가 없는데 60초 뒤 예측과 실제가 크게 다른" 경우가 있다 — 개인의 심박
동역학(반응 속도 τ/드리프트/현재 피로)이 평균과 다르기 때문. 이 오차 신호를 지금은 버린다.

## 결정

**기본 NN 예측 위에 개인 잔차를 온라인 학습해 보정한다.** DP2(Bayesian 경계 개인화)와 같은 철학 —
평균 모델 + 온라인 개인 보정. 매초 "과거 예측 vs 지금 실제"를 비교해 잔차 선형 모델을 LMS로 갱신한다.

- 잔차 모델: `residual_frac = w·[1, hr_sus_frac, dHR, elapsed_min]` (수평선 30/60 별도). 페이스 무관
  특징만 사용 → 추천 페이스 역질의와 정합(보정량만큼 밴드를 이동해 base 스윕).
- 보정 예측 = base_NN + clamp(잔차). 폭주 방지 clamp(±0.12 HRR frac).
- **페이스 게이팅**: 예측은 "이 페이스 유지 시" 조건부이므로, 예측 시점 페이스와 만기 시점 페이스가
  유지(±0.6 min/km)된 샘플만 학습에 쓴다. 페이스를 바꿨으면 예측이 틀린 게 아니라 조건이 바뀐 것.
- 세션 종료 시 가중치를 `LearnedDynamics`에 저장 → 다음 세션이 이어서 학습(LearnedZone과 동형).
- base vs corrected RMSE를 추적해 보정 효과를 수치로 검증.

## 대안 비교

| 대안 | 장점 | 단점 | 판정 |
|------|------|------|------|
| A. 온디바이스 NN 풀 재학습(역전파) | 표현력 최대 | 무겁고 catastrophic forgetting, 순수 Kotlin 추론 구조에 과함 | 기각 |
| **B. 온라인 잔차 보정(LMS, 채택)** | 경량/온디바이스, Bayesian 개인화와 정합, 페이스 게이팅 가능, 효과 측정 | 선형 잔차라 표현력 제한 | **채택** |
| C. 실주행 로그 → 오프라인 재학습만 | 기본 모델 자체 개선 | 즉시성 없음, 데이터 파이프라인 필요 | 보완(후속) |

C(로그 저장 후 오프라인 재학습)는 기본 모델을 시뮬→실데이터로 갈아끼우는 상보적 후속 과제로 남긴다.

## 근거 (adr-016 정합)

"AI ≠ NN": 기본 동역학은 데이터가 풍부한 오프라인 NN, 개인 편차는 소수/온라인이라 **온라인 재귀
학습(LMS)**이 맞는 도구. DP2와 같은 "평균 prior + 온라인 개인화" 패턴을 예측에도 적용한 것.

## 리스크/유보

- 선형 잔차의 표현력 한계 → clamp로 안전, 필요 시 특징 확장.
- 실제 심박(hr_now_frac)의 노이즈 → 지속(sus) 기반 특징과 LMS 평활로 완화.
- 페이스 게이팅이 느슨하면 조건 오염 → 허용치 보수적(±0.6). 데이터로 조정.
