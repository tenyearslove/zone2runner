# DP-03 리서치 노트 — 개인 경계 적응(기능적응성) 근거

> DP-03 본문(`dp-03-adaptability-decision.md`)의 근거 문헌 정리. 기존 리서치(spec-013/016, adr-004/012/025 작성 시 수행)를 이 DP 관점으로 재정리 + 강의 정본(framework/) 대조.

## 1. 기능적응성의 공식 정의

- **강의 정본(framework/ai-8-qa.md)**: 기능적응성 = 환경/대상 변화에 대해 **감지(Detection) → 적응(Adaptation) → 회복/안정(Stabilization)** 하는 진화적 적응 능력. 측정 = Quality Recovery(수렴 오차 감소), Time to Stabilization(안착까지 걸린 시간), Stability Index(안정 후 진동폭).
- **spec-002 QA2**: 세션 누적 + 변화 신호(드리프트/기온/말하기 테스트)를 적응 트리거로 → 개인 Zone 2 경계 온라인 Bayesian 갱신. 측정 = 수렴오차↓ vs 세션수, 안착 세션수, 세션 간 경계 진동폭.

→ DP-03의 평가 기준: "변화가 경계에 반영되기까지 얼마나 걸리는가(적응 지연), 수렴이 안정적인가, 적응 근거를 검증할 수 있는가".

## 2. 베이지안 온라인 갱신 — 표준 통계 방법

- **켤레 정규 갱신(Normal-Normal conjugate update)**: 사전 N(μ0, σ0²)에 관측(신뢰도 σobs²)이 들어오면 사후 평균이 두 분산의 역수 가중 평균으로 도출된다. **가중이 임의 상수가 아니라 두 불확실성에서 공식으로 나온다** — CLAUDE.md "값은 구조에서 도출" 원칙의 통계적 정본. 표준 교과: Gelman et al., *Bayesian Data Analysis* (3rd ed.).
- 이 시스템의 구현: `Zone2Prior`/`Personalization`(spec-004, spec-013, spec-016) — prior/σ0 층위와 관측 σ 크기의 근거는 spec-013/spec-016에 문서화(종류 C 상수 규율).

## 3. 온라인 적응 vs 배치 재학습 — concept drift 문헌

- **Gama et al., "A Survey on Concept Drift Adaptation", ACM Computing Surveys 46(4), 2014**: 변화하는 대상(개념 표류)에 대한 표준 대응 분류 — 온라인/증분 갱신(표본 단위 즉시 반영) vs 주기적 재학습(배치). 온라인 계열의 강점 = 적응 지연 최소, 배치 계열의 강점 = 노이즈 평균화/복잡 모델 사용 가능.
- 시사점: DP-03의 두 안이 이 분류의 양 끝과 정확히 대응. 결정축(적응 지연)도 이 문헌의 축과 일치.

## 4. 라벨의 검증 가능성 — 말하기 테스트

- **Persinger et al. (2004)** 및 후속 체계적 리뷰(2022): Talk Test의 "대화가 불편해지는 지점"이 제1환기역치(VT1)와 근사 — 실험실 장비 없이 얻을 수 있는 실용 임계 지표. 이 시스템의 3단계(편함/보통/벅참) 전환 근거 = spec-016.
- 시사점: 참값(랩 측정) 없는 조건에서 **사용자 실제 답이 유일하게 검증 가능한 적응 라벨**. 예측값을 라벨로 쓰면 자기참조(짜고치기)가 된다(adr-024의 교훈과 동일 구조).

## 5. 콜드스타트 사전값의 근거와 한계

- **Tanaka, Monahan, Seals (2001)**: HRmax = 208 − 0.7×나이. 220−나이보다 개선된 식이지만 **개인 표준편차 ±10bpm 수준** — 공식만으로 개인 경계를 고정하면 코칭이 계통적으로 어긋날 수 있다는 근거.
- 이 시스템의 층위: 공식 = 콜드스타트 출발선(종류 C, 문헌 근거) / 이후 = 실라벨 적응(종류 B 학습값). 안정심박 사다리 = spec-009, 갱신 방향 제약(위로만/아래로만) = adr-012.

## 6. 안전장치(폭주 방지)의 근거

- 세션당 경계 이동 한도 ±10bpm clamp = spec-004/DP-02 공유(제어가능성 측정 항목 "경계이동 ≤10bpm 보장률", spec-002 QA3).
- 불확실도 동반 추정(확신 폭이 라벨 하나의 영향을 자연 제한) = 베이지안 구조 자체의 성질(§2) — 별도 휴리스틱이 아님.

## 7. 2안(오프라인 재학습 개인화)의 실제 위상

- 산업 개인화/추천의 주류 = 수집 → Data Lake → 주기 재학습 → 레지스트리 → 배포(MLOps 재학습 루프). 강의 정본의 AI Development Subsystem(데이터셋 구축/Model Construction/모델 테스팅/Registry + Retraining)과 대응 — 카운터 도식이 이 표준 구성을 따른다.
- 2안이 우선되는 조건(정직): 대규모 사용자(코호트), 서버 인프라, 라벨/검증 체계(예: 랩 측정 코호트) 확보. 연합 학습(federated learning) 등 온디바이스 절충안도 이 계열의 변형이나, 서버 집계 인프라 전제는 동일.

## 8. DP-01/DP-02와의 관계

- 같은 아키텍처의 세 번째 QA 단면: DP-01 "설명이 판단 근거와 일치하는가", DP-02 "출력을 통제할 수 있는가", DP-03 "**경계가 개인을 따라가는가**". 투명한 추정(평균/확신 폭 노출)이 설명(DP-01)을, 이동 한도/라벨 채널이 통제(DP-02)를, 온라인 갱신이 적응(DP-03)을 각각 떠받친다.
