# 즉시 반응 판정 아키텍처 컴포넌트 카탈로그 (설계 B)

- **상태**: 검토용 v1 (2026-07-31). 강건성 DP의 **대안(설계 B)** 아키텍처를 우리 것과 **같은 방식**으로 식별/서술한다. 이는 우리가 구현한 게 아니라, 공정 비교를 위한 **가정 설계**(가장 단순한 평활-직결 구성)다.
- **도식**: `images/dp-04-robustness-counter-detailed.png`(상세) + `images/dp-04-robustness-counter-simple.png`(축약).
- **핵심 대비(우리 vs 카운터)**: 우리는 성격이 다른 방어 4층(범위 차단/이중 기준/통계 평탄화/소스 폴백)을 겹치고, 카운터는 **이동평균 한 층**이 유일한 방어다. 우리는 표시와 코칭의 기준을 분리하고, 카운터는 같은 값이 표시와 지시로 함께 간다.

---

## A. 파이프라인

### A1. 이동평균 평활기
- **표준 매핑**: 데이터 준비(평활) / **책임**: 최근 N초 이동평균으로 원시 신호를 다듬는다 — **유일한 방어층**. **우리와 차이**: 창 N 하나가 스파이크 억제(긴 창 유리)와 반응성(짧은 창 유리)을 동시에 감당해야 한다. 범위 검사/유효기간 검사가 없어 생리 범위 밖 값과 낡은 값도 평균에 섞인다.

### A2. 순간값 존 판정기
- **표준 매핑**: 모델 서빙(규칙 비교) / **책임**: 평활값을 경계와 즉시 비교해 존 판정. **우리와 차이**: 문턱이 하나라(히스테리시스 없음) 경계 근처에서 판정이 초 단위로 번복될 수 있고, 판정 입력이 순간값이라 잠깐 스친 이탈도 상태 변화가 된다.

### A3. 코칭 트리거 (판정 직결)
- **표준 매핑**: 운영 서비스 연계 / **책임**: 판정 변화를 그대로 코칭 트리거로 사용 — 반응 지연 수 초(2안의 강점). **우리와 차이**: 표시와 지시가 같은 값에 매여, 평활이 놓친 노이즈가 행동 지시로 직행할 수 있다. 우리는 코칭 판정의 입력을 60초 평균 심박(지속심박)으로 따로 둔다.

### A4. 마지막 값 유지기
- **표준 매핑**: (두절 대응) / **책임**: 신호 두절 시 마지막 값을 유지해 판정 지속. **우리와 차이**: 유효기간 판단이 없어 두절이 길어도 낡은 값으로 계속 판정한다. 우리는 staleness 기준으로 폐기하고 소스 폴백/보류로 전환한다.

## B. 파라미터

- 평활 창 N = 전역 고정(모든 사용자 동일). **우리와 차이**: 우리 노이즈 문턱은 개인 관측 노이즈의 배수(k·σ)로 자가 보정 — 노이즈가 큰 사용자와 깨끗한 사용자에서 같은 오경보율을 유지한다.

## 요약 — 무엇이 다른가

| 축 | 우리 (설계 A: 계층 방어 판정) | 카운터 (설계 B: 즉시 반응 판정) |
|---|---|---|
| 방어 층수 | 4층(성격별 분담) | 1층(이동평균) |
| 범위 밖 값 | 문에서 기각 | 평균에 희석되어 통과 가능 |
| 경계 근처 번복 | 히스테리시스로 억제 | 억제 장치 없음 |
| 표시 vs 지시 | 기준 분리(표시 빠름/지시 엄격) | 같은 값 직결 |
| 개인차 | k·σ 자가 보정 | 전역 고정 창 |
| 두절 | 유효기간 폐기 + 폴백/보류 | 마지막 값 유지(낡은 값 판정) |
| 반응 지연 | 표시 즉시 / 코칭 최대 60초 | 수 초 — 이 축은 카운터 우위 |
| 구조 복잡도 | 층 4개(모듈 분리) | 최소 — 이 축은 카운터 우위 |
