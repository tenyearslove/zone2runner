# DP-04 리서치 노트 — 입력-판정 계층 방어(강건성) 근거

> DP-04 본문(`dp-04-robustness-decision.md`)의 근거 문헌 정리. 기존 리서치(spec-003/025, adr-013/023/024 작성 시 수행)를 이 DP 관점으로 재정리 + 강의 정본(framework/) 대조.

## 1. 강건성의 공식 정의

- **강의 정본(framework/ai-8-qa.md)**: 강건성 = 이상/노이즈/적대 입력에서도 기능 수준을 유지하는 능력. 입력 가드레일이 1차 방어. 측정 = 이상 입력 기각률, 정상 대비 성능 유지율.
- **spec-002 QA4**: 생리범위 밖 이상치/GPS 튐/경계 근처 떨림 연속 입력 시나리오. 측정 = 이상치 기각율 100%, Flicker Rate(인접 프레임 판정 번복), Robustness Score(정상 대비 판정 유지율) — 폐루프 측정.

→ DP-04의 평가 기준: "참값 없는 조건에서 강건성 = 판정의 **일관성**(이상값 차단 + 번복 억제 + 두절 유지)".

## 2. 입력의 현실 — 손목 PPG/GPS 노이즈

- **손목 광학 심박(PPG)의 운동 중 모션 아티팩트**: 손목형 광학 심박계는 달리기 등 운동 중 팔 흔들림/밀착도 변화로 오차가 커진다는 것이 검증 연구들의 일관된 결론(가슴 스트랩 ECG 대비). 순간 스파이크(예: 케이던스 락온 — 심박이 걸음수에 잠기는 현상)도 보고됨.
- **GPS**: 고도는 특히 잡음이 크고(수 m 단위 튐), 도심/숲에서 점프 발생 — 이 시스템의 점간 게이트(0.5~40m)와 SlopeEstimator 게이팅의 근거(spec-025 §9-1).
- 시사점: "센서 값을 그대로 믿는" 설계가 이 조건에서는 성립하지 않는다는 전제의 문헌 근거.

## 3. 번복 억제 — 히스테리시스(슈미트 트리거)

- 문턱 하나로 비교하면 노이즈가 문턱 근처에서 출력의 고속 번복(chattering)을 만든다 — 해법은 **이중 문턱(히스테리시스)**: 들어올 때와 나갈 때 문턱을 분리. 전자공학의 슈미트 트리거로 대표되는 고전 표준 기법.
- 이 시스템의 구현: DisplayZoneJudge(표시 5존 = 순간값 + 히스테리시스), adr-013/adr-023. "왜 60초 평균 대신 순간+히스테리시스인가" = guide/02 설명 참조.

## 4. 오경보 억제 — 경보 관리 표준(ISA-18.2)

- **ISA-18.2**(공정 산업 경보 시스템 관리): 오경보(nuisance alarm) 억제의 표준 수단으로 **지속 시간 조건(on-delay/off-delay)**과 **데드밴드**를 규정. 경보가 행동을 요구하는 신호라는 점에서, "코칭 = 행동 지시"인 이 시스템과 문제 구조가 같다.
- 이 시스템의 구현: 코칭/통계 판정의 입력이 60초 지속심박 = 최근 60초 평균(spec-001 FR2 이중 기준). 표준의 on-delay 타이머와 수단은 다르나(타이머 대신 이동평균), 순간 이탈을 시간축에서 걸러 지시로 만들지 않는다는 목적은 같다, 발화 지속 N초 규칙(기존 다중시간대 설계에서도 ISA-18.2를 근거로 채택했던 규율 — arch/archive 참조).

## 5. 개인별 문턱 — SPC 관리한계(k·σ)

- **Shewhart 관리도(통계적 공정 관리)**: 이상 판정 한계를 고정 상수가 아니라 관측 산포의 배수(관례 3σ, 목적에 따라 k 조정)로 설정 — 산포가 다른 공정마다 한계가 자가 보정된다.
- 이 시스템의 구현: NoiseFloor — 드리프트 판정 문턱을 개인 관측 노이즈의 EWMA 기반 k·σ로(adr-024, spec-025). CLAUDE.md "threshold는 bpm 상수가 아니라 k·σ" 규칙의 구현체.

## 6. 추세의 신뢰도 동반 추정

- 회귀 추정은 점추정(기울기)만으로 판단하지 않고 표준오차(SE)/결정계수(R²)를 동반 보고하는 것이 표준 규율 — 신뢰도가 낮으면 판단 보류(게이팅)가 가능해진다.
- 이 시스템의 구현: LinearRegression(slope/SE/R²) + AnalysisEngine 게이팅(adr-024). 자기상관 시 유효표본수 보정으로 SE 과소평가를 정직하게 교정(기존 리서치).

## 7. 소스 폴백 사다리

- graceful degradation: 센서 부재/두절 시 기능을 멈추지 않고 하위 소스로 전환. 이 시스템: 케이던스 = 워치 실측 우선 → 폰 페이스 기반 추정 폴백(spec-001 §FR3 입력 폴백 상수 168/6/−4의 근거 문서화), staleness 15초(spec-003), GPS 점간 게이트(spec-025 §9-1).

## 8. 2안(즉시 반응 판정)의 실제 위상

- 짧은 이동평균 + 순간값 비교는 가장 단순한 구성으로, 센서가 깨끗하거나(가슴 스트랩 ECG) 출력이 기록/표시 위주인 조건에서는 합리적 선택이다. 반응 지연 최소가 실제 강점.
- 한계의 구조적 원인: 파라미터가 평활 창 하나라 스파이크 억제(긴 창)와 반응성(짧은 창)이 상충하고, 문턱이 하나라 경계 근처 번복은 창 길이와 무관하게 남는다. 표시와 지시가 같은 값에 매여 오판 비용 비대칭에 대응 불가.

## 9. DP-01/02/03과의 관계

- 같은 아키텍처의 네 번째 QA 단면: 층별 기각/게이팅 사유의 기록이 설명(DP-01)과 감사(DP-02)에, 개인 k·σ가 적응(DP-03)에 연결된다. 층 = 독립 모듈 구조는 테스트가능성(DP-05)의 검증 단위가 된다.
