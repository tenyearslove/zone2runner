# ADR-012: 콜드스타트 Zone 2 사전값(prior)을 프로필 factor로 정교화

- **날짜**: 2026-07-03
- **상태**: Accepted
- **결정자**: 성시원
- **보고서 매핑**: 설계 - Architectural Decision **DP2의 절반** (콜드스타트 축. 적응 축은 adr-004)
- **관련**: adr-003(하이브리드 판정), adr-004(Bayesian 적응), spec-004(개인화 모델), spec-009(프로필), spec-013(구현 명세)

---

## 맥락

개인 Zone 2 경계에는 정답이 없고(랩 젖산검사 없이는 라벨 불가), 우리의 답은 "공식 prior에서 시작해
세션 데이터로 적응"(adr-004)이다. 그런데 지금 prior는 **모든 사람이 동일하게 HRR 70%**다.
같은 나이/안정심박이라도 초보 러너와 마라토너의 유산소 임계(LT1)는 크게 다르다는 것이 정설이다:

- 훈련자 LT1 ≈ %HRmax 75~80, 비훈련자 ≈ 60~65 (지구력 훈련 강도분포 연구, Seiler 등)
- MAF 공식(180-age)은 **범주형 보정**(-10 질병회복 / -5 부상·정체 / +5 2년+ 꾸준한 훈련)을 이미 사용
  — "카테고리 몇 단계로 유산소 임계 prior를 보정한다"는 접근의 선례
- 비만/저체력군은 동일 부하에서 심박 상승과 Cardiac Drift가 커서 보수적(낮은) 경계가 안전(ACSM 지침의 저강도 권고)

Bayesian 적응은 결국 수렴하지만, **첫 1~5세션의 경험 품질은 순전히 prior가 결정**한다(C02 콜드스타트 제약).
prior가 5%p(HRR) 틀리면 초반 세션 내내 잘못된 방향으로 코칭한다. 사용자가 어차피 입력하는
프로필에 몇 개의 단계형 factor를 추가해 prior를 개인 근사치에서 시작할 수 있다면 콜드스타트 품질이 오른다.

단, 제약이 있다:
- **factor→경계의 참 매핑도 정답이 없다.** 매핑 자체가 또 하나의 추정이다.
- RHR이 이미 체력의 일부를 반영한다(HRR 공식). 과도한 보정은 **이중 계상** 위험.
- 온디바이스/1인 1달: 모델이 아니라 산술이어야 한다.

## 결정 대상 문제

**"사용자 데이터가 쌓이기 전, 초기 Zone 2 경계(prior μ0, σ0)를 무엇으로 산출하는가?"**

## 대안 비교

| 기준 | A. 공식 고정 (현행: HRR 70% 일괄) | B. 단계형 factor 오프셋 매핑 *(채택)* | C. 모집단 회귀/ML 모델 |
|------|------|------|------|
| 콜드스타트 정확도 | 하 (개인차 무시) | 중 (체계적 편차 흡수) | 중~상 (데이터 품질 의존) |
| 근거 데이터 요구 | 없음 | 없음 (문헌 기반 오프셋) | 공개 데이터셋 + 파생 라벨 필요 |
| 구현/검증 비용 (1인 1달) | 0 | 낮음 (산술 + 표) | 높음 (수집/학습/변환/검증) |
| 온디바이스 부담 | 없음 | 없음 (덧셈) | TFLite 추론 |
| 설명가능성 | 높음 | **높음 (오프셋 표가 곧 설명)** | 낮음 |
| 이중 계상 제어 | 해당 없음 | 오프셋 상한 clamp로 제어 가능 | 통제 어려움(feature 상관) |
| 오입력 강건성 | 해당 없음 | σ0 확대 + Bayesian이 회복 | 입력 오류에 민감 |
| 별점 | ★★☆ | **★★★** | ★★☆ |

### A. 공식 고정 (기각)
지금까지의 방식. 단순하지만 "개인화가 주 목적"인 과제에서 첫 세션들의 경계가 전 인구 동일 —
C02를 완화할 기회를 버린다. Bayesian이 수렴하기까지(관측 양호 시에도 3~5세션) 오판정 구간을 감수해야 한다.

### B. 단계형 factor 오프셋 매핑 (채택)
프로필에 **체형(5단계), 러닝 수준(5단계), 주간 운동 빈도(5단계)** + 키/몸무게를 추가하고,
각 factor의 단계를 HRR 비율 오프셋으로 변환해 uFrac0 = 0.70 + Σoffset 으로 prior를 잡는다.
- MAF의 범주형 보정과 동일한 구조라 문헌으로 정당화 가능, 표 하나가 곧 설명(설명가능성).
- **이중 계상 제어**: RHR이 체력을 이미 일부 반영하므로 오프셋 총합을 ±수%p로 clamp.
- **오입력 강건성**: 극단 단계 선택일수록 σ0(불확실성)를 키워 Bayesian 갱신이 더 빨리 교정하게 한다.
  잘못된 prior는 "느린 시작"일 뿐 고착되지 않는다(적응 축이 안전망).
- 키/몸무게 → BMI로 체형 기본값을 자동 제안(대한비만학회 기준), 사용자가 근육형 등 예외를 수정.

### C. 모집단 회귀/ML 모델 (기각)
공개 데이터로 (프로필 → LT1) 회귀를 학습. adr-004 대안 B와 같은 이유로 기각 —
파생 라벨의 정당화 부담, 1인 1달 리스크, 그리고 결국 라벨 자체가 공식/휴리스틱이라 B 대비 실익 제한.
**향후 과제**: 필드 로그(spec-012)가 쌓이면 "우리 사용자 데이터 기반" C로 진화 가능한 경로는 열어둔다
(B의 오프셋 표를 학습된 표로 교체하는 구조 — 인터페이스 동일).

## 결정

**대안 B.** 오프셋 표와 clamp 값은 spec-013에 명세. 구조적 원칙:

1. prior 산출은 **순수 함수** `(Profile) → (uFrac0, σ0)` — 테스트/교체 용이(향후 C로 진화 경로).
2. 오프셋 총합 clamp(이중 계상/극단 방지), uFrac0 범위 clamp.
3. 극단 선택/BMI-체형 불일치 → σ0 확대(불확실성 정직하게 반영).
4. 적응(adr-004)은 그대로 — prior만 개인화된 출발점으로 바뀐다.

## 결과

- (+) 콜드스타트 첫 세션부터 개인 근사 경계로 시작. "입력만으로 의미 있는 값 → 데이터로 점점 적응"의 이야기 완성(DP2).
- (+) 산술이라 온디바이스 부담 0, 표 기반이라 보고서/심사 설명 용이.
- (-) 오프셋 값 자체는 문헌 기반 추정 — 정밀 검증 불가(정답 없음). σ0 확대와 Bayesian 안전망으로 완화하고, 한계로 명시.
- (-) 입력 항목 증가로 온보딩 마찰 — 5단계 칩 UI로 3탭 이내 입력, 기본값(보통/중급/주2-3회) 제공으로 완화.
