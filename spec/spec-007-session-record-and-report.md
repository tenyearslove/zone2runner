# Spec-007: 운동 기록 저장 및 세션 리포트

- **상태**: Draft
- **날짜**: 2026-07-02
- **관련 요구**: spec-001 FR6, FR5(개인화 데이터 원천), spec-004(개인화)

## 목표

운동 세션 종료 후 주요 지표를 로컬에 저장하고, 세션별 요약 리포트와 이력 조회를 제공한다. 저장된 세션 데이터는 개인화(spec-004)의 입력이기도 하다.

## 범위

**포함**: 세션 기록 데이터 모델, 로컬 저장, 세션 요약 리포트, 이력 조회, 개인화 연동.
**제외**: 클라우드 동기화/백업(향후), 소셜 공유, 상세 UI 디자인.

## 기능 명세

### 저장 대상 (세션 종료 시)
- 메타: 시작/종료 시각, 총 시간, 거리(GPS)
- 심박: 평균/최대 HR, HR 시계열(요약 샘플)
- Zone 2: **유지 시간/비율**, 미달/유지/초과 구간 분포
- 보조: 평균 페이스, 케이던스, Cardiac Drift(디커플링) 요약, 누적 고도
- 개인화: 이 세션에서 추출한 개인 경계 관측치(spec-004 관측 z) + 갱신 후 경계(μ, σ)

### 주요 흐름
1. 운동 시작 → 실시간 파이프라인(HR/판정/코칭)과 별개로 세션 버퍼에 지표 누적
2. 운동 종료 → 요약 계산 → 로컬 DB 저장
3. 저장 직후 → 개인화 추정기에 세션 관측 전달(spec-004 갱신) — FR5 연결
4. 리포트 화면: 이번 세션 요약(Zone 2 유지율, 평균 HR, Drift 등)
5. 이력 화면: 과거 세션 목록 + 추세(Zone 2 유지율 변화, 개인 경계 이동)

### 저장 방식
- 로컬 DB(Room 등). 온디바이스 보관(프라이버시). 스키마: Session(1) - HrSample(N) 요약.
- HR 원시 시계열은 용량 위해 다운샘플/요약 저장.

### 예외 처리
- 비정상 종료(앱 강제종료): 진행 중 세션 자동 복구 또는 부분 저장
- GPS/거리 없음(실내): 거리/경사 관련 지표 생략, HR/Zone은 정상 저장

## 수락 기준 (AC)
- [ ] AC-1: 세션 종료 시 Zone 2 유지 시간/비율 + 평균/최대 HR이 저장된다
- [ ] AC-2: 저장된 세션이 이력에서 조회되고 요약 리포트가 표시된다
- [ ] AC-3: 세션 저장 직후 개인화 추정기가 갱신된다(FR5/spec-004 연결)
- [ ] AC-4: 데이터는 온디바이스 로컬에 저장된다(외부 전송 없음)
- [ ] AC-5: 실내(GPS 없음)에서도 HR/Zone 지표는 정상 저장된다
