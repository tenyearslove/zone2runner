# spec/archive — 탈락/대체된 기능 명세 (역사 기록)

현재 시스템에 **적용되지 않는** 명세를 모아둔 폴더다. 설계 변천의 근거(왜 시도했고 왜 접었는지)로 보존하며, 내용은 이동 시점 그대로다(본문 속 문서 경로는 이동 전 기준일 수 있음).

| 문서 | 무엇이었나 | 왜 탈락했나 | 대체 |
|---|---|---|---|
| spec-006 | Zone2 판정 MLP 분류기 | 시뮬 라벨 순환(자기참조)으로 지름길 학습 결함 → 판정을 규칙으로 재설계 | adr-013, ZoneJudge(규칙) |
| spec-014 | 심박 동역학 NN(시뮬-학습 MLP 회귀) | 시뮬레이터(손으로 쓴 ODE)를 흉내내는 학습은 순환/공허 → 명시적 생리 ODE로 교체 | adr-020, HrOdeModel |
| spec-015 | 역치 추정 NN | 개인화는 온라인 Bayesian이 전담(소수 라벨/콜드스타트/불확실성에 NN은 틀린 도구) | adr-016, Personalization |
