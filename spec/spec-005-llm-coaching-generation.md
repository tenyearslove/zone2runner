# Spec-005: LLM 상황 코칭 생성

- **상태**: Draft
- **날짜**: 2026-07-01
- **관련 ADR**: `arch/adr-002-ondevice-llm-coaching.md`

## 목표

Zone 2 판정 결과와 실시간 맥락을 입력받아 자연스러운 코칭 멘트를 생성하고 TTS로 출력한다. 코칭 방향은 규칙이 결정하고 표현만 LLM이 담당한다(adr-002 대안 C).

## 범위

**포함**:
- 코칭 의도 결정 (규칙): Zone 상태 → 가속/감속/유지/독려
- 입력 컨텍스트: Zone 상태, 페이스 추세, 고도(오르막/내리막), SPM, 기온/날씨
- 프롬프트 구조: system(코치 페르소나 + 제약), user(구조화된 상황 + 의도)
- 출력 가드: 방향 일치 검증, 길이 제한, 금지 표현, 중복 쿨다운
- TTS 출력

**제외**:
- LLM 모델/런타임 선정 상세 (adr-002에서 유보)
- Zone 2 판정/개인화 (adr-003 / spec-004)
- HR 수집 (spec-003)

## 기능 명세

### 주요 흐름
1. 판정기가 Zone 상태 변화 또는 주기 트리거 발생
2. 규칙이 코칭 의도 결정 (예: 초과 → 감속, 미달 → 가속, 유지 → 독려)
3. 맥락(고도/페이스/SPM/날씨)을 구조화해 프롬프트 구성
4. On-device LLM이 한 문장 코칭 멘트 생성
5. 출력 가드 검증: 의도 방향과 멘트 방향 일치 확인, 실패 시 재생성 또는 템플릿 폴백
6. TTS 음성 출력

### 예외 처리
- LLM 지연/실패: 의도에 대응하는 템플릿 문구로 폴백 (QA4 보장)
- 방향 불일치 출력: 가드가 차단하고 폴백 (QA1 보장)
- 동일 상황 반복: 쿨다운으로 중복 안내 억제

## 수락 기준 (AC)
- [ ] AC-1: Zone 이탈 방향과 코칭 멘트 방향 일치율 95% 이상 (QA1)
- [ ] AC-2: 상황 변화 감지 후 음성 출력까지 5초 이내 (QA4)
- [ ] AC-3: LLM 실패 시 템플릿 폴백으로 코칭이 끊기지 않음
- [ ] AC-4: 네트워크 없이(오프라인) 코칭이 동작함

## 미해결 사항
- [ ] 프롬프트 페르소나/톤 튜닝
- [ ] TTS 엔진 선택 및 지연 예산 배분
- [ ] 코칭 트리거 주기/쿨다운 값
