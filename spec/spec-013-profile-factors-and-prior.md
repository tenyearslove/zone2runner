# Spec-013: 프로필 factor 확장과 Zone 2 초기 prior 산출

- **상태**: Draft
- **날짜**: 2026-07-03
- **관련 요구**: spec-001 FR1/FR5, C02(콜드스타트), adr-012(결정), adr-004(적응 축), spec-004(개인화 모델), spec-009(프로필 기본)
- **구현 위치**: `app/` domain/Models.kt(Zone2Prior), data/ProfileStore, ProfileActivity, pipeline/Personalization

## 목표

사용자가 처음 입력하는 프로필만으로 **개인 근사 Zone 2 prior**(μ0, σ0)를 산출한다.
AI(Bayesian 적응)가 규칙 판정과 함께 데이터로 최적화되기 전에도 의미 있는 초기값을 제공하고,
이후 세션 데이터가 쌓일수록 prior에서 개인 실측 경계로 이동한다(C02 해소의 앞단).

| 항목 | 형식 | 기본값 | 용도 |
|------|------|--------|------|
| 나이 | 숫자 | 35 | HRmax(Tanaka), HRR |
| 안정시심박 RHR | 숫자 | 58 | HRR |
| 최대심박 | 숫자(0=자동 Tanaka) | 자동 | HRR |
| **키(cm)** | 숫자 | 170 | BMI → 체형 기본값 제안 |
| **몸무게(kg)** | 숫자 | 70 | BMI → 체형 기본값 제안 |
| **체형** | 5단계 칩 | BMI 제안값 | prior 오프셋 |
| **러닝 수준** | 5단계 칩 | 중급 | prior 오프셋 |
| **주간 운동 빈도** | 5단계 칩 | 주 2~3회 | prior 오프셋 |

### 단계 정의와 오프셋 (HRR 비율 %p, adr-012 대안 B)

**체형** (BMI 제안 기준: 대한비만학회 — <18.5 저체중, 18.5~23 정상, 23~25 과체중, ≥25 비만. 매우마름은 <17)

| 단계 | 매우 마른형 | 마른형 | 보통형 | 과체중형 | 비만형 |
|------|:---:|:---:|:---:|:---:|:---:|
| 오프셋 | -0.01 | 0.00 | 0.00 | -0.02 | -0.04 |

(근거: 체지방 증가 → 동일 부하 심박 상승/드리프트 증가 → 보수적 경계. 마른 쪽은 임계 상향 근거 부족 — 저근육 가능성으로 미세 하향)

**러닝 수준** (선택 안내문으로 자기평가 보조)

| 단계 | 입문(달려본 적 거의 없음) | 초급(가끔, 5km 미만) | 중급(주기적, 5~10km) | 상급(10km+ 꾸준히) | 엘리트(대회/훈련 수년) |
|------|:---:|:---:|:---:|:---:|:---:|

**주간 운동 빈도**

|------|:---:|:---:|:---:|:---:|:---:|
| 오프셋 | -0.02 | -0.01 | 0.00 | +0.01 | +0.02 |

### prior 산출식

```
# ★ Zone2 기준 = %HRmax (2026-07-04 재보정). 상단 = 최대심박의 (0.70+offset), 유산소 임계 LT1 근사.
#   이를 개인별 HRR 비율(uFrac0)로 환산해 파이프라인 규약(RHR + uFrac0×HRR)을 유지한다.
offset    = clamp(체형 + 수준 + 빈도, -0.08, +0.06)   # %HRmax 목표 미세조정
hrmaxFrac = clamp(0.70 + offset, 0.60, 0.78)          # Zone2 상단(%최대심박)
uAbs      = hrmaxFrac × maxHr                          # 상단(bpm)
uFrac0    = clamp((uAbs − RHR)/HRR, 0.30, 0.75)        # HRR 비율로 환산
μ0        = RHR + uFrac0 × HRR                         # bpm (= uAbs 근사)
extremity = Σ |단계 - 중앙(3)|  (각 factor, 0~6)
σ0        = 8.0 + 0.8 × extremity                      # bpm, 극단 선택일수록 불확실성 확대 (중앙=기존 σ 8과 동일)
BMI-체형 불일치(제안값과 2단계 이상 차이) 시 σ0 += 2.0
```

- 산출은 순수 함수 `Zone2Prior.of(profile)` — 단위 테스트 대상, 향후 학습된 표로 교체 가능한 지점.
- Personalization(spec-004)은 μ0/σ0²을 사전분포로 사용(기존 고정 0.70/8² 대체). 갱신식/가드는 불변.

## UI (ProfileActivity)

- 기존 나이/RHR/최대심박 아래에 키/몸무게 입력, 그 아래 3개 factor를 **가로 5칩 선택**으로 배치(각 1탭).
- 키/몸무게 변경 시 체형 칩에 "BMI 제안" 표시를 갱신(자동 선택은 최초 1회만, 사용자의 선택을 덮어쓰지 않음).
- 화면 하단에 **초기 Zone 2 범위 미리보기(bpm)** 를 실시간 갱신 — 입력이 결과에 미치는 영향을 즉시 보여줌
  (예: "초기 Zone 2: 128~141 bpm, 신뢰도 ±8bpm"). 입력↔효과의 피드백이 곧 편리한 UI의 핵심.
- 저장 전 항목 미입력이어도 기본값으로 동작(콜드스타트 C02 — 입력은 정확도를 올릴 뿐 필수 아님).

## RHR 모름 처리 (spec-009 4순위 폴백의 개선판)

- RHR 입력 0/공백 = 모름. %HRmax로 갈아타는 대신(파이프라인 전체가 HRR 기반이라 이원화 비용 큼),
  **러닝 수준/빈도로 모집단 RHR을 추정**해 HRR 파이프라인을 유지한다.
  `RHR추정 = [74,70,66,60,54][수준] - (빈도-3)×2, clamp 45~85` (근거: RHR-유산소 체력 역상관, 훈련자 40~60/일반 60~80).
- 추정치 사용 시 σ0 +3bpm(불확실성 정직 반영), 미리보기에 "추정 nn bpm" 명시.

## 개인화 안전 가드 (2026-07-03 실기기 관찰 반영)

세션 내 개인화 갱신이 상한을 +15bpm까지 올려 "HR 160인데 Zone 2 유지"가 관찰됨(임계 추출
Conconi 편향과 결합). 가드 강화:
- 세션 내 μ 이동 제한: mu0 ±15 → **±10bpm**
- 생리 가드: boundary uFrac clamp 0.30~0.75 (%HRmax 재보정 - 실측 maxHr/저RHR은 HRR 비율이 낮음, 토크테스트로 더 내려갈 수 있게)

## 하위 호환

- 기존 저장 프로필(나이/RHR/최대심박만)은 신규 필드 기본값(170/70/보통/중급/주2~3회)으로 로드
  → offset=0이면 %HRmax 0.70 목표를 HRR로 환산한 값. 기준이 %HRmax로 재보정됨.

## 수락 기준 (AC)

- AC1: 세 factor 모두 중앙 선택이면 uFrac0=(0.70×maxHr−RHR)/HRR (일반적으로 0.70 아님, %HRmax 환산값).
- AC2: 오프셋 합/uFrac0가 명세 범위를 절대 벗어나지 않는다(전 조합 자동 검증).
- AC3: 극단 선택일수록 σ0 증가, BMI-체형 2단계 불일치 시 σ0 추가 확대.
- AC4: 키/몸무게로 체형 기본값이 대한비만학회 기준으로 제안된다.
- AC5: ProfileActivity에서 factor 변경 즉시 미리보기 bpm이 갱신된다(실기기 확인).
- AC6: Personalization이 prior를 사용하고, 관측 갱신 후 수렴 동작은 기존과 동일(회귀 테스트).

## 검증 계획

- 단위 테스트: 매핑/clamp/BMI 제안/하위 호환(AC1~4, AC6).
- ml/prior_experiment.py: 참 경계가 factor와 상관하는 모집단 시뮬레이션에서
  "정교화 prior vs 고정 prior"의 초기 오차/수렴 세션 수 비교 → 보고서 수치.
- 실기기: 프로필 화면 조작 → 미리보기 갱신 → 시뮬 세션에서 개인화 uEst 출발점 확인(AC5).
