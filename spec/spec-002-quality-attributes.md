## Utility Tree

품질속성을 상위 개념에서 구체 시나리오(ASR 후보)로 세분하고, 각 잎에 (중요도, 난이도)를 표기한다. 중요도/난이도는 상=H(8~10), 중=M(6~7), 하=L(1~5)로 환산.

```
유용성(Utility)
├─ 기능 정확성(AI)
│   └─ QA1 Zone 상태에 맞는 코칭 방향 생성            (H, M)
├─ 강건성(AI)
│   └─ QA2 센서 이상값에도 정상 범위 출력 유지        (H, L)
├─ 기능 적응성(AI)
│   └─ QA3 누적 데이터로 개인 Zone 2 경계 보정         (H, H)
├─ 수행 효율성(AI)
│   └─ QA4 이탈 감지→음성 코칭 5초 이내               (H, M)
└─ 테스트 가능성
    └─ QA5 Watch 없이 HR 소스 교체로 전체 검증         (M, M)
```

## ASR 선정

ASR(Architecturally Significant Requirement)은 아키텍처를 좌우하는 핵심 요구로, **중요도 중(7) 이상**을 기준으로 선정한다. QA1~QA6 모두 중요도 7 이상이므로 전부 ASR이며, 우선순위(중요도·난이도 종합)는 QA3 > QA1 = QA4 > QA2 > QA5 순이다.

## ASR → 설계결정(DP) 매핑

각 ASR이 어떤 설계결정으로 해소되는지 추적한다. 이 매핑이 DP1/DP2 설계의 근거다.

> ★ DP 재구성(adr-016, 2026-07-05): DP0 하이브리드 / DP1 심박예측=NN / DP2 개인 Zone2 범위=Bayesian /
> DP3 판정=규칙 / DP4 LLM 코칭. 아래 매핑은 새 DP 번호 기준.

| ASR | 핵심 요구 | 해소 설계결정 |
|:---:|------|------|
| QA1 | 코칭 방향 정확성 (현재 수치 대비, 측정 지표) | **DP3** 규칙 판정이 3상태(미달/유지/초과) 제공 (adr-013, 결정론) → **DP4** 방향 결정 (adr-002) |
| QA2 | 이상값 강건성 (40~220 밖 이상치 기각) | 규칙 이상치 가드(OutlierGuard) + HR 파이프라인 필터 (spec-003) |
| QA3 | 개인 Zone 2 경계 적응 | **DP2** 온라인 Bayesian + 토크테스트 (adr-004/016, spec-004) |
| QA4 | 5초 이내 응답 | **DP4** 프롬프트 최소화 (adr-002) + 규칙 판정 즉시(무 추론) + 심박예측 NN 순전파 |
| QA5 | 소스 교체 검증성 | RunSource 추상화 + VirtualRunner 폐루프 시뮬 (spec-003, adr-016) |

### 평가 관점 (중요)
- **Zone 2 판정은 실측 정답(ground truth)이 없다** (개인별 진짜 경계는 랩 검사 없이는 모름). 따라서 판정 자체의 정확도로 QA를 평가할 수 없다.
- 그래서 **QA1은 현재 심박 수치 대비 코칭 방향의 정확성(일치율 95%)으로 측정**한다. 코칭은 방향(가속/감속)이 정확해야 하므로 판정은 3상태(미달/유지/초과)를 낸다. 판정은 규칙(지속 심박 vs 개인 경계 비교)이라 방향이 결정론적으로 정확하다(adr-013).
- 판정의 어려움(오르막 HR지연/드리프트 등 비선형)은 별도로 **심박 예측 NN(DP1)**이 다루어 선제 코칭에 활용한다. 판정 자체는 개인 경계(Bayesian이 학습)와의 비교라 규칙으로 충분하다.
- **센서 측정 노이즈는 프로젝트 범위 밖**(센서 하드웨어 소관)이다. QA2 강건성은 생리범위(40~220 bpm)를 벗어나는 **이상치 기각(필터링)**으로 달성한다.

## 비고
- AI QA (QA1~QA4): 기능 정확성 / 강건성 / 기능 적응성 / 수행 효율성
- 일반 QA (QA5): 테스트 가능성
- QA3의 초기 누적 기준(5회)은 FR5 설계 시 조정 가능
- 중요도 / 난이도: 1~10점 기준

| QA | 상태 | 근거 |
|:---:|------|------|
| QA1 | **달성(구조적)** | 판정이 규칙(경계 vs 지속심박)이라 코칭 방향이 결정론적으로 정확(반대 방향 불가). ZoneJudge 단위 테스트로 모순 불가 검증(속성 테스트). 구 MLP 채점(0.996)은 시뮬 라벨 자기참조라 폐기 |
| QA2 | **달성** | 이상치(40~220 밖) 기각률 1.0. ml 실험 + `OutlierGuard` 단위 테스트 |
| QA3 | **메커니즘 실증** | 관측 양호 시 세션 누적 수렴(오차 5→2bpm, 불확실성 감소). 실측 임계추출(Conconi 편향)은 한계로 명시(`ml/personalization.py`, HANDOFF) |
