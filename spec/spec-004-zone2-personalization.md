# Spec-004: Zone 2 개인화 모델 (Bayesian 경계 추정)

- **상태**: Draft
- **날짜**: 2026-07-01
- **관련 ADR**: `arch/adr-003-zone2-classification-approach.md`

## 목표

누적 운동 세션 데이터로 개인의 실제 Zone 2 심박 경계를 점진적으로 추정한다. 이 개인화 모델이 이 과제의 핵심 AI이며, Zone 2 판정은 이 모델이 산출한 경계에 현재 심박을 비교하는 것이다.

## 범위

**포함**:
- 개인 Zone 2 경계(하한/상한) 추정 상태 표현
- 사전분포(prior): 공식(HRR) 기반 초기 추정 + 인구 분산
- 관측(observation): 세션별 HR-Pace 관계, Cardiac Drift에서 도출한 실측 Zone 2 증거
- 업데이트 규칙: 세션 종료 후 posterior 갱신
- 콜드스타트: 데이터 부족 시 공식 baseline 우선, 누적될수록 개인화 가중 증가

**제외**:
- 판정의 실시간 임계값/히스테리시스 로직 (adr-003 규칙 레이어)
- 구체 수식 유도/하이퍼파라미터 (구현 시 확정)
- 코칭/TTS (spec-005)

## 기능 명세

### 개념 모델
- **상태**: 개인 Zone 2 경계에 대한 확률분포(불확실성 포함). 초기엔 넓고, 세션이 쌓일수록 좁아진다.
- **판정**: 현재 심박을 posterior 경계와 비교 → 진입/유지/이탈.
- **개인화**: 세션마다 관측으로 posterior를 갱신 → 경계가 실측 기반으로 이동.

### 주요 흐름
1. 신규 사용자: prior = 공식(HRR) 경계 + 넓은 분산
2. 세션 진행: HR-Pace, Cardiac Drift 기록
3. 세션 종료: 실측 증거로 posterior 갱신
4. 다음 세션: 갱신된 경계로 판정
5. 세션 누적: 공식 대비 개인 실측 방향으로 경계 수렴 (QA3)

### Cardiac Drift의 역할
- 동일 페이스에서 시간 경과에 따른 심박 상승(Drift)은 유산소 능력의 증거 신호로, Zone 2 상한 추정의 관측치로 활용한다(별도 하드 모델이 아니라 개인화의 입력).

### 예외 처리
- 이상 세션(센서 오류, 비정상 패턴): 관측 신뢰도를 낮춰 posterior 급변 방지 (강건성)
- 규칙 가드 우선: 개인화 결과가 생리적 안전범위를 벗어나면 규칙 baseline으로 clamp

## 수락 기준 (AC)
- [ ] AC-1: 5회 이상 누적 시 Zone 2 경계가 공식 baseline 대비 실측 방향으로 이동 (QA3)
- [ ] AC-2: 데이터 부족(콜드스타트) 시 공식 baseline으로 정상 판정 (C02)
- [ ] AC-3: 단일 이상 세션이 경계를 비정상적으로 이동시키지 않음 (강건성)
- [ ] AC-4: 개인화 경계가 항상 생리적 안전범위 내로 유지됨 (규칙 가드 우선)

## 미해결 사항
- [ ] Cardiac Drift → Zone 2 경계 증거 변환 함수
- [ ] prior 분산 초기값과 세션별 학습률
- [ ] 누적 기준 횟수 (spec-002 QA3의 5회는 조정 가능)
