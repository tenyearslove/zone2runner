## 기능 요구사항 (Functional Requirements)

| ID | TITLE | Description | AI |
|:--:|:--|:--|:--:|
| FR1 | 개인 프로필 관리 및 Zone 2 **초기** 경계 산정 | 프로필(나이/성별/신체 factor, 안정심박·최대심박은 알면 입력)을 관리·저장하고, 이를 토대로 **콜드스타트 Zone 2 경계**를 산정한다. 최대심박은 대개 모르므로 **Tanaka(208−0.7×나이) prior**로 시작, 안정심박을 알면 **Karvonen(%HRR)** 아니면 **%HRmax**로 초기 존을 잡는다(데이터 없으면 factor 기반 기본값). **관측 기반 갱신·토크테스트 역치 앵커 등 적응 개인화는 FR4.** 상세 §FR1. | |
| FR2 | 실시간 심박 수집 및 존 판정 | 갤럭시워치/센서에서 심박을 1초 주기로 수집하고, 규칙 기반으로 Zone 2 미달/유지/초과를 실시간 판정한다. | ● |
| FR3 | 심박 예측 및 선제 코칭 | 생리 모델(ODE)로 현재 페이스 유지 시의 앞선 심박을 예측해, 존을 벗어나기 전에 미리 코칭한다. | ● |
| FR4 | 개인화 학습 | 실주행 관측(말하기 테스트/드리프트)으로 개인 경계와 심박 반응 파라미터를 세션마다 자동 보정한다(점진적 개인화). | ● |
| FR5 | 실시간 코칭 제공 | 규칙이 코칭 방향과 사실을 확정하고, 온디바이스 LLM(Gemini Nano)이 이를 자연어(음성/텍스트)로 표현한다. | ● |
| FR6 | 세션 리포트 및 근거 설명 | 종료 후 경로/심박 추이/유산소 분석과 함께 "왜 이렇게 판정하고 코칭했는지"를 설명으로 제공한다. | ● |

- 규정 충족: FR 6개(최소 4개 이상), **AI 관련 FR = FR2/FR3/FR4/FR5/FR6**.

| C02 | 우리 도메인/사용자에 맞는 대량 학습 데이터를 만들 수 없음 | 개인 데이터는 세션 수십 개 수준. 공개 데이터셋(FitRec 25만 워크아웃 등)은 실존하나 이기종 기기/종목/인구가 혼재된 "모집단 평균"이라 개인 예측의 병목(개인차)을 풀지 못하고, 그 홀드아웃 정확도는 우리 사용자에 대한 보장이 아님(C03과 결합) → 블랙박스 NN 사전학습 대신 생리 ODE + 점진적 개인화(온라인 추정/Bayesian) 채택의 전제. (2026-07-08 정밀화 — "데이터가 없다"가 아니라 "있는 데이터가 우리 문제를 풀지 못한다") |
| C03 | 개인 참값(젖산/환기역치, Zone 2 상단) 측정 불가 | 소비자 기기로 랩 수준 참값 측정 불가 → 절대 정확도 대신 방향 정확성으로 품질을 목표한다. 근거: arch/zone2-physiology-and-estimation.md |
| C04 | 정량 평가는 폐루프 시뮬레이션으로 수행 | 실측 참값 부재(C03)로 QA 정량 평가를 가상러너 폐루프로 대신한다 → 소프트웨어/알고리즘 검증 범위이며, 실인간 정확도 주장이 아니다. |

- 온디바이스(전면)는 제약이 아니라 **C01이 강제한 설계 결정(DP0)**이다. (오프라인 동작/프라이버시는 그 부수효과.)

## FR1 상세 — 프로필 + Zone 2 초기(콜드스타트) 경계 (2026-07-10)

**스코프**: FR1은 **프로필 관리 + 그걸로 잡는 초기 경계(prior)**까지다. 관측으로 값을 갱신하고 토크테스트로 역치에 앵커하는 **적응 개인화는 FR4** 소관(아래 "적응(FR4)" 참조).

**프로필 관리**: 나이/성별/신체 factor, 안정심박·최대심박은 **사용자가 알면 입력**(대개 최대심박은 모름 — 전력질주 안 하면 알 수 없음). ProfileStore 저장(spec-009).

**초기 경계(콜드스타트) 산정**:
- **최대심박** = **Tanaka(208−0.7×나이) prior**(220−나이는 체계적 편향, Tanaka가 범용 최선).
- 계산법 = **안정심박 알면 Karvonen(%HRR)**(%VO2max와 더 상관/ACSM 권장), **모르면 %HRmax(Tanaka)**. **틀린 안정심박을 Karvonen에 꽂지 않는다** — 없으면 %HRmax 폴백.
- 존 구조(초기) = Z2 밴드를 문헌 관례로 잡고, 상·하위 경계는 **선언된 설계 비율(C)**. 정밀 개인화는 FR4.

→ **★ FR1만으로 완결된 5존이 산정된다(미보정 prior)**: 최소 **나이만** 있으면 Tanaka→%HRmax로 Zone 2(및 5존) 확정 — **FR4 없이도 첫 세션부터 존 표시·판정 동작**. 안정심박 있으면 Karvonen로 더 정확. 보정(토크테스트 역치 앵커)은 FR4가 이후에 상한을 실제 역치로 옮기는 것.

**정직한 한계**: 어떤 공식도 최대심박 ±10~15 bpm를 못 벗어남 → **초기값은 출발선일 뿐, 정확도는 FR4의 토크테스트 개인화가 지배**. Zone 2 하한은 생리학적으로 미정의(전문가 합의도 상한만). 문헌: Tanaka 2001, Karvonen/ACSM, Friel·Seiler(%LTHR), Zone 2 경계 변동성(PMC11986187).

**적응(FR4 소관, 여기 스코프 밖 — 참조용)**: (1) 관측 지속 피크로 **최대심박 위로만 갱신**(OutlierGuard, 프로필 저장), (2) **안정심박을 Samsung Health 수면/패시브 심박에서 추정**(아래로만 갱신 — 어떤 SDK도 완성값 안 줌), (3) **토크테스트로 Z2 상한을 유산소 역치(%LTHR)에 앵커** → 최대심박 의존 탈피 + 체력 자동 적응, (4) tier 승격(%HRmax→Karvonen→%LTHR). 상세 = FR4/spec-004.
