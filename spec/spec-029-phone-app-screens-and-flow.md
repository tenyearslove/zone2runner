## 목표

폰 앱의 화면 구성과 러닝 세션 플로우를 실제 구현 그대로 명세한다. 판정/분석/코칭의 내부 로직은 각 정본 spec이 담당하고, 이 문서는 "사용자가 보는 앱"의 정본이다.

## 화면 구성 (6개 Activity)

| 화면 | 역할 | 주요 요소 |
|---|---|---|
| **HomeActivity** | 진입점 | AI 모델 준비 배너(adr-027, 미다운로드 시 자동 다운로드+진행률), 프로필/Zone2 목표 카드(다중 프로필 선택기, 학습 반영 표시), 최근 러닝 카드, 시작(시뮬/실센서)/기록/프로필/설정 버튼, 프로필 미설정 온보딩 |
| **RunActivity** | 러닝(시뮬+라이브 겸용) | osmdroid 지도+경로+현재 위치, 심박 큰 숫자+존 칩+ZoneBandView 게이지(탭=Zone2 계산 근거 팝업), 시간/거리/페이스+경사/케이던스/보폭/기온, 코칭 문구, 워치 연결 상태. 시뮬 전용: 배속 칩, 입력 모드 순환(자동 가상러너/수동 페이스/수동 러너+슬라이더 4종), LLM on/off 토글+프롬프트 디버그 뷰 |
| **ReportActivity** | 세션 리포트 | 카드: 이전 세션 대비, 오늘 컨디션, 세션 추세 스파크라인, 개인 기록, 기간 요약(7/30일), 이번 러닝 이야기(터치=프로비넌스), 요약 그리드, 존 체류 분포, 유산소 분석(HR/페이스 추이+존 타임라인+관측 지표), 구간 분석, 경사 분해, 워밍업, 내리막 습관, 초과 원인 분해, 효율 곡선, 개인 상단 학습, 경로 지도, 코칭 로그(문장 터치=근거/프롬프트/출력 프로비넌스), LLM 사용 텔레메트리. 카드 제목 ⓘ 설명 팝업(METRIC_INFO) |
| **HistoryActivity** | 세션 목록 | 요약 리스트, 탭=리포트, 롱프레스=삭제 |
| **ProfileActivity** | 프로필/개인화 | 다중 프로필 스위처(생성/이름변경/초기화/삭제), 개인화 진행 카드(PersonalizationView+uFrac 스파크라인, AI 설명 터치=생성 프로비넌스), 심박/신체 정보, 체형/수준/빈도 5단계 칩, 관절 보호 체크(spec-026), 초기 Zone2 미리보기 |
| **SettingsActivity** | 앱 설정 | 코칭 빈도 5단계, 음성(TTS on/off, 속도/높낮이, 목소리 선택+미리듣기, 말투 4종), 더위 코칭, 화면 켜기, AI 모델 상태/다운로드 카드 |

## 러닝 세션 플로우

1. **시작**: 프로필 로드 → `LlmCallLog` 생성(프로비넌스, spec-027) → `LlmCoach` 생성+prewarm(준비 확정 전 코칭 보류, spec-028) → `RunEngine` 조립(개인화 prior/드리프트 플로어/오르막 경향 = LearnedZone 복원) → `RunSource` 선택(라이브=GPS+워치HR, 시뮬 3종) → RunLogger(JSONL) 시작 → 워치에 start/mirror 전송(adr-023).
2. **1Hz 루프**(`RunEngine.onSample`, spec-025 §결선): 정지 독려 → OutlierGuard → SafetyGuard(LLM 우회) → 누적(GPS 거리 게이트) → 판정(60초 지속심박+히스테리시스) → 분석 엔진 onTick(드리프트/GAP/케이던스) → 반응형/관절보호/방향 코칭 트리거(비동기 생성, spec-028) → 표시존(DisplayZoneJudge) → 워치 라이브 존 푸시 → 토크테스트 팝업 타이밍.
3. **종료**(`finalizeSession`): LearnedZone 저장(경계/관측/σ/드리프트 플로어/오르막 경향) → RunReport 저장(SessionStore JSON, llmCalls 포함) → 개인화 설명/세션 스토리 비동기 1회 생성(spec-023, 완료 시 llmCalls 갱신) → 워치 stop.
