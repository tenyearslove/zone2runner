# Spec-026: 내리막 관절 보호 코칭 (관절 위험군 우선 코칭)

- **상태**: Draft (검토 대기 — 구현 전 승인 필요)
- **날짜**: 2026-07-14
- **관련 ADR**: `arch/adr-013`(판정/코칭 역할 분리), `spec/spec-008`(안전 가드), `spec/spec-025`(분석 엔진/GAP), `spec/spec-013`(프로필 factor)

## 목표

내리막에서 관절(무릎) 부담이 큰 러너(무릎/관절 주의자, 고체중군)에게, **Zone 2 강도 안내보다 관절 보호 코칭을 우선**한다. 특히 내리막에서 관절 보호로 천천히 뛰어 심박이 낮아졌을 때 앱이 "속도 올리세요(미달)"라고 **잘못 코칭하는 문제를 제거**한다.

## 배경 (왜 GAP이 아니라 코칭인가)

- **GAP(경사보정 페이스, Minetti)은 대사(에너지) 비용 정규화**다. 내리막은 대사적으로 싸지만 **관절엔 부담**(제동 편심수축/충격)이라, GAP이 재는 축과 관절 부하 축이 다르다. GAP에 개인의 관절 보호 행동을 섞으면 검증된 측정 곡선을 오염시킨다(마법상수 금지 위배). → **GAP은 순수 대사 정규화로 불변**, 관절은 별도 코칭 축.
- **관절 부하는 우리가 못 잰다**(힘/지면반력 센서 없음). 따라서 "관절 부하=X" 같은 숫자를 만들지 않고, **문헌이 관절 부하 상승과 연관짓는 관측 조건**(내리막 경사 + 체중 + 과보폭/저케이던스)에서 **주의 코칭만** 낸다(종류 A 관측 조건 → 종류 C 임계로 게이트, 지어낸 지표 없음).

## 범위

**포함**:
- 프로필에 "무릎/관절 주의" 토글 추가(옵트인).
- 내리막 관절 위험 조건 감지(경사/체중/토글) → 관절 보호 코칭 트리거(RuleCoach 문구, 페르소나 반영).
- 내리막에서 "미달(속도 올려)" 코칭 억제, 관절 보호 큐로 대체. "초과(속도 줄여)"는 관절 보호 프레이밍으로 유지.
- (선택) 리포트에 내리막 행동 서술(종류 A 관측): "내리막에서 평균 N% 느리게 뛰었어요" — GAP 오염 없이 관측만.

**제외**:
- GAP/Minetti 변경(불변).
- 관절 부하 수치화(힘 센서 없음 — 안 만듦).
- 오르막/평지에서의 관절 코칭(이번 스코프는 내리막 한정).

## 기능 명세

### 트리거 조건 (내리막 관절 보호)

모두 만족 시 발동:
1. **확실한 내리막 지속**: `slopePct ≤ DOWNHILL_GRADE`가 `DOWNHILL_HOLD_SEC` 이상 지속.
2. **관절 위험군**: `profile.jointCaution == true`(토글) **또는** `bodyType ≥ 4`(과체중/비만 = BMI ≥ 25, 대한비만학회 기준, spec-013와 동일 근거).
3. 코칭 간격 게이트(기존 `CoachCadence` minGap) 준수 — 스팸 방지.

### 동작

- **우선순위**: 안전 가드(spec-008, 위험 심박=생명 안전, LLM 우회) > **관절 보호 코칭** > Zone 2 방향 코칭(미달/유지/초과). RunEngine에서 `maybeCoach`(Zone2) 앞에 검사.
- **미달(BELOW) 억제 + 대체**: 내리막 관절 조건에서 지속 심박이 하한 아래여도 **"속도 올려"를 내지 않고**, 관절 보호 큐를 낸다. 예(문구는 페르소나 반영): "내리막이에요. 보폭을 줄이고 케이던스를 유지해 무릎 부담을 낮추세요. 착지를 부드럽게."
- **초과(ABOVE) 유지 + 재프레이밍**: 내리막에서 속도가 붙어 초과면 "속도 줄이기"를 관절 보호로 프레이밍("내리막 속도를 통제하며 천천히 — 관절 보호").
- **저케이던스 강화(선택)**: 케이던스 < `CadenceBand.LOW`(162spm)면 큐에 "케이던스를 조금 올려 보폭을 줄이세요"를 덧붙임(과보폭 = 제동 충격↑, Heiderscheit 근거는 spec-005/Coach와 공유).
- **특수 코칭 계열**: 방향 render가 부적절하므로 마일스톤/워밍업/회복/오르막 예방과 같은 계열로 **RuleCoach 문구**로 낸다(LlmCoach 우회 or NanoRewriter 톤만).

### 설계 선택 상수 (종류 C — 근거 명시, CLAUDE.md 준수)

| 상수 | 출발값 | 근거(앵커) | 튜닝 |
|------|--------|-----------|------|
| `DOWNHILL_GRADE` | −4% | SlopeEstimator 데드밴드(±2%) 밖의 확실한 내리막. 제동 부하는 경사에 비례하며 대략 −3~−4%부터 유의. | 필드 |
| `DOWNHILL_HOLD_SEC` | 8s | 순간 고도 노이즈/짧은 굴곡을 거르고 "지속 내리막"만(SlopeEstimator 자체가 이미 거시 평활). | 필드 |
| 관절 위험 체중 기준 | `bodyType ≥ 4` (BMI ≥ 25) | 대한비만학회 과체중 기준(spec-013 재사용). 동일 부하에 관절 응력 비례 상승. | 고정(문헌) |
| 과보폭 케이던스 | < 162spm | 180×0.9(Heiderscheit/Daniels), 저케이던스=과보폭=제동 충격↑(Coach 재사용). | 필드 |

> 어떤 상수도 관절 부하 수치가 아니라 "주의 코칭을 언제 낼지" 게이트다. 관절 부하 자체는 만들지 않는다.

### 프로필 변경

- `Profile.jointCaution: Boolean = false`(무릎/관절 주의) 추가. ProfileActivity 토글 1개. ProfileStore 저장(하위호환: 없으면 false).
- (선택) BMI ≥ 25면 온보딩에서 "관절 주의 코칭을 켤까요?" 제안(자동 강제 아님 — 사용자 선택 존중).

## 수락 기준 (AC)

- [ ] AC-1: 관절 위험군(토글 on 또는 bodyType≥4)이 확실한 내리막에서 심박 미달이어도 "속도 올려" 코칭이 나오지 않고 관절 보호 큐가 나온다(시뮬 단위/폐루프).
- [ ] AC-2: 비위험군(토글 off + 정상체형)은 종전과 동일하게 동작한다(무회귀).
- [ ] AC-3: 안전 가드(위험 심박)는 관절 코칭보다 항상 우선한다.
- [ ] AC-4: GAP/Minetti 출력은 이 기능 전후로 불변이다.
- [ ] AC-5: 프로필 토글이 저장/복원되고, 미설정 기존 프로필은 false로 동작.
- [ ] AC-6: 앱 표시 문구에 내부용어/지어낸 관절 수치가 없다.
