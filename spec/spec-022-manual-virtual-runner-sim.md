# Spec-022: 수동 가상러너 시뮬 모드 (케이던스/보폭 직접 조종)

- **상태**: Draft (2026-07-08 사용자 요청 — 문서화 후 바로 구현/설치)
- **날짜**: 2026-07-08
- **관련**: spec-011(폰 러닝 앱), spec-019(가상러너 검증 계기), adr-020(심박 생리 ODE), adr-023(워치 뷰어화/토크테스트 폰 이관)
- **구현 위치**: `app/`(sim/ManualVirtualRunnerSource, RunActivity 시뮬 컨트롤), 워치는 기존 미러 경로 재사용

## 목표

시뮬레이터에 "완전수동" 가상러너를 추가한다. 사용자가 신체 스펙을 입력하고 케이던스/보폭을
슬라이더로 직접 조종하면 가상러너가 그 속도로 달리고, 심박은 신체 스펙 기반 생리 모델(1차 지연
ODE + 드리프트, adr-020과 동일 계열)이 자동 계산한다. 판정/코칭/토크테스트/개인화/워치 연동까지
전체 기능을 실주행 없이 손으로 재현하며 테스트할 수 있는 계기(instrument)가 목적이다.

## 범위

**포함**
- FR1 신체 스펙 입력: 나이, 안정심박, 최대심박, 기준 페이스(편한 페이스), 기온(더위 코칭 테스트용 —
  실측 날씨 조회 대신 이 값을 eng.ambientTempC에 주입). 기본값은 활성 프로필에서.
- FR2 조종 슬라이더(재생 중 실시간 반영, 각 줄에 범위 범례 + 현재 값 표시):
  - 케이던스 0~200 spm (**시작값 0 = 정지** — 올리면 달리기 시작, 내리면 정지 후 심박이 안정 심박으로 회복)
  - 보폭 0.60~1.50 m
  - 심박 보정 -20 ~ +20 bpm (생성 심박에 가산 — 개인차/컨디션 재현용)
  - 경사 -10 ~ +10% (0.5% 단위 — 파이프라인의 경사 입력(특징/예측/코칭) 점검용. 같은 속도 유지 시 심박 비용 증가, Sample.slopePct로 방출)
- FR3 심박 자동 계산: 속도 = 케이던스 x 보폭 → 페이스 → 강도(effort) 역산 → 목표 심박을
  1차 지연(hrTau)으로 추종 + 임계 초과 시 카디악 드리프트 누적 + 최대심박 포화(ManualRunSource와
  동일 방정식, 신체 스펙만 입력값으로 교체). 관측 노이즈 소량.
- FR4 토크테스트 팝업(2026-07-08 사용자 확정으로 범위 확대): 타이밍은 폰이 판단(adr-023).
  조건 판정은 **세션 시간 기준**(30초 승격/3분 간격/10분 폴백 — 가속 재생에서도 생리적 타이밍 유지,
  첫 질문은 승격 30초면 즉시), 실제 표시는 벽시계 30초 간격으로 제한(×70 스팸 방지).
  **모든 모드에서 폰 팝업 + 워치 전체화면 설문이 동시에 뜬다**(먼저 답한 쪽 반영).
  대시보드의 고정 5칩 UI(spec-016 인라인 자가관측)는 제거 — 입력 수단은 팝업으로 통일.
  **팝업이 떠 있는 동안 시뮬 시간은 정지**(RunSource.setPaused, 실센서 소스는 무시), 닫히면 재개.
  30초 무응답 시 자동 닫힘. 응답은 개인화(observeTalkTest)에 반영.
- FR5 시계연동 체크: 시작 전 "시계연동" 체크 시 워치도 미러로 실행 — 심박/존 표시(`/run/live`) +
  토크테스트 팝업(`/run/talk`)이 워치에도 뜬다. 체크 해제 시 워치로 아무것도 보내지 않는다(폰 단독 테스트).
- FR6 기존 시뮬 컨트롤과 공존: 재생 배속 칩 동작, "시뮬 입력" 선택이 [가상러너(자동) / 수동 페이스 /
  수동 러너(케이던스+보폭)] 3모드 순환.

**제외**
- GPS 실좌표(합성 경로 유지)
- 워치에서 케이던스/보폭 조종(조종은 폰 전용)
- 자동 가상러너(spec-019)의 폐루프 자동 응답 — 수동 모드에서는 토크테스트에 사람이 답한다
- 센서 아티팩트(드롭아웃/스파이크) 재현 — OutlierGuard 강건성(QA3) 검증은 자동 가상러너 담당(spec-019)

**파이프라인 입력 커버리지 점검(2026-07-08)**: 파이프라인이 소비하는 입력 = 심박, 페이스, 케이던스,
경사(특징 7종/ODE 예측 특징/코칭 맥락), GPS 좌표(경로/거리), 기온(더위 코칭), 토크테스트 응답.
수동 러너는 이 전부를 공급한다 — 심박(모델+보정), 페이스(케이던스x보폭), 케이던스(슬라이더),
경사(슬라이더), 좌표(합성 경로), 기온(스펙 입력), 토크테스트(폰 팝업/워치 설문).

## 기능 명세

### 조작 UI (RunActivity, 시뮬 모드)
| 컨트롤 | 형태 | 범위/기본 |
|--------|------|-----------|
| 시뮬 입력 | 칩(탭 순환) | 가상러너(자동) → 수동 페이스 → 수동 러너 |
| 신체 스펙 | 모드 선택 시 다이얼로그 | 나이/안정심박/최대심박/기준페이스, 항목별 라벨 명시, 기본=활성 프로필 |
| 케이던스 | SeekBar(범례+현재값) | 0~200 spm, **기본 0(정지)** |
| 보폭 | SeekBar(범례+현재값) | 0.60~1.50 m, 기본 1.00 |
| 심박 보정 | SeekBar(범례+현재값) | -20~+20 bpm, 기본 0 |
| 시계연동 | 체크박스 | 기본 해제. 시작 시점 값으로 고정 |

- 요약 라벨에 환산 페이스 실시간 표시(예: "172 spm x 1.05m → 5'32\"", 정지면 "정지").
- 페이스 = 1000 / (spm x 보폭) min/km. 속도 30 m/min 미만은 정지 취급 — 페이스 sentinel 20(화면 "--"),
  강도 최소(0.05)로 심박이 안정 심박 쪽으로 회복, GPS 이동 없음.
- 배치(사용자 피드백): 시작 버튼은 지도 바로 아래(스크롤 없이 조작), LLM 프롬프트 디버그 표시는 대시보드 맨 아래.

### 심박 생성(생리 모델)
```
speed(m/min) = spm x stride
pace(min/km) = 1000 / speed
effort = 0.5 + (basePace - pace) / 3.2      (0.30~1.05 클램프)
effortHr = restingHr + effort x HRR
hr += (effortHr - hr) / hrTau               (1차 지연, hrTau ≈ 30초)
drift += (driftScale x max(0, effortHr - uAbs) - drift) / driftTau
hrObs = clamp(hr + drift + noise + hrOffset, 35, maxHr)
```
- uAbs(진짜 임계)는 %HRmax 0.70 고정 근사(수동 모드는 "정답 수렴 검증"이 아니라 조종 계기이므로
  임의 정답 불필요 — 드리프트 발동 기준으로만 사용).
- hrOffset(심박 보정 슬라이더)은 관측 심박에 마지막에 가산 — 파이프라인엔 "더 힘든 몸"처럼 보인다.

### 토크테스트 팝업(폰)
- 트리거: RunActivity.updateTalkPrompt(adr-023)가 조건 충족 시 — 수동 러너 모드에서는 워치 전송과
  동시에 폰 AlertDialog 표시. 다른 시뮬/실센서 모드는 기존대로(폰 인라인 칩 + 워치 설문).
- 5단계 버튼(아주편함~매우벅참), 선택 즉시 반영 + 닫힘, 30초 무응답 자동 닫힘. 중복 표시 방지.
- 워치 설문과 동시에 떠 있을 수 있다 — 먼저 응답한 쪽이 반영되고 나머지는 타임아웃으로 닫힌다(중복 반영 허용,
  Bayesian 관측이라 무해).

### 시계연동(수동 러너 모드)
- 체크 시: 시작할 때 `/run/mirror` 전송(워치 미러 화면 자동 실행) + 러닝 중 `/run/mirrorhr`,
  `/run/live`(존), `/run/talk`(설문) 전송 — 기존 시뮬 미러 경로 그대로.
- 해제 시: 위 4종 전송을 모두 생략(폰 단독).

## 수락 기준 (AC)

- [ ] AC-1: 수동 러너 모드에서 케이던스/보폭 슬라이더를 움직이면 페이스가 즉시 바뀌고, 심박이
  수십 초 지연을 두고 새 수준으로 수렴한다(즉시 점프하지 않음).
- [ ] AC-2: 심박 보정 슬라이더 +20은 표시/판정 심박을 즉시 +20 올리고, 존 칩/밴드가 그에 맞게 바뀐다.
- [ ] AC-3: 강도를 Zone 2 이상으로 30초+ 유지하면(3분 간격) 폰에 토크테스트 팝업이 뜨고,
  응답이 개인 Zone 2 상단 보정에 반영된다(uEstView 변화).
- [ ] AC-4: 시계연동 체크 시 워치 미러가 자동 실행돼 폰과 같은 심박 숫자/존 색이 표시되고
  토크테스트 설문도 워치에 뜬다. 체크 해제 시 워치에 아무것도 표시되지 않는다.
- [ ] AC-5: 재생 배속 칩(×1~×70)이 수동 러너 모드에서도 동작한다(슬라이더 반영 주기도 함께 가속).
- [ ] AC-6: 세션 종료 시 기존과 동일하게 리포트가 저장된다.
