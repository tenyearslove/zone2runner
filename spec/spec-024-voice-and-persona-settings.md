# Spec-024: 음성 코칭 보이스와 말투(페르소나) 설정

- **상태**: Implemented (2026-07-08 — 사용자 지시로 문서화 직후 구현/설치. 단위 테스트: 페르소나 4건 포함 전건 통과. 실기기 AC-1/2는 다음 사용에서 확인)
- **부분 개정(2026-07-23, spec-028)**: 페르소나는 LLM 프롬프트 파라미터(말투 한 단어)로만 적용. 폴백은 단어 수준 큐(중립)라 페르소나 문구 세트는 폐기됨.
- **날짜**: 2026-07-08
- **관련 ADR**: `arch/adr-002-llm-coaching-guardrails.md` (방향은 규칙, LLM은 표현), `arch/adr-007-ondevice-llm.md`
- **관련 Spec**: `spec-021-app-settings.md` (설정 화면 — 본 기능이 항목 추가), `spec-005-llm-coaching-generation.md`

## 목표

음성 코칭의 "목소리"와 "말투"를 사용자가 고를 수 있게 한다. 현재는 TTS 속도 3단계만 조절 가능하고, 목소리는 기기 기본 보이스 고정, 말투는 프롬프트에 고정된 한 가지 톤이다. 사용자마다 듣기 편한 목소리와 동기부여가 되는 코칭 성격이 다르므로 이를 설정으로 연다.

## 범위

**포함**:
- TTS 보이스 선택 (기기에 설치된 한국어 보이스 열거, 미리듣기)
- TTS 피치(음 높낮이) 조절
- 코칭 말투(페르소나) 선택 — LLM 표현 계층에만 적용, 방향 결정 규칙은 불변
- 설정 화면(spec-021) "음성" 섹션 확장

- 워치 음성 출력 (워치는 TTS를 쓰지 않음 — 폰 전용 기능)
- 새 TTS 엔진 다운로드 유도 (기기에 설치된 보이스만 사용)
- 페르소나별 코칭 "내용" 차이 (무엇을 말할지는 규칙이 확정 — 페르소나는 어떻게 말할지만)

## 기능 명세

### FR1 — TTS 보이스 선택

1. 설정 화면 "음성" 섹션에 "목소리" 항목 추가.
2. `TextToSpeech.voices`에서 한국어(`ko`) 보이스를 열거해 목록으로 보여준다. 네트워크 전용 보이스는 제외(러닝 중 오프라인 동작 보장, C01 온디바이스 원칙과 일치). 항목 표기는 "보이스 1", "보이스 2"식 순번 + 성별/특성 힌트가 있으면 병기.
3. 항목 탭 시 해당 보이스로 샘플 문장을 즉시 재생(미리듣기): "지금 페이스 좋아요. 이대로 유지하세요."
4. 선택은 `AppSettings.voiceName`(보이스 식별자 문자열)으로 영속화. 러닝 시작 시 TTS 초기화에서 `tts.voice = 선택 보이스`로 적용.

### FR2 — 피치 조절

1. "음 높낮이" 3단계 (낮게 0.85 / 보통 1.0 / 높게 1.15) — 기존 속도 설정과 같은 칩 UI.
2. `AppSettings.voicePitch`로 영속화, TTS 초기화에서 `tts.setPitch()` 적용. 미리듣기에도 반영.

### FR3 — 코칭 말투(페르소나)

1. "코칭 말투" 선택 4종:

| 페르소나 | 성격 | 프롬프트 스타일 지시(요지) |
|---|---|---|
| 친절한 코치 (기본) | 현행 톤 | (스타일 지시 없음 — 현행 프롬프트 그대로) |
| 스파르타 교관 | 단호, 명령형 | "군대 교관처럼 짧고 단호한 명령형으로" |
| 다정한 친구 | 반말, 응원 | "친한 친구처럼 편한 반말로 다정하게" |
| 차분한 안내 | 존댓말, 담백 | "아나운서처럼 차분하고 담백한 존댓말로" |

2. 구현 = `coach_prompt.json`에 `persona` 맵 추가(외부화 원칙 유지 — 문구 편집은 에셋에서), `CoachPrompt.render`가 선택된 페르소나의 스타일 절을 `{persona}` 플레이스홀더로 삽입. 코드에는 페르소나 키만.
3. **방향 무결성 불변**: `direction`/`must` 절(방향 잠금 어휘 강제)은 페르소나와 무관하게 항상 포함. DirectionGuard 검사도 그대로 — 페르소나 문장이 방향 규약을 어기면 기존대로 기각/폴백.
4. 페르소나는 LLM 표현에만 적용. LLM 미가용/기각 시 폴백 문구는 중립 톤(현행 RuleCoach).
5. `AppSettings.coachPersona`로 영속화. 세션 시작 시 로드(러닝 중 변경은 다음 세션부터 — spec-021 기존 규약).

### FR4 — 설정 화면 통합

1. spec-021 설정 화면의 "음성" 그룹을 확장: 음성 안내 on/off, 속도(기존), **목소리(FR1)**, **음 높낮이(FR2)**, **코칭 말투(FR3)** 순.
2. 음성 안내 off면 목소리/높낮이 항목은 비활성 표시(말투는 화면 문구에도 무관하므로 활성 유지 — 코칭 카드 텍스트에도 페르소나가 적용되기 때문).

### 예외 처리

- 한국어 보이스가 0개이거나 TTS 초기화 실패: "목소리" 항목에 "기기 기본 보이스 사용" 표기 + 선택 비활성. 코칭은 현행대로 동작.
- 저장된 voiceName이 기기에서 사라짐(TTS 앱 업데이트 등): 조용히 기기 기본 보이스로 폴백, 설정 화면에 "기본" 표시로 복원.
- coach_prompt.json에 persona 맵 누락: 내장 기본값(친절한 코치)으로 폴백 — 기존 템플릿 폴백 규약과 동일.
- 미리듣기 중 다른 항목 탭: 이전 재생 중단 후 새 보이스 재생(QUEUE_FLUSH).

## 수락 기준 (AC)

- [ ] AC-1: 설정 화면에서 한국어 보이스 목록이 뜨고, 탭하면 그 보이스로 미리듣기가 재생되며, 선택 후 러닝 코칭 음성이 그 보이스로 나온다 (실기기).
- [ ] AC-2: 피치 낮게/높게 선택이 미리듣기와 러닝 코칭 음성에 반영된다 (실기기).
- [ ] AC-3: 페르소나 선택 시 LLM 프롬프트에 해당 스타일 절이 포함된다 (시뮬 모드 프롬프트 디버그 노출로 확인). 단위 테스트: 페르소나 4종 각각 render 결과에 스타일 절 + direction/must 절이 모두 존재.
- [ ] AC-4: 페르소나를 바꿔도 DirectionGuard 방향 검사(기존 테스트 전건)가 통과하고, 시뮬 세션에서 방향 기각률이 기본 페르소나 대비 유의미하게 늘지 않는다 (기각 카운터 비교).
- [ ] AC-5: 한국어 보이스 0개/보이스 소실 상황에서 앱이 죽지 않고 기기 기본 보이스로 코칭이 동작한다 (단위 테스트 + 실기기 확인은 가능한 범위).
- [ ] AC-6: 설정이 앱 재시작 후에도 유지되고 다음 세션부터 적용된다.
