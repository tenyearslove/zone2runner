# spec-021 앱 설정 화면 (코칭 빈도 + UX 환경설정)

> **⚠ 예측 de-scope (2026-07-10, adr-024)**: FR3 심박 예측 드롭. "선제 코칭(예측 기반) 켜기/끄기" 설정(FR3/AC4)은 **de-scope 대상** — 코칭이 반응형으로 전환돼 해당 토글은 무의미. 나머지 설정(코칭 빈도/음성/더위 등)은 유효. 정합 재작성은 안정화 후. 본문 미수정.

- 상태: 승인 대기 → 구현
- 관련: spec-005(LLM 코칭), `spec/archive/spec-014-hr-dynamics-model.md`(예측/선제 코칭 — 폐기, 현행 예측은 adr-020 생리 ODE), adr-002(온디바이스 코칭), spec-020(프로필/개인화)

## 배경 / 문제

코칭 간격(재코칭 60초, 최소 간격 20초 등)과 음성/화면 동작이 코드에 하드코딩돼 있어 사용자가
조절할 수 없다. 코칭이 잦으면 거슬리고, 드물면 놓친다. 사람마다 선호가 다르므로 런타임 설정이 필요하다.

## 목표

앱 전역 설정 화면을 추가한다. 프로필(신체/개인화)과 분리된 **UX 환경설정**으로, 홈에서 진입한다.

## 기능 요구 (FR)

- FR1 코칭 빈도 5단계: `최소 / 적게 / 보통 / 자주 / 매우 자주`. 기본 `보통`.
  - 빈도는 엔진의 코칭 케이던스(초)로 환산한다(`CoachCadence`): 최소 간격 / 존 밖 재코칭 / 정지 재안내.
  - `보통`은 기존 하드코딩 값(20/60/40초)과 동일 — 하위 호환.
- FR2 음성 코칭 켜기/끄기 + 음성 속도 3단계(`느리게 / 보통 / 빠르게`).
- FR3 선제 코칭(예측 기반 미리 알림) 켜기/끄기. 구 spec-014 FR4의 preemptive 경로(현행은 adr-020 ODE 예측)를 게이팅.
- FR4 더위 코칭(기온 반영) 켜기/끄기. 끄면 WeatherProbe/가상 기온을 코칭 맥락에 넣지 않는다.
- FR5 화면 항상 켜기 켜기/끄기(기본 켜기). 러닝 중 `FLAG_KEEP_SCREEN_ON` 적용 여부.
- FR6 설정은 `SharedPreferences`에 즉시 영속. 다음 러닝부터 반영(러닝 중 변경은 다음 세션부터).
- FR7 AI 모델(Gemini Nano) 상태/다운로드(adr-027): 기능 2종(코칭 문장/설명 생성, 리포트 요약 — 톤 재작성은 adr-028로 폐지)의 상태(사용 가능/다운로드 필요/다운로드 중/미지원) 표시 + "안 받은 모델 다운로드" 수동 트리거(진행률 표시). 홈 화면은 첫 진입 시 자동 다운로드 배너(`NanoModelManager`). 모델이 없어도 코칭은 규칙 문구로 무중단.

## 비목표

- 프로필별 설정(설정은 앱 전역 1벌). 워치 설정 동기화(후속).
- 코칭 문구 편집 UI(`assets/coach_prompt.json` 외부화로 대체).

## 설계

- `data/AppSettings.kt`: 설정 데이터 클래스 + 파생값(cadence, ttsRate). `SettingsStore` 로드/저장.
- `pipeline/CoachCadence.kt`: 빈도(0..4) → (minGapSec, overdueSec, idleReSec) 상수표. level 2 = 기존값.
- `RunEngine`: 생성자에 `cadence`, `preemptiveEnabled` 추가. 하드코딩 20/60/40을 케이던스로 대체.
- `RunActivity`: 설정 로드 → 엔진에 전달 + TTS 속도/on-off + keepScreenOn + 기온 게이팅.
- `SettingsActivity`: 다크 팔레트 카드 UI(칩 세그먼트 + 스위치). 홈에 "설정" 버튼.

## 수용 기준 (AC)

- AC1 빈도 `보통` 선택 시 케이던스가 기존값(20/60/40)과 동일(단위 테스트).
- AC2 빈도를 올리면 minGap/overdue/idle이 단조 감소(자주 = 더 자주)(단위 테스트).
- AC3 음성 끄기면 TTS 미발화, 화면 항상 켜기 끄기면 러닝 중 화면 자동 꺼짐 허용.
- AC4 선제 코칭 끄기면 예측 기반 선제 코칭이 발생하지 않음.
