# Spec-010: 워치 러닝 대시보드 (Wear 앱)

- **상태**: Draft
- **날짜**: 2026-07-02
- **관련 요구**: spec-001 FR2(실시간 표시)/FR3(존 판정)/FR6(세션), adr-001(Watch=수집/표시), adr-008(HR 수집 PoC), spec-003(HR 파이프라인)
- **구현 위치**: `wear/` (sensor-poc와 분리된 독립 모듈, applicationId `com.zone2runner.wear`)

## 목표

러너가 달리는 동안 워치 한 화면에서 심박/현재 존/페이스/거리/속도/경과시간을 즉시 확인하고 세션을 조작(시작/일시정지/재개/종료)한다. 원형 화면 특성상 스크롤 없이 한 화면에 정보와 조작을 모두 배치한다.

## 범위

**포함**
- 실시간 HR 표시(Health Services) + 경량 존 시각화(베젤 게이지)
- GPS 기반 페이스/속도/거리, 경과시간(일시정지 반영)
- 세션 상태기계(대기 → 진행 → 일시정지 → 종료)
- 원형 화면 단일 화면(무스크롤) 레이아웃

**제외**
- 개인화 Zone 2 판정(규칙: 지속심박 vs 개인 경계) + 경계 학습(Bayesian) — 폰 담당(adr-013/004). 워치는 폰 판정을 **미러 표시만**(폰 `/run/live` 실시간 수신, adr-022).
- 폰 Data Layer 전송, LLM 음성 코칭, 세션 영속 저장/리포트(FR6 상세는 spec-007)
- 프로필 입력 UI — 폰 담당(프로필/개인화 경계는 폰 판정에 반영돼 `/run/live`로 워치에 자동 반영됨)

## 기능 명세

### 표시 항목 (한 화면)
| 위치 | 항목 | 비고 |
|------|------|------|
| 상단 | 경과시간 mm:ss | 일시정지 중 정지 |
| 중앙 | HR(bpm) 큰 숫자 | 현재 존 색상 |
| 중앙 하단 | 존 라벨 (`Z2 지방연소 · 목표 유지`) | 존별 색상, Z2 강조 |
| 하단 3열 | 페이스(min/km) / 거리 / 속도(km/h) | |
| 최하단 | 조작 버튼 | 상태별 가변 |
| 베젤 | 존 게이지(5구간 아크 + 현재 마커) | 하단 270도 개방, 버튼 공간 |

### 존 표시 = 폰이 확정한 표시 존 수신 (adr-023, 2026-07-08 현행)
- **워치는 존을 계산하지 않는다(무로직 뷰어).** 폰이 매초 `/run/live`로 **순간심박, 존 인덱스(1~5), 존 내 위치(0~1000)**를
  보내고, 워치는 받은 존의 색/라벨을 칠하고 등폭 게이지의 해당 세그먼트 안에 마커를 놓는다 → 판정 규칙이 폰 한 곳뿐이라 불일치가 구조적으로 불가능.
- **표시 존 판정(폰) = 순간심박 + 히스테리시스**(DisplayZoneJudge: 경계 2bpm 초과 시 즉시, 그 안이면 3초 연속 시 전환) — 화면의 큰 숫자와 존 색이 항상 일치. 코칭/통계/개인화는 기존대로 60초 지속심박(adr-013 역할 분리 유지).
- 존 색은 폰-워치 공통 5색(Z1 파랑/Z2 초록/Z3 노랑/Z4 주황/Z5 빨강). 폰 밴드는 심박 범위 비례 가변 폭, 워치 베젤 게이지는 고정 등폭 - 색만 동일하면 됨.
- 폰 상태 미수신/워밍업(신선도 8초 경과) 시: **존 미표시**("폰 동기화 중", 심박 숫자는 회색 유지). 워치 자체 폴백 판정은 adr-023으로 삭제(불일치 원천 제거, 사용자 확정).
- 제약: Data Layer는 폰-워치 앱의 **applicationId가 동일해야** 라우팅됨 → wear도 `com.zone2runner.app` 사용.
- 배경: adr-022(경계+지속심박 전송, 워치 재계산)에서도 색 체계 차이로 폰 주황/워치 빨강 불일치(실기기 2026-07-07). adr-023으로 판정/색을 폰 단일화.

### 토크테스트 프롬프트 = 별도 전체화면 화면 (2026-07-06)
- 좁은 원형 화면에 5단계 칩을 인라인/오버레이로 끼워넣으면 대시보드를 못 덮거나 칩이 잘린다(실기기).
  → **별도 Activity(`TalkTestActivity`)**로 새 화면을 띄운다. 5단계 답을 **세로 버튼 리스트(ScrollView)**로 배치해
  원형 화면에서 모두 접근 가능. 답 선택 또는 30초 무응답 시 닫히고 러닝 대시보드로 복귀.
- 러닝 세션은 RunService가 계속 소유하므로 설문 화면이 떠 있어도 측정/누적 지속(adr-009).
- **타이밍 판단은 폰(adr-023 이관)**: 지속 심박이 Zone2 하한 이상 30초+ 머묾 + 3분 내 미질문, 10분 폴백. 조건 충족 시 폰이 `/run/talk`을 보내고 워치는 설문 표시(진동)와 응답 전달(`/talk/<state>`)만 한다.

### 파생 지표
- 속도: `location.speed`(m/s) → km/h. 없으면 직전값 유지.
- 페이스: `60 / 속도(km/h)` min/km, 속도 <0.5km/h면 `--'--"`.
- 거리: 진행 중 연속 위치의 `distanceTo` 누적. 0.5~40m 구간만 반영(정지 노이즈/GPS 튐 제거).

### 상태기계
```
IDLE --시작--> RUNNING --일시정지--> PAUSED --재개--> RUNNING
  ^                 |                    |
  +------종료-------+--------종료--------+
```
- 시작 시 권한(BODY_SENSORS + ACCESS_FINE_LOCATION) 확보 후 HR/GPS 등록.
- 일시정지: 경과시간/거리 누적 중지(HR은 계속 표시 가능).
- 종료: 센서 해제, 지표 초기화, 대기 화면.

### 화면 유지
- `FLAG_KEEP_SCREEN_ON`으로 앱 포그라운드 중 화면 유지(러닝 디버깅/사용성). 손목 내림 제스처는 별도.
