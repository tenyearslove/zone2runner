# Spec-018: 심박 예측 온라인 개인 보정

- **상태**: Draft
- **날짜**: 2026-07-05
- **관련 ADR**: `arch/adr-019`(온라인 잔차 보정), `arch/adr-016`(도구 선택), `spec/spec-014`(심박 예측 NN)

## 목표

기본 심박 예측 NN(시뮬 학습 "평균 러너")의 예측 오차를 실주행에서 학습해, 개인 심박 동역학에 맞게
예측을 보정한다. "페이스 변화가 없는데 60초 뒤 예측과 실제가 크게 다르면 → 다음부터 그 사람에 맞게
덜 틀리게" 만든다. DP2(Bayesian 경계 개인화)와 같은 패턴을 예측에 적용.

## FR

- **FR1 (온라인 학습)**: 매초 예측 시점의 base 예측과 특징을 버퍼에 저장. 30/60초 뒤 실제 심박이
  도착하면 오차를 계산해 잔차 모델을 LMS로 갱신.
- **FR2 (페이스 게이팅)**: 예측은 "이 페이스 유지 시" 조건부. 예측 시점 페이스와 만기 시점 페이스가
  ±0.6 min/km 이내로 유지된 샘플만 학습에 사용(조건이 바뀐 샘플 제외).
- **FR3 (보정 적용)**: 표시/선제코칭용 예측 = base_NN + clamp(잔차, ±0.12 frac). 추천 페이스 역질의는
  목표 밴드를 보정량만큼 이동해 base 스윕(보정 후 밴드 중심 겨냥).
- **FR4 (세션 누적)**: 세션 종료 시 잔차 가중치를 `LearnedDynamics`에 저장 → 다음 세션이 이어서 학습.
- **FR5 (성과 추적)**: base vs corrected RMSE(30/60초, bpm)를 집계해 보정 효과를 수치화(로그 기록).

## 설계

- 잔차 모델: `residual_frac = w·[1, hr_sus_frac, dHR·10, elapsed_min/30]`, 수평선(30/60) 별도 가중치.
  페이스 무관 특징만 사용(추천 페이스 정합). 8개 가중치(w30 4 + w60 4).
- 갱신: LMS `w += lr·(actual − (base+corr))·x`, lr=0.02. clamp로 폭주 방지.
- 저장: `data/LearnedDynamics`(SharedPreferences, CSV 8값). 로드는 RunActivity가 RunEngine에 주입.
- 구현: `pipeline/HrPredictionLearner`, `RunEngine`에 통합(observe→record→correct 순).

## AC

- [x] AC-1: 체계적 바이어스가 있는 시나리오에서 보정 RMSE < base RMSE(단위 테스트).
- [x] AC-2: 페이스가 유지되지 않은 샘플은 학습에서 제외된다(단위 테스트).
- [x] AC-3: 가중치 저장/복원 시 동일 보정을 낸다(단위 테스트).
- [ ] AC-4: 실기기에서 세션 종료 시 base/corrected RMSE가 로그에 남고, 다음 세션이 이어서 학습한다.

## Non-goals

- 온디바이스 NN 풀 재학습(역전파) — adr-019에서 기각.
- 기본 모델의 시뮬→실데이터 재학습(로그 저장 후 오프라인) — 상보적 후속.
