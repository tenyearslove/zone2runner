# /report — 보고용 문서 작성 스킬

## 역할
발표·보고서용 텍스트 원고를 작성한다.
사용자가 `/report {제목}` 형태로 호출하면, `report/report-{nnn}-{title}.md` 파일을 생성한다.

## 절차

1. `report/` 디렉토리의 기존 번호를 확인해 다음 번호를 결정한다.
2. 슬라이드 구조(섹션 제목 + 내용)에 맞게 텍스트 원고를 작성한다. 날짜는 오늘 날짜를 사용한다.
3. 파일 경로와 슬라이드 구성을 사용자에게 요약한다.

## 작성 규칙

- **슬라이드 단위로 구분**: `## 슬라이드 N — 제목` 형태로 각 슬라이드 명시
- **간결하게**: 사용자가 PPT에 그대로 옮길 수 있도록 불필요한 설명 제거
- **구조 유지**: 불릿·표·강조 등 PPT 레이아웃을 고려한 형태로 작성
- **관련 문서 참조**: spec·adr 내용을 반영할 경우 출처 명시
- **기호 규칙**: `·` 기호 사용 금지. 열거는 `,` 또는 `/`, 강조는 `-` 사용.

## 템플릿

```markdown
# Report-{nnn}: {제목}

- **날짜**: YYYY-MM-DD
- **용도**: (발표 / 중간 보고 / 최종 보고 등)

---

## 슬라이드 N — {슬라이드 제목}

{내용}

---

## 슬라이드 N+1 — {슬라이드 제목}

{내용}
```
