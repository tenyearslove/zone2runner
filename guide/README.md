# 이 앱 이해하기 — 사용자를 위한 안내서

zone2runner 앱이 **무엇을 측정하고, 무엇을 계산하고, 사용자에게 무엇을 보여주는지**를 하나도 빠짐없이, 중학생도 이해할 수준으로 풀어 쓴 문서 모음입니다. 모든 항목은 실제 코드(file:line)에서 정밀하게 뽑았어요.

## 먼저 이 약속부터

> **이 앱은 미래를 점치지(예측하지) 않아요. 없는 숫자를 지어내지도 않아요.**
> 실제로 잰 관측과, 그걸로 계산한 근거 있는 숫자만 씁니다. 확실하지 않으면 비워둬요.

## 어디부터 읽을까

- **처음이라면** → [00. 한눈에](00-한눈에.md) (3분, 앱 전체 그림)
- **순서대로 깊이** → 01 → 02 → 03 → 04 → 05
- **궁금한 것만** → 아래 표에서 골라 읽기

## 값의 세 종류 (모든 문서 공통 표기)

- **A. 도출값** — 잰 신호에서 그때그때 계산 (예: 회귀 기울기, 효율)
- **B. 학습값** — 그 사람에게서 스스로 배워 수렴 (예: 평소 드리프트 선)
- **C. 설계 선택** — 문헌 근거가 있는 출발 상수 (예: 60초 창, Minetti 다항식)
